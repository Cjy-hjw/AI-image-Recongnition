## 云端手册/

每轮上云**随代码一起打包**的两份，文件名即打包后的名字（云端 agent 按这个名字互相引用）：

- `操作说明.md` — 执行步骤（解压 → 校验哈希 → 起训 → 回报）
- `速查表.md` — 数据格式/类别编码/字段含义/FAQ，查阅用不通读

⚠️ 打包时 `速查表.md` 需改名为 `AGENTS.md`（云端 agent 自动加载该文件名），
`操作说明.md` 保持不变。改名后记得同步 `操作说明.md` 里对它的引用。

面向的是云端的小模型 agent，**写得短、给判断表、别讲来龙去脉**。
