> 本手册由 2026-08-31 部署探路的实战排障定型,替换此前的推理轮手册口径。
> 面向操作者(用户/云 agent),只给操作与判据。

## 一、部署形态(三件套全在挂载盘,容器重建免疫)

| 件 | 位置 | 说明 |
|---|---|---|
| 代码+配置+resnet18 | `/2026aicompetition/workspace/cloud_infer/` | cloud_infer.zip 解压产物 |
| 依赖 | `/2026aicompetition/workspace/pylibs/` | `pip install --target` 装入(镜像自带的 torch/numpy/Pillow 不装) |
| 主权重 | `cloud_infer/checkpoints/official_heads_seg_best.pth` | 训练产物,云端原生 |

🔴 **为什么全进挂载盘**:平台容器「停止→启动」会**清空容器层**(site-packages、~/.cache 全丢,实测两次);只有 workspace 挂载盘存活。软链接/拷贝进 ~/.cache 也会丢。

## 二、创建测评容器(字段填法)

- **容器类型**:测评容器;端口 8000
- **镜像**:自定义/公共镜像均可(依赖不靠镜像)
- **环境变量栏**(key/value 分框,4 行):

| key | value |
|---|---|
| `PYTHONPATH` | `/2026aicompetition/workspace/pylibs` |
| `AICOMP_RESNET18_WEIGHTS` | `/2026aicompetition/workspace/cloud_infer/torch_hub_checkpoints/resnet18-f37072fd.pth` |
| `AICOMP_WEIGHTS` | `/2026aicompetition/workspace/cloud_infer/checkpoints/official_heads_seg_best.pth` |
| `PRODUCTION` | `1` |

- **启动命令栏**(🔴 必须朴素形态,不包裹):

```
cd /2026aicompetition/workspace/cloud_infer; python -m src.service.app
```

🔴 **禁止** `sh -c "..."` 包裹(平台执行器不兼容,容器启动日志报 `sh: 0: Illegal option -d`,秒死,状态永远"启动中");禁止内联 `KEY=VAL` 前缀(不走 shell 解析)。

## 三、排障 SOP

1. **状态卡"启动中" → 第一动作:看容器启动日志**(实例详情/监控)。找 `Starting exec start up command` 之后的行——报错就在那里。**别盲试换命令/镜像**(2026-08-31 盲试三次全因没看日志)。
2. **推理失败** → 同一份日志,找 `[ERROR] src.service.tasks` 的 traceback。
3. **缺包** → web 终端 `pip install --target=/2026aicompetition/workspace/pylibs <包名> -i https://mirrors.aliyun.com/pypi/simple/`,装完跑真实 import 链验证(如 `PYTHONPATH=... python -c "from skimage.feature import graycomatrix"`)。
4. 探活 `/health` 大量 `200 OK` 是正常心跳,不是新任务。

## 四、依赖版本集(实测可用,勿漂移)

- numpy 2.4.6 + torch 2.8.0+cu128(镜像自带,不装)
- **pylibjpeg 2.1.0 + libjpeg 2.4.0 + openjpeg 2.5.0**(🔴 旧版 2.2.1/2.1.0 绑 numpy1 ABI,numpy2 下 import 即炸)
- opencv-python-headless **4.x(<5,5.0 炸 detect_splicing)**
- skimage 需 `lazy_loader`(--target 安装可能漏,显式补装)
