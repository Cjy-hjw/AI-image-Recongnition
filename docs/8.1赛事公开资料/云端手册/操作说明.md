## 步骤 1：解压

```bash
cd <项目根>
unzip -o cloud_infer.zip
```

🔴 **必须用 `unzip -o`，不要用图形界面的"替换同名目录"。**

2026-08-17 出过事故：走"替换目录"导致 `src/` 下同级的四个子目录被整个抹掉
（67 个 `.py` 只剩 9 个），而当时 `sha256sum -c` **全是 OK 查不出来**
（哈希只验清单里列出的文件，覆盖不到被连带删除的）。

**解压后跑这两条核验**：

```bash
sha256sum -c SHA256SUMS.txt | grep -v OK    # 期望：无输出
find src -name "*.py" | wc -l                # 期望：41
```

两条是正交的：哈希验内容、计数验完整。**把输出原样发我。**

## 步骤 3：装依赖

## 步骤 4：起服务

### 🔴 先确认主模型权重

主模型权重**不在包里** —— 它是**云端训练产出**的那份。

```bash
export AICOMP_WEIGHTS=/绝对路径/official_heads_seg_best.pth
ls -lh $AICOMP_WEIGHTS
```

**为什么这一步最关键**：项目里有好几个 `.pth` 长得很像、大小也差不多，但只有
训练产出的那份含训练好的四个分类头。装错了服务照样能起来、`prediction.json`
照样合法，**但四个维度输出的是随机数** —— 比不输出还糟。

**把 `ls -lh` 的结果（文件名 + 大小 + 日期）发我确认后再往下走。**

### 起服务

```bash
export PRODUCTION=1        # 权重缺失时启动即报错，别静默跑

nohup python -u -m src.service.app > service.log 2>&1 &
sleep 10 && curl -s http://localhost:8000/health && echo
head -50 service.log
```

- `nohup` 和 `-u` **都不能少**：不加 `nohup` SSH 一断进程就被杀；不加 `-u` 日志攒着不刷新。

**把这两条的输出发我。** 期望 `/health` 返回类似 `{"status":"ok",...}`。

## 步骤 5：验证四个分类头真的生效了

平台发第一批任务后，随便挑一份产出的 `prediction.json`：

```bash
python - <<'EOF'
import json, glob
ps = sorted(glob.glob("/2026aicompetition/workspace/answer/*/*/prediction.json"))
print(f"共 {len(ps)} 份")
for p in ps[:3]:
    d = json.load(open(p, encoding="utf-8"))
    ns = d["Prediction"]["Nodules"]
    print(f"\n{p}\n  StudyUID={d['StudyUID']}  结节数={len(ns)}")
    assert sorted(d["Prediction"]["MaskFiles"]) == sorted(n["MaskFile"] for n in ns), "🔴 MaskFiles 对不上"
    if ns:
        n = ns[0]
        lp = n["LocationProbs"]
        uniform = all(abs(x - 1/7) < 1e-6 for x in lp)
        print(f"  Location={n['Location']} ETE={n['ExtrathyroidalExtension']} "
              f"TIRADS={n['TI_RADS_Class']} T={n['T_ClinSig']['T']}")
        print(f"  LocationProbs={[round(x,4) for x in lp]}")
        print(f"  🔴 LocationProbs 是均匀分布吗? {uniform}   <- True 说明权重装错了!")
EOF
```

**把完整输出发我。** 重点看最后那行：

- `False` → 正常，四个头在工作
- `True` → **停下来报我**，权重装错了，继续跑等于交随机数

## 什么时候该停下来

| 现象 | 做什么 |
|---|---|
| `find src -name "*.py" \| wc -l` 不等于 41 | 🔴 **停**，解压不完整，别自己重传 |
| `sha256sum -c` 有 FAILED | 🔴 **停**，报哪些行 |
| `pip install` 报错 | 🔴 **停**，报是哪个包、什么错 |
| 依赖自检 `ModuleNotFoundError` | 🔴 **停**，报缺哪个 |
| `import src.service.app` 报错 | 🔴 **停**，发完整报错 |
| `/health` 不通 | 🔴 **停**，发 `service.log` 全文 |
| `LocationProbs` 是均匀分布 | 🔴 **停**，权重装错了 |
| 每个病例都 FAILED | 🔴 **停**，发 `service.log` 里第一个病例的完整报错 |
| 服务进程消失了 | 🔴 **停**，发 `service.log` 末尾 50 行 |
| 日志有 `authenticity 权重加载失败` | ✅ **继续**，这是设计好的降级，正常 |
| 日志有 `calibration 参数文件不存在` | ✅ **继续**，正常，不影响输出 |
| 某个病例报 gzip / NIfTI 读取错误 | ✅ **继续**，已知有损坏文件，报我文件名即可 |
| 阴性病例的 `Nodules` 是空数组 | ✅ **继续**，正常，官方要求这样输出 |

## 环境变量速查

只有前两个需要你设，其余用默认值。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `AICOMP_WEIGHTS` | `checkpoints/thyroidxl_merged_v2.pth` | 🔴 **必须覆盖**成训练产出的权重 |
| `PRODUCTION` | 未设 | 设 `1`：权重缺失时启动即报错（交付时应设） |
| `AICOMP_CONFIG` | `configs/thyroid_config.yaml` | 不用改 |
| `AICOMP_PRECISION` | `fp16` | 不用改 |
| `AICOMP_MAX_FRAMES` | `0` | 动态图抽帧上限（0=全帧，2026-09-08 检测 AP 药方起默认全帧） |
| `AICOMP_WORKSPACE` | `/2026aicompetition/workspace` | 平台挂载点 |
| `AICOMP_ANSWER_ROOT` | `{workspace}/answer` | 结果根目录 |
| `AICOMP_CALLBACK_BASE_URL` | `http://10.1.13.241:80` | 平台内网网关 |
| `AICOMP_INFERENCE_WORKERS` | `1` | 不用改（2026-09-08 OOM 后默认 1 串行；内存实测峰值 15-19G/64G） |
| `AICOMP_AUDIT_FRAMES` | `3` | 动态 gatekeeper 审计帧数（软模式零分值影响）；恢复全帧审计设 `0` |
| `AICOMP_VIDEO_BATCH` | `8` | 动态批量前向批大小（2026-09-09 提速）；=1 回退旧逐帧（异常对拍用） |
| `AICOMP_SEG_THRESHOLD` | `0.35` | 静态分割二值化阈值（2026-09-11 云端扫参定参,代码默认值已改,不设 env 也生效）|
| `AICOMP_SEG_THRESHOLD_DYNAMIC` | `0.5` | 动态分割阈值（扫参证实 0.5 已是测试范围最优,维持默认不动）|
| `AICOMP_SEG_GROW` | 未设(关) | 静态滞回生长阈值（阶段3 手段4,须 < SEG_THRESHOLD）。未设=恒等关闭;≥阈值/畸形自动钳回关闭。**离线扫参定参前勿设** |
| `AICOMP_MIN_AREA_RATIO` | `1e-4` | 静态最小面积占比（件套④ AP 单调性）；只作用静态。垃圾/inf/nan 自动回默认 |
| `AICOMP_MAX_NODULES` | `20` | 预测结节数上限（阶段1方向A）。🔴 静/动**两池同时生效**；🔴 设之前必须先跑 analyze_diag_sidecar 确认**两池** n_pred 饱和率（截断在绑才设,否则零收益正成本——动态写盘 O(全尺寸体素) 是 8h 时限风险）。合法值 1-100 整数,畸形回默认 20 |
| `AICOMP_CLEAN_2D` | `0`(关) | 静态 2D mask 形态学清理（2026-09-12 离线对拍双负判死,🔴 保持关闭勿设）|
| `AICOMP_STATIC_TTA` | `0`(关) | 静态 hflip TTA（D2 2026-09-12 第9次跑分 -0.94 **判死**,默认关）；勿设回 1 |
