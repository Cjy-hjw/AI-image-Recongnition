## 1. 跑诊断(全量约 30-60 分钟;先 --limit 3 预检约 2 分钟)

```bash
cd /2026aicompetition/workspace

# ① 预检(3 例,验管道能跑通)
python scripts/diagnose_detection.py \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --weights checkpoints/official_heads_seg_best.pth \
    --config configs/thyroid_config.yaml \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    --limit 3

# ② 全量(无 --limit;nohup 防断)
nohup python -u scripts/diagnose_detection.py \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --weights checkpoints/official_heads_seg_best.pth \
    --config configs/thyroid_config.yaml \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    > /2026aicompetition/workspace/diagnose_r5.log 2>&1 &
tail -f /2026aicompetition/workspace/diagnose_r5.log
```

说明:
- `--weights` 指向 **r5 的 official_heads_seg_best.pth**(诊断对象是当前交付权重,
  不是 r7 新训的;r7 若对拍胜出后再跑一轮指向 r7 即可)。
- ⚠️ 若 r7 训练刚做完,cache 里已是新表 samples.pkl —— 诊断只用它的 img/mask,
  临床标签不消费,新旧表对该脚本无影响。
- 启动后第一屏会打印权重绝对路径,确认指向 official_heads_seg_best.pth。

## 我们要看的(你不用判断,原样回报即可)

| 观察 | 含义 |
