## 2. r7 训练(冷启 24ep,约 40 分钟)

```bash
# 先 mv 走旧 JSONL(JSONL 是追加不是覆盖,不 mv 会跨轮污染)
mv /2026aicompetition/workspace/logs/*.jsonl /2026aicompetition/workspace/logs/r6_backup/ 2>/dev/null || mkdir -p /2026aicompetition/workspace/logs/r6_backup && mv /2026aicompetition/workspace/logs/*.jsonl /2026aicompetition/workspace/logs/r6_backup/ 2>/dev/null

nohup python -u scripts/train_official.py \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    --epochs 24 \
    --out checkpoints/official_heads_seg_r7_ep24.pth \
    > /2026aicompetition/workspace/train_r7.log 2>&1 &

# 盯前 3 个 epoch(判据:启动正常、loss 有限、无 NaN)
tail -f /2026aicompetition/workspace/train_r7.log
```

🔴 **不带 `--resume-from`**(冷启,r6 实验定案:混训底座对分类有害)。
🔴 **`--out` 必须是版本化文件名**(勿用默认 official_heads_best.pth,那是冒烟默认路径)。
