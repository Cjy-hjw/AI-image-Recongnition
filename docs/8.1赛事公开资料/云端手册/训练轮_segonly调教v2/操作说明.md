## 1. 训练(20ep,r5 热启动,约 35-50 分钟)

```bash
# 先 mv 走旧 JSONL(JSONL 是追加不是覆盖,不 mv 会跨轮污染)
mkdir -p /2026aicompetition/workspace/logs/segonly_v2_backup
mv /2026aicompetition/workspace/logs/*.jsonl /2026aicompetition/workspace/logs/segonly_v2_backup/ 2>/dev/null

cd /root/cloud_train_pkg
PYTHONPATH=/2026aicompetition/workspace/pylibs nohup python -u scripts/train_official.py \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    --resume-from checkpoints/official_heads_seg_best.pth \
    --seg-only \
    --epochs 20 \
    --out checkpoints/seg_only_finetune_v2.pth \
    > /2026aicompetition/workspace/train_segonly_v2.log 2>&1 &

# 盯前 3 个 epoch(判据:启动正常、loss 有限、无 NaN;横幅应打印
# "boundary_weight=0.0 lovasz_weight=0.3 epochs=20 ... dice 硬门已删")
tail -f /2026aicompetition/workspace/train_segonly_v2.log
```

说明:
- `--resume-from` 指 r5 全量权重(r5 冻结交付不受影响,这是训练树路径);
- 横幅门文案是"mal/tirads/loc/t/ete 各不降超 0.01,对照 epoch=0 基线"
  (🔴 **val_dice≥0.72 旧门已删**,val_dice 只留档不再判生死,低 dice 不是失败);
- 20ep 约 35-50 分钟(95s/ep 实测口径);
- 训练命令带 `PYTHONPATH=/2026aicompetition/workspace/pylibs`(依赖装在 pylibs 挂载盘,
  容器原生 site-packages 是裸 torch,不带会 import pandas/openpyxl 失败)。
