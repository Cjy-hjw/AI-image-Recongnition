## 二、1ep 量级标定(必做,反推正式权重)

```bash
cd /2026aicompetition/workspace
PYTHONPATH=/2026aicompetition/workspace/pylibs python -u -m scripts.train_official \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx <标注.xlsx> \
    --config /root/cloud_train_pkg/configs/thyroid_config_deepsup.yaml \
    --resume-from <ep16权重路径> \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    --seg-only --epochs 1 \
    --out checkpoints/deepsup_calib_probe.pth 2>&1 | tee deepsup_calib.log
```

读 JSONL(日志目录默认 `/2026aicompetition/workspace/logs`,取最新一行的):
- `loss_seg`(总,含深监督项)与 `loss_seg_deepsup`(分项)。

**🔴 正式权重反推公式(净主项版,防分子污染)**:

```
w = 0.3 × (loss_seg − 1.0 × loss_seg_deepsup) / loss_seg_deepsup
```

(目标:深监督分项贡献 ≈ 净主项的 0.3 倍,与 lovasz 同量级;1.0=标定轮占位权重。)

改 `configs/thyroid_config_deepsup.yaml` 的 `seg_deepsup_weight` 为反推值后进正式训练。

## 三、20ep 正式训练

```bash
cd /2026aicompetition/workspace
PYTHONPATH=/2026aicompetition/workspace/pylibs nohup python -u -m scripts.train_official \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx <标注.xlsx> \
    --config /root/cloud_train_pkg/configs/thyroid_config_deepsup.yaml \
    --resume-from <ep16权重路径> \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    --seg-only --epochs 20 \
    --out checkpoints/deepsup_ep20.pth > deepsup_train.log 2>&1 &
```

**健康判据(回报这三样)**:
1. 启动横幅两行:`[seg 损失配方] ... deepsup_weight=X` 与 `[SEG-only 配方] ... deepsup_weight=X`(X=反推后的值,若还是 1.0=没改 config,停);
2. `[warm-start]` 应打"四头权重全部命中"+"深监督辅助头 4 键随机初始化(任务D 标准路径)";
3. JSONL 里 `loss_seg_deepsup` 分项恒在且量级 ≈ 0.3×净主项。

快照自动落 `deepsup_ep20_ep{4,8,12,16,20}.pth`(命名规律同 seg_only/CC)。

## 四、训后:快照批量诊断

复用 `快照批量诊断_CC.txt` 的 sh,只需把开头的快照 glob 从 `cc*_ep{N}.pth` 改成
`deepsup*_ep{N}.pth`(其余不动:基线 ep16、config 绝对路径、AICOMP_DIAG_WORKERS=4、
Δ 判据 Δ匹配≥0.012 且 ΔAP≥0.008 vs ep16)。诊断跑 workspace 树(老坑,勿在
cloud_train_pkg 下跑)。
