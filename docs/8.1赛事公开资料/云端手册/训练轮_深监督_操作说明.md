# 云端任务书:深监督辅助头 训练轮(1ep 标定 → 20ep)

> 2026-09-20。包 cloud_train_deepsup.zip 已上传,基线=ep16(线上 69.51)。
> 全程在 /root/cloud_train_pkg 树跑(与 CC 轮同一棵树,unzip -o 超集覆盖)。

## 第 0 步:部署

```bash
cd /root/cloud_train_pkg && unzip -o cloud_train_deepsup.zip
sha256sum -c SHA256SUMS.txt   # 应 6 行全 OK,报错就停
grep -n "seg_deepsup_weight" configs/thyroid_config_deepsup.yaml   # 应见 1.0(标定占位)
```

## 第 1 步:1ep 标定(dw=1.0 探针,约 35-50 分钟)

```bash
# JSONL 是追加不是覆盖,先 mv 走旧的
mkdir -p /2026aicompetition/workspace/logs/deepsup_calib_backup
mv /2026aicompetition/workspace/logs/*.jsonl /2026aicompetition/workspace/logs/deepsup_calib_backup/ 2>/dev/null

cd /root/cloud_train_pkg
PYTHONPATH=/2026aicompetition/workspace/pylibs nohup python -u scripts/train_official.py \
    --config configs/thyroid_config_deepsup.yaml \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    --resume-from checkpoints/seg_only_finetune_v2_ep16.pth \
    --seg-only \
    --epochs 1 \
    --out checkpoints/deepsup_calib_probe.pth \
    > /2026aicompetition/workspace/train_deepsup_calib.log 2>&1 &

tail -f /2026aicompetition/workspace/train_deepsup_calib.log
```

**启动横幅判据(不满足就停,回报)**:
1. `[seg 损失配方]` 行含 `deepsup_weight=1.0`(config 读到);
2. `[SEG-only 配方]` 行含 `deepsup_weight=1.0`;
3. `[warm-start]` 打"四头权重全部命中"+"深监督辅助头 4 键随机初始化(任务D 标准路径)"。

**跑完后取数(回报这两个数)**:日志目录默认 /2026aicompetition/workspace/logs,取最新 JSONL 的最后一行:
```bash
ls -t /2026aicompetition/workspace/logs/*.jsonl | head -1 | xargs tail -1 | python3 -c "
import json,sys; d=json.load(sys.stdin)
print('loss_seg =', d.get('loss_seg')); print('loss_seg_deepsup =', d.get('loss_seg_deepsup'))"
```

## 第 2 步:等本地反推权重(回报后停下)

把 loss_seg / loss_seg_deepsup 两个数发回,本地按净主项公式反推:
`w = 0.3 × (loss_seg − 1.0 × loss_seg_deepsup) / loss_seg_deepsup`
改 config 的 seg_deepsup_weight 后再发第 3 步命令。**不要自己改 config。**

## 第 3 步:20ep 正式训练(命令同第 1 步,三处不同)

```bash
cd /root/cloud_train_pkg
PYTHONPATH=/2026aicompetition/workspace/pylibs nohup python -u scripts/train_official.py \
    --config configs/thyroid_config_deepsup.yaml \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --samples-pkl /2026aicompetition/workspace/cache/samples.pkl \
    --resume-from checkpoints/seg_only_finetune_v2_ep16.pth \
    --seg-only \
    --epochs 20 \
    --out checkpoints/deepsup_ep20.pth \
    > /2026aicompetition/workspace/train_deepsup.log 2>&1 &
```

**健康判据(回报这三样)**:
1. 横幅两行 `deepsup_weight=X`(X=反推值,若还是 1.0=没改 config,停);
2. `[warm-start]` 四头全命中 + aux 4 键随机初始化;
3. JSONL 里 `loss_seg_deepsup` 分项恒在,量级 ≈ 0.3×净主项。

快照自动落 `checkpoints/deepsup_ep20_ep{4,8,12,16,20}.pth`。训完发"快照批量诊断"任务书(本地另备)。
