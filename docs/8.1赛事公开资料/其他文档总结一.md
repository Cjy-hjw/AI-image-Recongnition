📄 文档二：AI识图大赛-模型开发-创建代码库操作流程

本指南详细说明了如何在大赛的开发管理平台上创建个人代码库，并配置 Git 环境以便进行代码的克隆和管理。

🚀 操作流程

登录开发管理平台
    在云桌面打开 Chrome 浏览器，点击书签栏的 开发管理平台。
    输入用户名和密码，点击 登录。
进入代码管理
    进入工作台后，点击 代码管理。
新建代码库
    点击 新建代码库。
    选择 普通新建。
    录入代码库名称、选择公开性（如：私有）、录入代码库描述。
    点击 确定。
创建个人访问令牌
    在新建的代码库页面，点击 使用个人令牌进行克隆。
    进入个人设置页面，点击 新建访问令牌。
    录入令牌名称、过期时间。
    在权限选择中，为“代码管理”下的“代码仓库”勾选“读写”权限。
    点击 新建。
    点击复制图标复制令牌（注意：仅可见一次，要及时保存）。
配置并克隆代码库
    打开命令行工具（如 Git Bash 或命令提示符）。
    设置 Git 用户名和邮箱：
                git config --global user.name "your_name"
        git config --global user.email "your_email@example.com"
        
    执行 git clone 命令：
                git clone https://<用户名>:<个人访问令牌>@<代码库URL>
        
    根据提示输入令牌，点击 continue。
    查看输出信息，完成代码仓库克隆。

     ### **📄 文档三：AI识图大赛-模型开发-vscode连接容器操作流程**
   
     **操作流程：**
   
     1. 在云桌面打开chrome，点击书签栏：**一体化算力管理平台**。
     2. 点击“高级” -> “继续前往”。
     3. 录入用户名和登录密码，点击登录。
     4. 点击 **容器实例**。
     5. 对要连接的容器点击：**更多方式**，查看容器的ip端口、账号密码。
     6. 点击云桌面上的 **vscode** 图标，打开vscode。
     7. 点击 **远程资源管理器** 图标。
     8. 点击SSH菜单旁边的 **+** 号。
     9. 根据训推平台显示的信息填写ssh连接命令并回车。
     10. 选择其中一个配置文件进行更新。
     11. 选择密码方式验证，输入密码，点击连接。
     12. 连接成功后，点击“**打开文件夹**”，选择打开的文件夹并点击确定。
     13. 选择“**信任文件夹并继续**”。
     14. 编写代码，开发模型，执行训练脚本，查看训练日志。
     15. 完成开发训练后，在训推平台容器实例中，点击对应容器的“操作” -> **保存镜像**。
     16. 选择镜像仓库，录入镜像名称和镜像标签，点击提交。
     17. 选择镜像仓库，选中**自定义镜像仓库**，查看已保存的镜像。

     ### **📄 文档六：AI识图大赛-模型提交-创建测评容器操作流程**
   
     **操作流程：**
   
     1. 在云桌面打开chrome，点击书签栏：**一体化算力管理平台**。
     2. 点击“高级” -> “继续前往”。
     3. 录入用户名和登录密码，点击登录。
     4. 点击：**AI开发 > 容器实例**。
     5. 点击：**添加实例**。
     6. 录入容器名称，选择容器类型为**测评容器**。
     7. 选择调度规格（如果有）。
     8. 新增调度规格（如果没有合适的规格）：
        - 点击新增调度规格。
        - 录入规格名称，选择规格类型。
        - 录入CPU、GPU、内存数量，点击确定。
     9. 选择镜像来源、镜像类型、镜像。
     10. 选择pip、apt源。
     11. 点击**新建**。
     12. 查看新建容器的状态，直至状态为：**运行中**。
     13. 点击：**测评容器状态查询**。
     14. 查看测评容器状态查询结果。

     ### **📄 文档七：AI识图大赛-自带模型上传操作流程**
   
     **操作流程：**
   
     1. 打开官网，点击“登录/注册”。
     2. 输入用户名和密码，点击登录。
     3. 点击：**个人空间**。
     4. 点击“**点击上传**”，上传文件。
     5. 查看**安全扫描状态**。
     6. 在云桌面打开**赛事管理平台**，重新登录赛事管理平台。
     7. 进入个人工作台的**个人空间**。
     8. 对审核通过的模型文件进行下载。
     9. 进入 **AI资源 / 镜像仓库**，点击**镜像仓库列表**。
     10. 查看镜像仓库信息。
     11. 点击“问号”，查看推送镜像操作说明。
     12. 在弹出的推送镜像指南窗口下拉到 **Crane 推送示例**，查看crane推送镜像操作说明。
     13. 点击放大镜图标，搜索 `cmd`，点击**命令提示符**。
     14. 执行 `crane auth login` 命令登录。
     15. 执行 `crane push` 命令推送镜像到镜像仓库。
     16. 在训推平台点击：**自定义镜像仓库**。
     17. 查看已推送到训推平台的自定义镜像。
