## 一、大赛评审整体框架

### （一）五大核心评审目标

本次大赛设置五项评审目标，并划分为两大属性类别：

目标一：AI区分真人体、假人体、非人体影像

目标二：AI识别重复影像、拼接影像

目标三：AI识别肿瘤占位与非肿瘤占位

目标四：AI完成肿瘤分期、分级、病理分型等临床诊断

目标五：AI自动标注病灶关键点位，输出具备可解释性诊断依据

目标一、二归类为**医保安全属性**，设置晋级门槛，未达标不参加初赛总分排名，无晋级决赛资格。目标三、四、五归类为**临床诊断属性**，决定模型临床能力得分。

### （二）初赛门槛规则

**考核对象：**除赛道七外，其余赛道全部队伍必须完成医保安全属性**通用基础任务**考核；组委会将分赛道、分组别设置统一门槛指标（如Top-K、Recall@10%FPR、Precision@15%Recall），门槛值拟在正式推理测试前48小时统一公示，**任一指标未达门槛值视为未达标**。未达标模型不参与初赛总分排名，无晋级决赛资格，但组委会仍计算模型在各评审指标上的得分，供模型所属团队参考。

**赛道七执行规则：**赛道七无需参加评审目标一、二全部考核，总分由评审目标三、四、五的得分计算得出。

### （三）初赛完整计分规则

\1. **变量定义与取值区间**

（1）Sins

Sins：医保安全属性得分，取值范围[0,1]，为非人体影像、拼接影像、重复影像三项识别任务得分的调和平均值。

Sins = 3/(1/S_人体 + 1/S_重复 + 1/S_拼接)，Sins∈[0,1]

其中：

S_人体=非人体影像识别任务得分（评审指标：Partial AUC-PR（Recall∈[5%,50%]））

S_拼接=拼接影像识别任务得分（评审指标：Partial AUC-PR（Recall∈[5%,50%]））

S_重复=重复影像识别任务得分（评审指标：AUC-PR）

补充约束：任意一项任务得分为0时，Sins直接等于0。

（2）Sclin

Sclin：临床诊断属性得分，取值范围[0,1]，由赛道专属病灶检测、分类、分期、结构化可解释性等自动化评分项综合计算得出。

（3）Wins

Wins：医保安全属性动态权重，计算公式：

Wins = 0.2 + 0.2×(1 − Sins)

（4）Wclin

Wclin：临床诊断属性动态权重，Wclin = 1−Wins

设计逻辑：医保安全得分Sins越高，Wins越小、Wclin越大，临床诊断得分在总分中占比越高，引导模型保障影像真伪识别基础能力。

**2.** **总分计算公式（百分制，保留小数点后两位数字）**

赛道1—6、8适用：总分= Sins*Wins*100 + Sclin*Wclin*100

赛道七适用：总分 = Sclin

示例：某模型Sins = 0.8，Sclin = 0.75

1.Wins = 0.2 + 0.2 × (1 − 0.8) = 0.24

2.Wclin = 1 − 0.24 = 0.76

3.总分 = 0.8 × 0.24 × 100 + 0.75 × 0.76 × 100=76.20

**3.** **比赛排名**

同赛道同组别下，组委会根据参赛团队的总分进行排名。对于总分相同的情况，若同分队伍的模型使用同种算力（即同为国产算力或同为国外算力），组委会使用基于Min-Max归一化的相对评分法，分别计算每支队伍的推理速度得分和峰值显存占用得分，再将两者按 50% : 50% 的权重加权求和，得到模型效率综合得分，该得分高者排名靠前。若同分队伍的模型使用的为异种算力（即一个队伍使用国产算力，另外一个队伍使用国外算力），则视为受限于硬件生态，不作效率比较，直接并列排名。并列名次将占用相应名额，后续名次顺延。

### （四）模型综合能力评估（不计入初赛自动计分）

初赛第二轮推理测试增设鲁棒性、泛化能力专项评估，所有模型测试数据完整存档，仅作为决赛专家评审模型落地实用性、临床稳定性的参考依据，不参与初赛总分计算。

**1.** **鲁棒性评估**

测试集加入扰动鲁棒样本，对比模型正常样本与扰动样本推理结果，计算性能下降率，数值越高代表模型抗干扰能力越弱。

**2.** **泛化能力评估**

测试集加入训练集未覆盖样本，对比常规影像与陌生设备影像、陌生场景影像指标，评估模型跨设备、跨场景推理稳定性。

 

## 二、两层比赛任务总述

本次大赛全部任务分为通用基础任务、赛道特有临床诊断任务两层。推理结果提交要求与计分规则如下：

**1.** **提交要求**

参赛模型必须对测试集中的每一例影像（无论其预测为真实还是伪造），均输出评审目标一、二、三、四、五的全部推理结果（注：赛道七不需输出评审目标一、二的推理结果）。

**2.** **评分过滤原则**

组委会评分时，不采用模型自己预测的影像真伪类别来筛选临床诊断对象。组委会将依据测试集的金标准标签（Ground Truth），仅筛选出标签为“真实病例”的样本。

**3.** **最终计分**

提取上述真实病例样本所对应的临床诊断字段内容，与专家标注的标准诊断答案进行比对，计算目标三、四、五的得分。

（1）若某真实病例被模型误判为伪造，其预测的临床诊断结果仍参与目标三、四、五的计分。

（2）若某伪造病例被模型误判为真实，其预测的临床诊断结果不参与目标三、四、五的计分。

 

## 三、通用基础任务（对应评审目标一、二，赛道七不需参与考核）

区分测试集中真实病例影像与三类伪造影像，伪造影像定义：

（1）非人体影像：无人体解剖结构影像；

（2）拼接影像：跨患者拼接（3D影像）、跨部位套用（3D、2D影像）拼接合成影像；

（3）重复影像：在原图基础上轻微调整且与原图无临床差异的复制影像。

三类伪造影像识别均设置门槛考核指标，相关指标需全部达到赛道门槛，否则不参与初赛总分排名，无晋级决赛资格。

 

## 四、各赛道特有临床诊断任务

**全赛道通用统一评审约束：**

\1. 金标准主病灶判定标准

l 单病灶病例：唯一病灶为主病灶；

l 多病灶病例：最具临床意义的病灶定义为主病灶；

\2. 输出强制要求

所有分类、分级、分型任务，模型必须输出各类别概率分布/置信度，无概率输出对应子任务计0分。

\3. 可解释性统一划分标准

l 初赛自动化计分项：结构化标签、几何测量、定位精度等，直接计入Sclin；

l 决赛必选评审项：热力图、分割掩码、病灶框等可视化材料，初赛不计分；

l 决赛可选评审项：自然语言诊断报告，仅作为决赛加分参考，初赛不计分。

 

 

### （七）赛道七：基于超声的甲状腺癌智能检测（不需参与目标一、二相关指标考核）

依托甲状腺静态超声图、动态视频序列，以二维/三维语义分割 + 多标签分类为基础任务。本赛道病灶匹配规则：静态数据采用病灶级IoU匹配（直接基于2D掩膜文件计算IoU），动态数据采用病灶级IoU（各标注帧帧级IoU的算术平均）匹配，均使用匈牙利算法求解一对一最优匹配，IoU≥0.5判定为匹配成功。

动态数据仅标注帧（开始帧、清晰帧、结束帧）参与匹配和指标计算，未标注帧的预测不纳入评分。动态数据采用病灶级IoU匹配：对每个标注帧计算预测病灶与金标准病灶的2D IoU，若某标注帧上模型无预测（切片为空或全0），则该帧IoU记为0；所有标注帧的帧级IoU取算术平均作为病灶级IoU，不设置单帧IoU下限，仅以算术平均后的病灶级IoU进行匹配判定。

模型必须输出包含完整视频全部帧预测结果的三维NIfTI文件，文件z轴切片总数、帧顺序必须与原始输入视频完全一致；若3D掩码z轴帧数多于/少于原视频、帧时序错乱，判定为格式错误，该病例所有指标不予计分。无结节的帧（包括结节出现前和消失后的帧）可直接填充全0像素，不视为格式违规。

提交格式硬性校验：

l 所有掩码文件的尺寸（Height × Width）必须与对应的原始输入超声图像完全一致；

l MaskFiles列表中的每个文件，必须在Nodules数组中有且仅有一个结节的MaskFile字段与之对应；反之，Nodules数组中的每个结节，其MaskFile字段必须在MaskFiles列表中存在；

l 不满足上述任一条件的提交，视为格式错误，该病例所有指标不予计分，不进入评分流程。

动态数据各指标计算方式：单个结节平均Dice采用帧级平均（逐帧计算Dice取平均→病灶级Dice）；结节检测AP、良恶性AUC-PR、TI-RADS加权Kappa、侵犯分级加权Kappa、主病灶位置加权宏平均AUC、T分级AUC均采用病灶级汇总，每个预测病灶仅贡献一个样本（Kappa在全测试集一次计算）。帧维度仅用于匹配判定和Dice系列指标的计算。

主病灶说明：在金标准中，良恶性、TI-RADS分类、甲状腺外侵犯、主病灶位置、T临床显著性仅对主病灶标注，非主病灶无对应标签值，不参与分类/分期类指标计算。参赛模型无需显式区分或标记哪个预测结节对应主病灶。评估脚本将自动根据空间匹配结果（IoU≥0.5），从所有检出的结节中识别与金标准主病灶相对应的预测结节，并仅对该匹配成功的预测结节进行分类/分期指标评估。

置信度字段规范：Detection.confidence（检测置信度）、Malignancy.confidence（恶性置信度）、T_conf（T临床显著性置信度）的值域均为[0,1]。若上述字段出现字段缺失、值为NaN或Inf、类型错误（如字符串）、数值超出[0,1]范围等任一情形，评估脚本将统一将该置信度按0处理，对应样本在排序类指标（AP、AUC-PR、AUC）中排在最后。参赛模型应确保输出的置信度值合法合规。

主病灶匹配失败处理：若金标准主病灶未能与任何预测结节匹配（IoU<0.5），则该主病灶视为漏检，其属性指标（良恶性、TI-RADS、侵犯、位置、T临床显著性）不参与分类/分期指标计算（即不对该漏检病例的AUC/Kappa贡献样本），但该漏检已在结节检测AP（召回率降低）和单个结节平均Dice（未匹配结节Dice=0）中受到双重惩罚。

**1.** **识别肿瘤和非肿瘤占位（权重：60%****）**

（1）结节分割：单个结节平均Dice（评审指标：平均Dice，对所有金标准结节，匹配成功取实际Dice，未匹配取0，取平均）

（2）检测甲状腺结节（评审指标：结节检测AP，所有预测结节均参与计算，但标签由匹配结果决定）

（3）主病灶良恶性判断（评审指标：良恶性AUC-PR，仅匹配成功的主病灶）、ACR TI-RADS分类（评审指标：TI-RADS加权Kappa，仅匹配成功的主病灶）。

**2.** **识别肿瘤分期或其他诊断（恶性结节）（权重：40%****）**

（1）甲状腺外侵犯4级分级（评审指标：侵犯分级加权Kappa，仅匹配成功且为恶性的主病灶）

（2）7类病灶位置（评审指标：位置分类加权宏平均AUC，仅匹配成功的主病灶）

（3）T临床显著性：有/无（评审指标：T分级临床显著性AUC，仅匹配成功且为恶性的主病灶）。

**3.** **可解释性（决赛阶段附加评审，不计入初赛量化总分）**

（1）决赛必选：结节分割掩码、多灶标注可视化，供专家评审；

（2）决赛可选：自然语言诊断报告，供专家评审。

阴性病例（无结节）：模型输出为MaskFiles:[]和Nodules:[]，阴性病例不参与分割Dice、分类/分期类指标及Kappa计算。

l 所有检出结节均需输出T和T_conf，良性结节或T临床显著性阴性时T输出0，T_conf输出相应置信度。

 

**补充说明**

（1）置信度/概率向量要求

l 所有置信度字段（Malignancy.confidence、T_ClinSig.T_conf）取值须在[0,1]区间内。

l LocationProbs概率向量各分量之和须为1（允许微小浮点误差），各分量值须在[0,1]区间内。

（2）键名一致性

l 上表中的键名（如Malignancy.predicted、TI_RADS_Class、ExtrathyroidalExtension、Location、T_ClinSig.T等）为强制标准。

l 参赛模型必须使用完全一致的键名，大小写敏感。

（3）推理输出要求

l 模型应对所有检出的结节均输出完整的属性字段（Malignancy、TI_RADS_Class、ExtrathyroidalExtension、Location、T_ClinSig等）。评估时，仅当该结节被匹配为金标准主病灶时，其属性字段才参与分类/分期指标的计算；非主病灶的属性字段不参与评分。模型无需预先判断哪个预测结节对应主病灶，评估脚本会自动根据空间匹配结果进行筛选。金标准中甲状腺外侵犯、主病灶位置、T临床显著性分级仅对主病灶标注，评估时仅针对匹配成功的主病灶。

（4）布尔值处理

Malignancy.predicted为JSON布尔值（true/false），不是字符串。



 

### （八）赛道八：基于胸部X光的多种疾病智能检测

本赛道围绕胸部X光图像，以多类别目标检测为核心，参赛模型需输出每个病灶的边界框（DICOM坐标，单位mm）及其对应的征象类别（17类之一），实现“定位→分类→属性量化”的端到端评估。评估脚本自动执行NMS去重预处理（IoU阈值0.5），无需参赛者设计后处理策略。

NMS规则与机制说明：

评估脚本在执行匹配前，会先对模型输出的全部检测框进行非极大值抑制（NMS，IoU阈值0.5），处理规则如下：

l 同一征象类别（Finding相同）：若有多个框的IoU重叠超过0.5，仅保留置信度最高的一个，其余框直接丢弃，不参与后续匹配与评分。

l 不同征象类别（Finding不同）：即使位置完全重叠，NMS也不会抑制或丢弃，每个框分别进入各自类别的独立匹配流程。

l 专家复核：赛后专家将对模型输出的检测框可视化结果进行复核。若发现明显的投机式多框输出（如在无明确病灶区域密集输出大量不同类别框，或在明显只有单一征象的位置输出多种类别框），经专家确认后，该队伍决赛总成绩直接予以降档处理。

**1.** **识别各类征象及其占位（权重：60%****）**

输出全部病灶坐标边界框，区分17类影像征象：

（1）A类（10类局灶征象）：片状模糊、肺不张、支气管扩张、肺部肿块、肺结节、空洞、肺内钙化、胸膜增厚、胸腔积液、气胸；匹配采用面积自适应IoU阈值（小病灶<30mm²用0.30，中病灶30–300mm²用0.40，大病灶≥300mm²用0.50）。

阈值判定依据：面积自适应阈值中的面积，依据金标准（Ground Truth）框的物理面积（即标注团队提供的边界框面积）进行计算。具体规则为：金标准框面积<30mm²的病灶，匹配IoU阈值设为0.30；面积在30–300mm²之间的病灶，阈值设为0.40；面积≥300mm²的病灶，阈值设为0.50。预测框不参与阈值档位的判定，仅负责与金标准框计算IoU并与该阈值进行比较。

（2）B类（7类弥漫征象）：纤维条索影、空气支气管征、间质性改变、肺水肿、肺气肿、纵隔增宽、心影增大。匹配采用固定宽松IoU阈值0.25。

匹配策略为逐类别独立匹配（非全局匹配），按征象类别分别执行匈牙利算法，同一病灶区域多种征象可分别匹配成功。评估指标：综合平均精度（mAP，17类平均）+ 分层APs/APm/APl（对应小/中/大病灶），基于匹配结果计算。

**2.** **识别征象的其他临床属性（权重：25%****）**

核心机制：所有金标准“肺肿块”/“胸腔积液”病灶均强制纳入评估。检出且分类正确者按实测误差计分；漏诊者直接赋予最大惩罚（肿块误差计1.0，积液各级概率均设为0）。

目标四惩罚机制——两类“未正确检出”的同等处理规则：

| **场景**                       | **定义**                                                     | **惩罚方式**                         |
| ------------------------------ | ------------------------------------------------------------ | ------------------------------------ |
| 完全漏诊（无框）               | 金标准病灶区域无任何预测框覆盖（未匹配）                     | 肿块：相对误差=1.0；积液：各级概率=0 |
| 检出但分类错误（有框但标签错） | 预测框与金标准病灶区域匹配成功（IoU达标），但Finding与金标准标签不一致 | 同上，同等最大惩罚                   |

 

（1）肺肿块最大径（回归）：所有金标准“肺肿块”病灶均纳入误差计算。（评审指标：以相对绝对误差中位数为主指标，Spearman相关系数为辅指标）

Spearman相关系数样本量梯度计分规则：Spearman相关系数（ρ）用于评估模型对肺肿块最大径的排序一致性。由于小样本下秩相关系数极不稳定，本赛事采用梯度计分机制：

| **匹配成功且分类正确的“肺肿块”病灶数量** | **Spearman****得分计算方式**          |
| ---------------------------------------- | ------------------------------------- |
| ≥10                                      | 正常计分：得分 = (ρ + 1)/2            |
| 2-9                                      | 样本量不足，统一给予0.5分（随机水平） |
| <2                                       | 样本量过少，不参与总分计算            |

 

（2）胸腔积液分级（有序分类）：所有金标准“胸腔积液”病灶均纳入分级AUC计算，以加权Kappa评估分级一致性。

肺部肿块最大直径（MaxDiameter_mm）定义

本赛事金标准与模型预测统一遵循胸部DR影像临床阅片通用测量标准：

l 测量对象：仅对“肺肿块（＞3cm）”病灶进行最大径测量。

l 测量定义：最大径 = 肿块轮廓上任意两点之间可画出的最长直线距离（物理长度，单位mm），不区分边界是否规则。

l 测量范围：金标准测量包含肿块实性部分及内部空洞——即测量肿块的整体外缘轮廓，空洞区域计入肿块整体范围，不以空洞边界作为测量终点。

**3.** **可解释性（权重：15%****）**

（1）初赛自动化计分：

1)  病灶空间定位精度校验：对所有匹配成功的A类病灶计算平均IoU、对所有匹配成功的B类病灶计算平均IoU

2)  验证模型对病灶区域的定位精度：对所有匹配成功的病灶（不要求分类正确）计算平均IoU，旨在验证模型是否关注了正确的解剖区域，而非追求精确边界。

（2）决赛必选：病灶边界框可视化标注，供专家评审。
