# 赛道七_自有模型组_南师智医_参赛技术方案概要

## 一、背景情况

**1. 参赛赛道、组别、团队名称**

参赛赛道：2026 全国医保影像 AI 识图大赛 赛道七（甲状腺超声多任务诊断）；组别：自有模型组；团队名称：南师智医。

**2. 任务目标**

面向甲状腺超声影像（静态 DICOM 切片与动态 3D NIfTI 视频序列）构建多任务诊断系统，在单一常驻 HTTP 推理服务中同时完成：结节分割与检测、结节良恶性判别、TI-RADS 分级、甲状腺外侵犯（ETE）分级、病灶位置（7 类）分类与 T 临床显著性判别。按官方初赛评审口径（总分 Sclin，官方取值区间 [0,1]，本文按百分制表述），Sclin = 目标三（检出肿瘤/非肿瘤，权重 60%：单个结节平均 Dice、结节检测 AP、良恶性 AUC-PR、TI-RADS 加权 Kappa）+ 目标四（恶性结节分期，权重 40%：侵犯分级加权 Kappa、位置分类加权宏平均 AUC、T 分级临床显著性 AUC）。

**3. 主要技术难点**

（1）**多任务耦合**：分割、检测与五项分类共用同一骨干，梯度冲突与负迁移风险高；
（2）**小目标分割**：真实病灶仅占 512×512 图像的 0.1%–3%，像素级损失易被背景淹没；
（3）**类别不均衡**：ETE 4 级中血管类仅 5 例，位置 7 类与 TI-RADS 级别分布高度偏斜；
（4）**动态序列帧对齐**：官方要求 3D 输出掩码 z 轴帧数与原视频严格一致，且金标准仅标注 3–5 帧；
（5）**输出契约严苛**：所有分类、分级、分型任务必须输出概率分布/置信度，无概率输出的子任务计 0 分；置信度字段非法（缺失/NaN/Inf/越界）时官方按 0 处理、该样本在排序类指标中垫底，属静默失分，须以硬校验前置拦截。

**4. 拟解决的核心问题及预期目标**

以"检测与分割质量是 Sclin 的闸门"为核心判断（漏检主病灶导致匹配失败时五项分类指标同时失分，双重惩罚），构建"分割主线 + 多头分类 + 工程化零分防线"的端到端方案，目标在官方初赛线上测评取得 69+ 总分（百分制）并稳定交付。

## 二、数据处理方法

**1. 数据集概况**

大赛提供甲状腺超声标注数据集：样本 6,626 例（静态 5,459 / 动态 1,167，按磁盘扩展名 .dcm/.nii.gz 互斥判定）；动态病灶 339 个，主病灶掩码仅 3–5 帧非零。标注层级为 ROI 级 xlsx（合并表头在第 2 行，须 header=1 解析），含位置 7 类、侵犯 4 类等临床字段（列名含空格/全角变体，须归一化匹配）。

**2. 数据集整理及清洗方法**

（1）列名按字段名解析、禁硬编码列号；归一化（去空格、全角转半角、转小写）双轮匹配；
（2）患者级 GroupKFold 防泄漏划分（同患者多帧绝不跨 train/val）；
（3）数据更新断链处理：对 9-9 官方增补做样本级过滤打点（0.35% 缺失，超 5% 报警）；
（4）多主病灶标注修法：第二主病灶行改标为次要病灶，数据加载器天然兼容。

**3. 数据预处理方法**

（1）静态 512×512 重采样；动态全帧解码（max_frames=-1）后按标注帧定位；
（2）预抽取 PNG 缓存：若每 epoch 对每个动态样本整卷解压，累计解压耗时将达数十小时量级，预抽取至缓存后训练达 95s/epoch；
（3）ROI 支路按病灶×交集帧展开，保留原分辨率帧（bbox 在原图坐标系）。

**4. 数据增强策略**

mixup/cutmix（软 mask 同步混合、样本序不变，保证实例级权重注入正确性）；归一化统计量与训练-推理严格同源。

## 三、算法与技术方案

**（一）总体技术路线**

技术路线：DICOM/NIfTI 输入 → 扩展名分发（静/动）→ 预处理 → 双骨干前向（分类侧 EfficientNet-B2 + 分割侧 ConvNeXt-Nano，均 ImageNet 预训练）+ CBM 概念瓶颈层 → 分割头 + 五分类头 → 后处理（实例化、置信度校验）→ V2.1 契约输出（prediction.json + 逐结节 .nii.gz）→ 常驻 HTTP 服务（批量目录任务 + 健康探针）。训练侧采用 A/B/C 分阶段调度（冻结分类侧骨干温升分类头 → LLRD 解冻 → 低 lr 收尾），分割前向链（分割主干 + 解码器）全程可训。

**（二）模型架构及核心创新**

**1. 基础网络框架**

自研多任务模型：双骨干设计——分类侧 EfficientNet-B2 + 分割侧 ConvNeXt-Nano（均 ImageNet 预训练）+ U 形分割解码器 + CBM（概念瓶颈模型）+ 五个轻量分类头（良恶性、TI-RADS、ETE、位置、临床 T）。TI-RADS 头额外消费 CBM 概念特征（18 维拼接，全部 detach 防梯度串扰；可解释性为赛道不计分项，CBM 在本方案的实际用途是给 TI-RADS 头提供概念特征辅助输入）。

**2. 网络结构的创新设计与改进**

（1）**多头消费接口与梯度隔离**：四个分类头（TI-RADS/ETE/位置/临床 T）从分割侧 stage4 空间特征（352 通道）+ soft_mask detach 副本 + 尺度标量（log 通道 + clamp 防空 mask -inf）取输入，良恶性头走独立分支；梯度隔离实测精确为 0，分割主干不受分类梯度污染；
（2）**union 监督（核心创新）**：同图全部 GT 病灶掩码并集作分割监督（像素 OR 在消费端合成，与单病灶缓存物理隔离），直接对齐"IoU 匹配率"官方口径——该改进在离线判线中取得 +0.0224 匹配率/+0.0238 AP 的最大增量，为最终交付权重的主引擎；
（3）**推理输出契约工程**：动态 32 帧抽样后 scatter 回填全帧长度（合规红线）、LocationProbs 七类 softmax、置信度有限性硬校验（防 NaN 静默垫底）、阴性病例空数组输出、良性/无侵犯结节 ETE=1 兜底、逐结节掩码文件与 json 一一对应。

**3. 损失函数设计**

分割：BCE + Dice 主项 + **Lovász-Hinge（Berman et al. 2018 二值形式，权重 0.3，IoU 代理损失，直接优化官方匹配口径）**+ union 并集监督；边界加权项经标定实测为近零信号（-0.0007）后置零。分类：良恶性 BCE，TI-RADS/ETE 加权 Kappa 催化（CB-Focal β=0.9 稀有类加权经三连对拍验证为 ETE 必要条件），动态权重按有效标签数归一。

**4. 核心创新点及其预期作用**

（1）union 监督对齐官方 IoU 匹配口径（+2.2pt 匹配率）；
（2）Lovász 主导的欠分割药方（Dice+AP 双涨）；
（3）零分防线工程：概率分布完备性 + 置信值域 + 帧数契约，十次线上测评后五次连续零格式判零；
（4）期望取整后处理（分类头输出向合法整数编码收敛）带来 +0.5 总分增益。

**（三）训练、推理与后处理**

**1. 训练集划分方式**

患者级 GroupKFold（groups=PatientId），train/val 患者零交集，杜绝同患者多帧泄漏（曾实测随机划分导致 AUC 虚高 0.71 → 无泄漏真值 0.50 的教训）。

**2. 超参数设置**

A/B/C 调度：Stage A（ep1-10，冻结分类侧骨干温升分类头，相邻 epoch lr 比值 ≤5 硬约束防崩塌）→ Stage B（ep11-30，LLRD 分层解冻，backbone lr = head lr ×0.1，逐层再乘 η=0.75 衰减）→ Stage C（ep31-35，低 lr 收尾；交付方案经指标跨度分析裁至 24 epoch，其中 Stage C 5 个 epoch 指标跨度仅 0.00047 属零增益区间）。头 lr 基准 2.4e-3、batch 16、512²、bf16 混合精度、AdamW（weight decay 5e-4）。分割精调轮 20 epoch（快照 ep4/8/12/16/20 全量落盘供官方口径离线选模）。轮次谱系：基线 35 epoch → 裁至 24 → 精调 20，交付权重为 20 epoch 轮的第 16 快照。

**3. 训练平台及硬件配置**

官方云平台容器（RTX 5090 32GB / 16 vCPU / 64G 内存，pytorch 2.8.0-cuda12.8 基础镜像），训练显存峰值 8,716 MiB 恒定。

**4. 推理策略**

batch 恒 1、512² FP16 前向；动态序列全帧前向 + 置信度二值化（32 帧抽样会漏标注帧，帧级 IoU 归零，AP 全灭——实测定位后修复）；推理 worker 内存按最坏单例预算（worker=1 起步，防 OOM）。另实测过滑动窗口推理（512/stride 384，概率域 max 融合）与 TTA 翻转自集成，经离线判线口径实测均显著为负，未上线（见五（一）失败案例）。

**5. 后处理方法**

实例化（连通域分析 + 3D 稀疏存储防大例 OOM）；期望取整（分类头 argmax 向合法编码收敛）；置信度逐项值域校验（[0,1] 硬拦，宁可整例报错不交垫底输出）；掩码文件白名单（预测目录混入非法扩展整批判零的防线）。

## 四、实验与结果

**（一）主要实验结果**

**1. 评价指标**

官方初赛口径：目标三（60%）= 单结节平均 Dice、结节检测 AP、良恶性 AUC-PR、TI-RADS 加权 Kappa；目标四（40%）= ETE 加权 Kappa、位置分类加权宏平均 AUC、T 临床显著性 AUC。

**2. 官方测试集定量结果**

第 10 次线上测评（最终提交版）：**总分 69.64/100**。分项：单结节平均 Dice 9.27、结节检测 AP 9.85、良恶性 AUC-PR 16.17、TI-RADS 加权 Kappa 8.32、ETE 加权 Kappa 7.48、位置分类宏平均 AUC 9.36、T 临床显著性 AUC 9.19。官方回传为单点总分；同一权重离线复测环境零漂移（同权重重复测量 Δ=±0.0000），线上分项日间波动在 ±0.04 内。

**3. 与基线方法的比较**

官方未提供公开基线方法，以自身迭代为基线。十次线上跑分演进链：前 5 次因部署环境与输出契约问题整批零分（根因逐一破案修复）→ 61.89 → 68.30 → 68.80（期望取整 +0.50）→ 69.51（分割精调：Lovász 0.3 + 快照离线选模，Dice+0.51/AP+0.36）→ **69.64（union 监督换权重：AP+0.16，分类三项变化在 ±0.03 噪声带内、TI-RADS 逐位不变）**。离线判线与线上增益方向一致（离线增益在线上兑现的比例约 0.3）。

**4. 关键指标统计分析**

union 监督离线判线（快照 ep16 vs 单病灶监督基线 0.8478/0.8250）：静态匹配率 0.8702（同权重重复测量 Δ=±0.0000，环境零漂移）、静态 AP 0.8488，Δ 分别 +0.0224/+0.0238；多组对照（CC-DiceCE、深监督、悬崖加权、ROI 支路、640 分辨率、滑动窗口、TTA 等）经预注册判死线逐一量化裁决，负增益路线零上线，历次线上增益均为正。

**（二）典型病例可视化分析**

三类典型病例的定性表现：（1）**静态大结节真阳**：典型良性结节病例中预测掩码与金标准轮廓重合度高（IoU>0.75），匹配成功后良恶性置信度稳定输出（confidence 约 0.8-0.95 档）；（2）**动态序列**：3D 输出掩码 z 轴与原视频帧数严格一致，标注帧上分割掩码与金标准帧级对齐，非标注帧全零合规输出；（3）**失败模式（欠分割漏检）**：小病灶（<262 像素）病例中预测掩码小于金标准导致帧级 IoU<0.5 判匹配失败——这正是将 Lovász（IoU 代理损失）置于损失主力的动因，修复后该类病例匹配率显著回升。完整对比图（影像+金标准+预测三联图）见随文档提交的可视化附图。

## 五、讨论与结论

**（一）方法优势、局限性及失败案例**

**优势**：分割-检测-分类单服务闭环，输出契约完备（十次测评、后五次零格式判零）；预注册判死线 + 环境一致性对照的实验纪律使每轮换权重决策有据；零分防线工程完备。

**局限性**：（1）良恶性 AUC-PR 得分率约 90%（按满分 18 反推），接近上限；（2）ETE 血管类仅 5 例，该级别召回受数据量物理约束；（3）动态池仅 4.7% 病例占比，时序建模算术上不成立，未引入视频级时序模型。

**失败案例**：（1）ROI（感兴趣区域）双支路架构（病灶级裁剪 + 独立 ROI 头，λ=0.0436 量级配比标定）经 20 epoch 判线全负（最优快照 Δ匹配率 -0.0139）——ROI 支路稀释整图分割的梯度与步数，且 ROI 头自身指标（loc AUC 0.55 / ETE Kappa 0.004）未学出有效能力，判死回退；（2）滑动窗口推理与 TTA 翻转自集成分别实测 -0.94 量级与显著负增益，判死；（3）640 分辨率提升假设经对照实验证伪（512 为甜点位；训练侧单变量实验累计 0 胜 5 负收敛）；（4）悬崖加权（困难样本主项×4）五快照全过晋级线但增量约 0，头对头让位 union 监督。

**（二）核心贡献与应用展望**

**核心贡献**：（1）union 监督对齐官方 IoU 匹配口径的分割监督方法（+2.2pt 匹配率实测）；（2）多任务单服务输出契约工程化范式（前 5 次零分根因全部破案闭环、后 5 次零格式判零交付）；（3）预注册判死线 + 环境一致性对照的实验纪律（每一步增益可归因）。

**意义**：69.64 的分项结构显示 Dice（9.27/15，得分率约 62%）与 AP（9.85/15，约 66%）仍相对最低（按内部满分反推口径，非官方公布），检测侧仍有余量但进入收益递减段（+0.71 → +0.13）。

**未来改进方向（均为拟验证路径，非承诺）**：（1）实例级判别头（掩膜连通域回灌四头）的低成本验证；（2）外部公开数据（ThyroidXL 11,635 幅）预训练底座迁移（与现有架构兼容前提下）；（3）稀有类（ETE 血管）的针对性采样（在加权 Kappa 口径下先验证再上线）。
