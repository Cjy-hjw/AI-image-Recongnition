# 甲状腺超声多任务诊断系统_自有模型组_参赛技术方案概要

## 一、背景情况

**1. 参赛赛道、组别、团队名称**

参赛赛道：2026 全国医保影像 AI 识图大赛 赛道七（甲状腺超声多任务诊断）；组别：自有模型组。

**2. 任务目标**

面向甲状腺超声影像（静态 DICOM 切片与动态 3D NIfTI 视频序列）构建多任务诊断系统，在单一常驻 HTTP 推理服务中同时完成：结节分割与检测、结节良恶性判别、TI-RADS 分级、甲状腺外侵犯（ETE）分级、病灶位置（7 类）分类与 T 临床显著性判别。按官方初赛评审口径，总分 Sclin = 目标三（检出肿瘤/非肿瘤，权重 60%：单个结节平均 Dice、结节检测 AP、良恶性 AUC-PR、TI-RADS 加权 Kappa）+ 目标四（恶性结节分期，权重 40%：侵犯分级加权 Kappa、位置加权宏平均 AUC、T 分级临床显著性 AUC）。

**3. 主要技术难点**

（1）**多任务耦合**：分割、检测与五项分类共用同一骨干，梯度冲突与负迁移风险高；
（2）**小目标分割**：真实病灶仅占 512×512 图像的 0.1%–3%，像素级损失易被背景淹没；
（3）**类别不均衡**：ETE 4 级中血管类仅 5 例，位置 7 类与 TI-RADS 级别分布高度偏斜；
（4）**动态序列帧对齐**：官方要求 3D 输出掩码 z 轴帧数与原视频严格一致，且金标准仅标注 3–5 帧；
（5）**输出契约严苛**：所有分类任务必须输出合法概率分布，任一字段越界即整项计零。

**4. 拟解决的核心问题及预期目标**

以"检测与分割质量是 Sclin 的闸门"为核心判断（漏检主病灶导致匹配失败时五项分类指标同时失分，双重惩罚），构建"分割主线 + 多头分类 + 工程化零分防线"的端到端方案，目标在官方初赛线上测评取得 69+ 总分（百分制）并稳定交付。

## 二、数据处理方法

**1. 数据集概况**

大赛提供甲状腺超声标注数据集：样本 6,626 例（静态 5,459 / 动态 1,167，按磁盘扩展名 .dcm/.nii.gz 互斥判定）；动态病灶 339 个，主病灶掩码仅 3–5 帧非零。标注层级为 ROI 级 xlsx（合并表头在第 2 行，须 header=1 解析），含位置 7 类、侵犯 4 类等临床字段（列名含空格/全角变体，须归一化匹配）。

**2. 数据集整理及清洗方法**

（1）列名按字段名解析、禁硬编码列号；归一化（去空格、全角转半角、转小写）双轮匹配；
（2）患者级 GroupKFold 防泄漏划分（同患者多帧绝不跨 train/val）；
（3）数据更新断链处理：对 9-9 官方增补做样本级过滤打点（0.35% 缺失，超 5% 报警）；
（4）多主病灶 xlsx 修法：第二 M 行改病灶 N，loader 天然兼容。

**3. 数据预处理方法**

（1）静态 512×512 重采样；动态全帧解码（max_frames=-1）后按标注帧定位；
（2）预抽取 PNG 缓存：动态整卷解压耗时 24h 级，预抽取至缓存使训练达 95s/epoch（35 epoch 约 55 min）；
（3）ROI 支路按病灶×交集帧展开，保留原分辨率帧（bbox 在原图坐标系）。

**4. 数据增强策略**

mixup/cutmix（软 mask 同步混合、样本序不变，保证实例级权重注入正确性）；归一化统计量与训练-推理严格同源。

## 三、算法与技术方案

**（一）总体技术路线**

技术路线：DICOM/NIfTI 输入 → 扩展名分发（静/动）→ 预处理 → 共享骨干前向（分割主干 + CBM 概念瓶颈层）→ 分割头 + 五分类头 → 后处理（实例化、置信度校验）→ V2.1 契约输出（prediction.json + 逐结节 .nii.gz）→ 常驻服务（uvicorn:8000，/call 批量 + /health 探针）。训练侧采用 A/B/C 分阶段调度（冻主干温升三头 → LLRD 解冻 → 校准），全程分割可训。

**（二）模型架构及核心创新**

**1. 基础网络框架**

自研多任务模型：ConvNeXt-Nano/高效骨干（ImageNet 预训练）+ U 形分割解码器 + CBM（概念瓶颈模型，五概念 logits 显式可解释通路）+ 五个轻量分类头（良恶性、TI-RADS、ETE、位置、临床 T）。TI-RADS 头额外消费 CBM 概念特征（18 维拼接，全部 detach 防梯度串扰）。

**2. 网络结构的创新设计与改进**

（1）**三头消费接口设计**：分类头从分割侧 stage4 空间特征（352 通道）+ soft_mask detach 副本 + 尺度标量（log 通道 + clamp 防空 mask -inf）取输入，梯度隔离实测精确为 0，分割主干不受分类梯度污染；
（2）**union 监督（L2 线，核心创新）**：同图全部 GT 病灶掩码并集作分割监督（像素 OR 在消费端合成，与单病灶缓存物理隔离），直接对齐"IoU 匹配率"官方口径——该改进在判线中取得 +0.0224 匹配率/+0.0238 AP 的最大增量，为最终交付权重的主引擎；
（3）**推理输出契约工程**：动态 32 帧抽样后 scatter 回填全帧长度（合规红线）、LocationProbs 七类 softmax、置信度 _assert_finite 硬拦（防 NaN 静默垫底）、逐结节掩码文件与 json 一一对应。

**3. 损失函数设计**

分割：BCE + Dice 主项 + **Lovász-Softmax（权重 0.3，IoU 代理损失，直接优化官方匹配口径）**+ union 并集监督；边界加权项经对照实验后置零（距离场内部恒正项反而奖励概率集中）。分类：良恶性 BCE，TI-RADS/ETE 加权 Kappa 催化（CB-Focal β=0.9 稀有类加权经三连对拍验证为 ETE 必要条件），动态权重按有效标签数归一。

**4. 核心创新点及其预期作用**

（1）union 监督对齐官方 IoU 匹配口径（+2.2pt 匹配率）；
（2）Lovász 主导的欠分割药方（Dice+AP 双涨）；
（3）零分防线工程：概率分布完备性 + 置信值域 + 帧数契约，六次线上跑分零格式事故；
（4）期望取整后处理（四头输出向合法整数编码收敛）带来 +0.5 总分增益。

**（三）训练、推理与后处理**

**1. 训练集划分方式**

患者级 GroupKFold（groups=PatientId），train/val 患者零交集，杜绝同患者多帧泄漏（曾实测随机划分导致 AUC 虚高 0.71 → 无泄漏真值 0.50 的教训）。

**2. 超参数设置**

A/B/C 调度：Stage A（ep1-10，冻结主干温升三头，相邻 epoch lr 比值 ≤5 硬约束防 Stage2 崩塌）→ Stage B（ep11-30，LLRD 解冻 backbone，分层 lr 缩放 0.1）→ Stage C（ep31+，校准）；batch 16、512²、bf16 混合精度、AdamW、训练轮数 24（经 composite 跨度分析砍掉尾部 5 个零增益 epoch，省 31%）；seg-only 精调轮 20 epoch（快照 ep4/8/12/16/20 全量落盘供官方口径判线选模）。

**3. 训练平台及硬件配置**

官方云平台容器（RTX 5090 32GB / 16 vCPU / 64G 内存，pytorch 2.8.0-cuda12.8 基础镜像），训练显存峰值 8.7GB 恒定。

**4. 推理策略**

batch 恒 1、512² FP16 前向；动态序列全帧前向 + conf 二值化（32 帧抽样会漏标注帧，帧级 IoU 归零，AP 全灭——实测定位后修复）；推理 worker 内存按最坏单例预算（worker=1 起步，防 OOM）。

**5. 后处理方法**

实例化（连通域分析 + 3D 稀疏存储防大例 OOM）；期望取整（分类头 argmax 向合法编码收敛）；conf 逐项值域校验（[0,1] 硬拦，宁可整例报错不交垫底输出）；掩码文件白名单（预测目录混入非法扩展整批判零的防线）。

## 四、实验与结果

**1. 评价指标**

官方初赛口径：目标三（60%）= 单结节平均 Dice、结节检测 AP、良恶性 AUC-PR、TI-RADS 加权 Kappa；目标四（40%）= ETE 加权 Kappa、位置加权宏平均 AUC、T 临床显著性 AUC。

**2. 官方测试集定量结果**

第 10 次线上测评（最终提交版）：**总分 69.64/100**。分项：单结节平均 Dice 9.27、结节检测 AP 9.85、良恶性 AUC-PR 16.17、TI-RADS 加权 Kappa 8.32、ETE 加权 Kappa 7.48、位置宏 AUC 9.36、T 临床显著性 AUC 9.19。

**3. 与基线方法的比较**

十次线上跑分演进链：5 次零分连环（环境/格式事故逐一破案修复）→ 61.89 → 68.30 → 68.80 → 69.51（seg-only 精调：Lovász 0.3 + 快照判线选模，Dice+0.51/AP+0.36）→ **69.64（union 监督换权重：AP+0.16，分类三项逐位稳定）**。本地诊断与线上增益方向一致（本地→线上传递比例约 0.3）。

**4. 关键指标统计分析**

union 监督判线（快照 ep16 vs 单病灶监督基线）：静态匹配率 0.8702±0.0000（哨兵复测逐位一致）、静态 AP 0.8488，Δ 分别 +0.0224/+0.0238；多组对照（CC-DiceCE、深监督、悬崖加权、ROI 支路、640 分辨率、TTA 等）经预注册判死线逐一量化淘汰，负增益路线零上线，保证每一步线上增益均为正。

## 五、讨论与结论

**（一）方法优势、局限性及失败案例**

**优势**：分割-检测-分类单服务闭环，输出契约零事故（十次测评无格式判零）；判线纪律（预注册判死线 + 哨兵环境校验）保证每轮换权重决策有据；零分防线工程完备。

**局限性**：（1）良恶性 AUC-PR 已达 90% 得分率，接近上限；（2）ETE 血管类仅 5 例，该级别召回受数据量物理约束；（3）动态池仅 4.7% 病例占比，时序建模算术上不成立，未引入视频级时序模型。

**失败案例**：（1）ROI（感兴趣区域）双支路架构（病灶级裁剪 + 独立 ROI 头，λ=0.0436 量级配比标定）经 20 epoch 判线全负（最优快照 Δ匹配率 -0.0139）——ROI 相位稀释整图梯度，且 ROI 头四项指标（loc AUC 0.55 / ETE Kappa 0.004）未学出有效能力，判死回退；（2）640 分辨率提升假设 0 胜 5 负证伪（512 为甜点位）；（3）TTA 翻转自集成 -0.94 判死。

**（二）核心贡献与应用展望**

**核心贡献**：（1）union 监督对齐官方 IoU 匹配口径的分割监督方法（+2.2pt 匹配率实锤）；（2）多任务单服务输出契约工程化范式（六次零分事故全破案、零格式事故交付）；（3）预注册判线 + 哨兵校验的实验纪律（每一步增益可归因）。

**意义**：69.64 的分项结构显示 Dice（58% 得分率）与 AP（63%）仍是最低两项，检测矿仍有余量但进入收益递减段（+0.71 → +0.13）。

**未来改进方向**：（1）实例级判别头（YOLO-seg 式掩膜 CCL 回灌四头）的低成本验证路径；（2）外部公开数据（ThyroidXL 11,635 幅）预训练底座迁移；（3）稀有类（ETE 血管）的针对性采样与合成。
