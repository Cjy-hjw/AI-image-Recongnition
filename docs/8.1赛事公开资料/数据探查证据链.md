## 第1轮·字段与格式初探（回答.md）

- 标注 xlsx 共 16 个业务列（实际文件 74 列）：PatientId / AccessionNumber / SeriesUid / DetailDescription / RoiName / RoiVolume / RoiVoxelCount / RoiHU(Max/Min/Avg/Std) / STUDY备注7类 / 良恶性3类 / TI-RADS5类 / cancer_label2类 / patho_histology5类 / extrathy_ext6类 / lesion_loc9类 / clin_t_stage2类。
- 主病灶标法：RoiName 列值为 "M" 即主病灶；非主病灶为 "病灶1"、"病灶2" 等。
- Mask 格式：静态=2D、动态=3D（带 z 帧序列），像素 0/1 二值，.nii.gz。
- 训练集共 5401 个样本目录；命名格式 `M_1_mask.nii.gz`（主）、`病灶1_1_mask.nii.gz`（次）。
- 数据目录中**未找到任何评分细则文档**（无 metric/evaluation/score/评分/Dice 关键词）；datasets 下仅有 training/、evaluation_first/、evaluation_second/、evaluation_finals/、verification/，evaluation_* 为空或不含评分规则。

## 第2轮·静动态区分与规则验证（回答2.md）

- 实际读取 Excel（ROI级别 sheet，7920 行，74 列）核实字段：`extrathy_ext` 用 "1无/2甲状腺包膜/3毗邻软组织/4血管" 编码，阴性写 "1无"；病理缺失类叫 "非肿瘤性"（160 个）。
- **静动态严格对应**：`.dcm`=静态图、`.nii.gz`=动态图，5401 样本无例外。静态约 4680 个、动态约 721 个。
- 字段计数：RoiName（Col30）M=4877、病灶1=471、病灶2=290、病灶3-11=423、清晰帧1-3=350、开始/结束=442；良恶性 良2687/恶2584/无10；ETE（Col60）1无3906/2包膜267/3软组织67/4血管5；位置（Col61）左中1058/右中1179/右下620/左下531/右上395/左上389/峡部86；临床T（Col62）0无2410/1有1831；病理（Col59）0无1027/1非肿瘤性160/2良性1062/3交界7/4恶性2011；cancer（Col57）0阴性2112/1阳性2159。
- **规则验证（"恶性且(直径>1cm或ETE>=2)=T有"）**：对 4882 个主病灶，整体吻合率仅 **68.19%**（3329/4882），漏报率 **85.56%**（1493/1745 被漏），阳性命中 80.77%。**规则不能作为 T 分期替代**。
- **动态 Mask 帧数**：Mask z 维 = 视频总帧数（文件尺寸对齐），但仅少数帧有标注（>0），如 344 帧只 5 帧有标注、209 帧只 3 帧。评估脚本若要求全帧预测，模型只输出标注帧将导致 0 分风险。

## 第3轮·T分期驱动/动态标注位置/新维度分布（回答3.md）

- **T 有驱动因素**：T 有 1745(35.7%)/T 无 2410(64.3%)。T 有中 N 有占比 43.7%、M 有 9.4%；恶性子集 2405 个中 T 有且 ETE=无 1485 个（85.1%），其中 N 有 742(49.9%)/N 无 743(50.1%)。结论：N 分期是重要驱动**但不是唯一**，T 由多因素综合，不能仅靠体积+ETE 规则。
- **动态图标注位置**：与静态图**同表（ROI级别）**，无单独表。RoiName 含"清晰帧1"(221)/清晰帧2(111)/清晰帧3(18)、开始/结束(各221)。清晰帧**无 ROI 体积、无临床信息**，只含 pointAnnotate 坐标（Col 46 "x, y"）。
- **新维度分布**：Col 57-64 不仅 M 行有，非 M 行（1716）也有约 13% 数据率（如病理 228、ETE 227、位置 228、T 226）。**训练不能只回传 M 行损失**，应检查临床列是否为空：空则 skip、有值则参与训练（masked loss）。

## 第4轮·目录命名/.dcm属性/推理输入/清晰帧帧号（回答4.md）

- **目录命名初判**：一级目录名（32位 MD5）与 PatientId（34位）及 StudyUid 长度不匹配，初判"内部/检查哈希 ID"（**后被第5轮推翻**，见裁决）。
- **.dcm 属性**（实测 19 个）：全 MONOCHROME2 灰度、单帧（NumberOfFrames=1）、无 JPEG 压缩（原始）、BitsAllocated=16、分辨率多样（576×765/984×1280/819×1456 等）、大小 348KB~1.26MB。**.dcm 非视频，每文件单帧静态图**。
- **推理输入（verification/original）**：3 层嵌套，顶目录 32 位哈希→2 级 DICOM UID→dcm/nii.gz 文件。统计：915 目录、988 个 .dcm、58 个 .nii.gz，确有静态+动态混合，靠扩展名区分。
- **清晰帧帧号**：Excel 无明确 Frame Index 列，Col 45（=142）疑似帧号但未确证（**后被第6轮裁决非帧号**），Col 46 为坐标。

## 第5轮·目录名关联字段确认 + .dcm 像素范围（回答5.md）

- **裁决**：目录名 `9442b50b...` 匹配 Excel **检查级别 sheet Col1（PatientId）**（Row 3046），不匹配 StudyUid。结论：**目录名 = PatientId**（32 位 MD5），同一 PatientId 可有多个 StudyUid。→ 推翻第4轮"不匹配 PatientId"的初判。
- **.dcm 像素范围**（实测 48 个文件）：**uint8，Min=0，Max=254-255（1 个为 234），无负值**，RescaleSlope=1/Intercept=0，即 0~255 灰度（非 DICOM HU 标准格式）。分辨率多样，Mean 13.7~71.1。

## 第6轮·三表关联键 + 清晰帧 Col45 裁决（回答6.md）

- **三表关联键**：**PatientId（Col1）是三张表（检查/序列/ROI级别）的共同关联键**。ROI级别**没有 SeriesUid 列**（Col29 实为 RoiUid，Col8/Col29 值与 Col1 相同）。序列级别 Col14（SeriesLabel）大部分为空。
- **清晰帧 Col45 裁决**：Col45=142 ≠ 视频总帧数 215（样本 nii.gz shape 1442×802×215），**Col45 不是帧号**，推断为坐标索引或点标注 ID；Col46 才是坐标。→ 推翻第4轮"可能帧号"的疑虑。

## 第7轮·PatientId 多目录 + Col15 对齐风险（回答7.md）

- **一个 PatientId 对应多个检查/序列目录**（抽样 50：1:1 映射 68%、1:2 映射 32%）。总 PatientId 5400、总目录 5401。
- **ROI级别通过 Col15（SeriesUid）区分归属**，值格式 `1.2.826.0.1.3680043.8.498...`。
- **严重问题初判**：Col15 值不匹配磁盘子目录名、不匹配检查级别 Col8、不匹配序列级别 Col14 —— 担心训练对齐错位（**后被第8轮修正**：实为用错了对照字段）。
- 训练建议初稿：解析 .dcm 的 StudyInstanceUID 反查对齐，不能直接用 PatientId/Col8 关联（**第8轮修正后用 SeriesInstanceUID**）。

## 第8轮·Col15 真身 + 动态图关联方式（回答8.md）

- **裁决（关键）**：ROI级别 **Col15 = SeriesInstanceUID**（DICOM 标签），静态图二级子目录名 = SeriesInstanceUID，二者 100% 匹配（2/2 样本）。**StudyInstanceUID = PatientId**（34 位 MD5），不是 Col15。→ 修正第7轮"Col15 不匹配子目录"的误判：是"Col15 匹配 SeriesInstanceUID 而非此前对照的 StudyUid/PatientId"。
- **动态图关联**：通过 **PatientId 直接关联**——子目录名=PatientId（同名嵌套）、文件名=PatientId.nii.gz，无 DICOM 头、无 Series 概念，Col15 不适用（3/3 子目录=PatientId，Col15=子目录 0/2）。
- **最终关联策略**：静态图用 SeriesUID 匹配（`子目录==Col15`，可 DICOM 标签断言）；动态图用 PatientId 直接定位（`{pid}/{pid}/{pid}.nii.gz`）。

## 第10轮·全量统计审查（全量统计审查结果.md）

**基于磁盘全量扫描 5401 个 PatientId 目录**（本次 Excel 标注文件不可用，Q3-Q6 用前序推断+验证代码）：

- **Q1 动态是否 1 对多**：否 ✅。每个动态 PatientId 严格对应 1 个 .nii.gz，患者=序列一对一，1 对多=0 个。
- **Q2 静动态是否混合**：否 ✅，**完全互斥**。仅静态 5057（93.6%）、仅动态 343（6.4%）、混合 0。
- **Q3 Col15 命中子目录**：推断静态图 100% 匹配（SeriesUID=子目录）、动态不适用；需 Excel 验证。
- **Q4 静动态区分列**：推断为"图像性质"列（1静/2动），需 Excel 验证。
- **Q5 无标注目录数**：推断存在少量；磁盘 5401 目录 vs Excel 检查级别 5401 行，需对比验证。
- **Q6 SliceIndex 字段**：官方提到记帧号、从 1 起；ROI表 Col45 已排除，可能在序列/ROI级别其他列，需全文搜索。
- **补充全量**：静态图二级目录全部为 SeriesInstanceUID 模式（6361 个子目录，平均 1.26/PatientId），无 PatientId 模式子目录。
