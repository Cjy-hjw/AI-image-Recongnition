## 2. 系统总体架构

总体数据流如下(离线单容器内完成):

```mermaid
flowchart TD
    A[输入 JPG<br/>静态图/动态帧] --> G{Gatekeeper 闸门}
    subgraph G [Gatekeeper 四层闸门 · 防御性工程(2026-07-28豁免,不参与初赛计分)]
        G1[① 真实性<br/>ELA+GLCM+频域→MLP<br/>真/体模/合成 三分类]
        G2[② 重复检测<br/>dHash + ResNet 余弦]
        G3[② 拼接/篡改<br/>copy-move + 直线缝几何 + CAT-Net DCT/BAG]
        G1 --> G2 --> G3
    end
    G -->|REJECTED| R[拒绝 JSON<br/>+ 原因 + bbox<br/>*仅 enforcement_mode=hard 时可达*]
    G -->|PASS 或 soft-flag| B
    subgraph B [异构双主干 · 输入端完全解耦]
        B1[ConvNeXt-Nano<br/>分割主干 · 7×7 大核抗散斑]
        B2[EfficientNet-B2<br/>分类主干 · 全局语义]
    end
    B1 -->|分割 mask| S[结节定位/关键点]
    B1 -.detached 特征.-> TAA[TaskAlignmentAdaptor<br/>单向跨层空间软门控]
    TAA --> B2
    B2 --> CBM[ConceptEmbedding CBM 头<br/>5×TI-RADS 概念瓶颈]
    CBM --> MAL[良恶性 logits]
    CBM --> REP[报告生成器<br/>结构化结论 + Grad-CAM]
    S --> REP
    MAL --> REP
```

文字描述:输入(JPG 静态/动态帧)→ **gatekeeper 四层闸门**(真实性→重复→拼接/篡改)→ 通过后进入 **双主干**(ConvNeXt-Nano 分割 + EfficientNet-B2 分类)→ **TaskAlignmentAdaptor** 单向跨层空间对齐 → **CBM 概念头**输出 5 维 TI-RADS 概念 + 良恶性 → **报告生成器**输出可解释结论 + Grad-CAM。

> **闸门执行策略(2026-07-29)**:赛道七豁免医保安全考核后,gatekeeper 默认运行在 `enforcement_mode: soft` ——审计照跑、结论照写进 `result.json` 的 `gatekeeper` 字段,但**不中断诊断输出**(误拒一次即白丢该病例全部临床得分,而审计本身零计分)。上图 REJECTED 分支仅在显式配置 `hard` 时可达。

> **概率输出(2026-07-29)**:所有分类/分级/分型头均输出**完整概率分布**(`concept_probabilities`/`malignancy_probabilities`),对应官方"必须输出功率分布或置信度否则计0分"的硬约束。

- 关键设计原则:**完全解耦双主干**消除分割/分类的表征竞争(详见 §5.1 论证);任务对齐**单向**(分割→分类,且分割特征 `detach`),防止分类梯度回流污染分割主干。
- 部署形态:离线推理容器(`predict.py` 单图 + `video_predict.py` 动态图,`entrypoint.sh` 按输入扩展名自动分发并对两入口 + `thyroidxl_merged_v2.pth` 做 SHA-256 校验),无外网依赖,契合"比赛期间不联网"约束。

## 4. 基础项工程实现(防御性投入,不参与初赛计分,简述)

> 赛道七豁免此二项考核(2026-07-28)，以下简述工程实现以体现完整性，报告篇幅重点见 §5。

### 4.1 真实性识别:真人体 / 假人体 / 非人体
- 方法:`authenticity.py` 传统CV(ELA + GLCM + 频域)特征 + MLP 分类。
- 合成数据引擎:`gatekeeper/synthesis.py` 生成假/非人体样本用于训练(等官方真假样本到位后微调/校准)。
- `[待数据]` 官方真假标注 → 升级/验证为达标方案;报告需给出三分类指标与失败样本分析。

### 4.2 规范性审核:重复 / 拼接
- 重复检测:`deduplication.py` 特征哈希(dHash)+ ResNet 余弦近重复召回(二级兜底)。
- 拼接/篡改:`tampering.py` + `tampering_catnet.py`。**copy-move** 用稠密块匹配(特征 = 块均值/标准差 + 4×4 降采样,空间隔离 + 簇过滤,干净图零误报);**splicing(硬粘贴)** 经两轮迭代后定为**几何缝判据**——放弃像素/区域方差方案(超声结节本身即局部方差异常区,实测干净图 20/20 误报,触碰一票否决红线),改抓硬粘贴矩形特有的「轴对齐长直缝 + 角点正交相交」特征。实测干净图误报 **0/80**(红线达标),真实组织拼接召回 **~84%**。**splicing(羽化/泊松融合)** 用 **CAT-Net v2 风格 DCT/BAG 取证**(Apache-2.0 可商用):追踪 JPEG 8×8 块伪影栅格(BAG)主导相位,滑窗定位相位错位区——来自另一 JPEG 的错位粘贴即使 RGB 边界被融合得看不见,仍会破坏全图一致的块栅格,补几何缝检测抓不到的「无长直阶跃」盲区。守红线三重设计:全图无栅格弃权、`grid_strength` 绝对能量地板防分母塌缩、局部相位换算回全图坐标系。可插拔降级:深度 HRNet 权重存在则启用,缺失则纯 NumPy/cv2 BAG 取证,零破坏既有检测器。
- `[待数据]` 官方重复/拼接标注 → 标定阈值、补召回/误报曲线。

## 5. 核心算法

### 5.1 病灶识别:异构双主干 + 任务对齐
- **问题**:单主干晚期分叉导致分割(密集预测,要空间细节)与分类(全局语义)的**梯度角度冲突**,锁死 AUC。
- **方案**:输入端即解耦 ConvNeXt-Nano(分割,7×7 大核抗散斑)+ EfficientNet-B2(分类);**TaskAlignmentAdaptor** 用 detached 分割特征作软注意力门控,单向注入分类分支(Stage3/4)。
- 论据见 `reference/` 下双主干解耦相关调研报告(数学推导 + 选型对比；具体文件名待核实补全，原引用路径已失效)。
- `[待数据]` 良恶性 AUC-PR(评审规则确认指标为 AUC-PR，非 AUC)、分割 Dice(校准后真实基准)。

### 5.2 辅助诊断:概念瓶颈(CBM)
- 5 维 ACR TI-RADS 概念(composition/echogenicity/shape/margin/foci)经概念瓶颈预测,再聚合到良恶性 → **可解释、可干预**。
- 当前概念为 mask 形态学弱监督伪标签;`[待数据]` 若官方带 TI-RADS 概念标注则转监督训练。

### 5.3 判读效率:关键点 + 可解释报告
- 分割 mask → 结节定位/关键点;CBM 概念 + Grad-CAM(双主干分支)→ 结构化诊断报告。
- Grad-CAM 已接入 `predict.py --enable_gradcam`:对 `cls_backbone`(EfficientNet-B2)末层求恶性激活热图,叠加原图输出 `gradcam_cls.png`,`result.json` 置 `gradcam_generated:1`。端到端梯度路径有回归测试守卫。

## 6. 训练方法与正确性保障

- **三阶段渐进训练**:Stage1 分割+概念预热 → Stage2 全量 → Stage3 主干冻结、AUC 精调。🔴 **新增官方四头(2026-08-10 规划/08-13 落地,含 backlog #124 补的 TI-RADS 头)**:位置(7 类)/ETE(4 级)/T 临床显著性/TI-RADS(5 类)四个头,走独立 A/B/C 调度(`src/training/schedule_official.py`,相邻 epoch lr 比值 ≤5),由 `scripts/train_official.py` 入口在官方数据上以 warm-start 训练;四头复用 CBM「边缘 Margin」、归一化等效直径等既有特征,不新建大子网络。⚠️ 混训 checkpoint 已证跨域分割能力(ThyroidXL 15%→87%),但**概念/分类分支在其上零监督,禁止用于输出概念概率/CBM 报告**(`docs/训练与架构/三头实现记录.md` §6)。
- **5 通道 FAMO** 动态损失加权(独立通道防梯度相消);**Masked 多任务损失**(缺标签样本零梯度污染,适配官方部分标注)。四头走固定 λ 外挂、不进 FAMO。
- **续训态持久化**:`training_state.pth` 存 FAMO 权重 + AUCM 对偶参数 + lambda_latent,与 best_model 配对,支持中断恢复。
- **质量门**:`verify_model.py` 8-Gate(形状/vCLUB梯度隔离/数值安全/优化器绑定/BatchNorm 冻结/Stage 掩码/LR 对齐/TaskAlignmentAdaptor cls→seg梯度隔离)+ reviewer 审查 + 回归测试全绿(测试总数随环境/新增头浮动，最新数字见 `tests/AGENTS.md`，不在此处写死快照数字) → 体现"模型质量可靠性"。四头本身的逐头单测 + 官方 loader 合成数据单测见 `tests/test_*_head.py`/`tests/test_official_loader.py`。

## 8. 数据异质性与真实世界鲁棒性(专家评审重点)

基层超声设备异构、增益不一、散斑噪声、声影伪影。我们以**超声物理先验**为指导设计 7 种领域专用增强(`dataset/augmentation/transforms.py`),而非套用自然图像 transform;ConvNeXt 7×7 大核本身亦是天然低通,对散斑稳健。

| 增强 | 物理对应 | 关键参数 | 概率 |
|:---|:---|:---|:---|
| RandomAffine | 探头位姿/视野变化 | ±15° 旋转 / ±10% 平移 / 0.95–1.05 缩放 | 0.5 |
| RandomElasticDeformation | 探头压力致软组织形变 | alpha=150, sigma=15(cv2.remap) | 0.3 |
| RandomSpeckleNoise | 乘性散斑/增益噪声 `I·(1+n)` | std 0.05–0.15 | 0.5 |
| DepthAttenuation | 深度方向声衰减 `exp(-μy)` | μ 0.1–0.4 | 0.3 |
| GaussianShadow | 钙化灶下方声影(沿结节向下) | 宽 10–30px,衰减 0.3–0.7 | 0.3 |
| HazeArtifact | 近场杂波/雾化(上强下弱) | 1/8 尺度噪声上采样 × 纵向梯度 | 0.2 |
| SpeckleReduction | 机内散斑抑制滤波 | 双边 d=5 | 0.2 |

- **Dominant-Region CutMix(DR-CutMix)**(`mixup.py`):粘贴区按**结节占比 R** 决定标签继承——`R≥0.65` 继承 donor 标签、`R≤0.35` 继承 recipient、中间区(0.35<R<0.65)`mask_weight=0` 屏蔽分类损失,避免歧义样本污染监督;无结节区同样置零。这是把 CutMix 适配到**像素级 + 分类多任务**的关键改造。
- 静态图 + 动态图(cine)两种输入均已支持:静态走 `predict.py`;动态走 `video_predict.py`——均匀抽帧(MP4/AVI/MOV/MKV + 多帧 DICOM cine,含彩色/多普勒灰度兜底)→ 逐帧 gatekeeper(默认 soft:命中只记 flag 不中断整段,去重库/真实性模块/篡改检测器三重型对象帧循环前各构建一次跨帧复用)+ 逐帧诊断 → 帧级聚合(恶性概率取**最大帧**做最终判定,召回优先)→ 关键帧产出 mask/报告/Grad-CAM。具体抽帧数/聚合权重待官方动态数据形态确定后微调。
- 域偏移缓解、单类/缺标签鲁棒:**Masked 多任务损失**对缺标签样本零梯度,适配官方部分标注(详见 §6)。

## 9. 创新点总结

对照专家评审维度(创新性 / 可靠性 / 合理性 / 独特性 + 数据异质性 / 真实世界复杂性 / 可扩展性)逐条强化:

1. **异构非对称双主干 + 单向跨层任务对齐**(创新性 / 独特性):输入端即解耦 ConvNeXt-Nano(分割)与 EfficientNet-B2(分类),从根上消解多任务**梯度角度冲突**;TaskAlignmentAdaptor 以 detached 分割特征作软注意力**单向**门控注入分类分支,既借力空间先验又杜绝梯度回流污染。区别于常见"共享主干晚期分叉"的范式。
2. **概念瓶颈(CBM)可解释诊断**(合理性 / 临床价值):预测 5 维 ACR TI-RADS 概念(composition/echogenicity/shape/margin/foci)再聚合良恶性,诊断**可解释、可干预**——医生可修正概念层并观察结论变化,契合医保审核的可追溯诉求。
3. **四层 gatekeeper 把"真实性/规范性"工程化为可验证闸门**(可靠性 / 真实世界复杂性)：真实性三分类 + 重复(dHash+ResNet)+ 几何缝拼接检测 + copy-move——splicing 检测器经两轮失败后主动放弃方差方案、换取干净图 0/80 零误报,体现工程取舍的严谨性(该项赛道七已豁免计分,展示工程完整性)。
4. **缺标签鲁棒的训练栈**(数据异质性 / 可扩展性):5 通道 FAMO 动态损失加权 + Masked 多任务损失(缺标签零梯度)+ DR-CutMix 占比化标签继承,适配官方**部分标注 / 数据异质**;7 种超声物理先验增强提升设备域鲁棒。
5. **全离线、可校验、可恢复的生产级工程**(可靠性 / 可扩展性):SHA-256 四方完整性校验(predict/video_predict 双入口 + src 全树 + 权重,`seal_container.py` 密封)、续训态持久化(FAMO+AUCM 对偶参数)、`verify_model.py` 8-Gate + reviewer 审查 + 回归测试全绿(数字见 `tests/AGENTS.md`)构成质量门;架构模块化(概念头可换、gatekeeper 可插拔),便于跨赛道复用。
