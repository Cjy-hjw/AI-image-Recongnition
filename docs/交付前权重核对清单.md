## 一、运行时权重依赖总表

按**缺失后果**分三级。判定依据是代码里的实际探测路径，不是下载缓存里有什么。

### 🔴 级：缺失 = 该输入类型全程零分

| 文件 | 运行时查找路径 | 缺失后果 | A800 现状(07-29) |
|:---|:---|:---|:---|
| `thyroidxl_merged_v2.pth` | `--weights` 默认值 `checkpoints/` | `build_model` **仅打 `[WARNING]` 后随机初始化**，照常输出一份完整但全是垃圾的诊断——**比崩溃更危险**（评测方拿到的是"看起来正常"的错误结果） | ✅ 在 |
| `authenticity_model.pth` | `dirname(--weights)/`，即 `checkpoints/` | **硬 `RuntimeError`** → 入口兜成 `status=ERROR` → **每张静态图零诊断**。`predict.py` 无 `--skip_gatekeeper`（与 `video_predict.py` 不对称），绕不过 | ✅ 在 |
| SSCD **或** resnet18 缓存（二选一） | SSCD: `checkpoints/` 或 `~/.cache/torch/hub/checkpoints/`<br>resnet18: `~/.cache/torch/hub/checkpoints/resnet18-f37072fd.pth` | 两者**都**缺 → resnet18 尝试联网下载 → 离线必失败 → `RuntimeError` → 静态图全挂 | ⚠️ 见下方缺口①<br>resnet18 ✅ 在（当前靠它兜底） |

### 🟡 级：缺失 = 静默劣化，不报错但影响得分

| 文件 | 查找路径 | 缺失后果 | A800 现状 |
|:---|:---|:---|:---|
| `calibration.json` | `checkpoints/`（`calibration.param_file`） | 安全降级全 T=1.0，**但概率不校准会饱和**（实测输出过 0.9999999）。官方硬约束只要求"输出概率分布"，格式达标；**但若评测用 log-loss / Brier 这类校准敏感指标，饱和概率会被重罚**（用 AUC/Kappa 则无影响） | ❌ 不在 |

## 二、2026-07-29 审计发现的缺口

### ① SSCD 打包了却从未生效（**本次审计最大发现**）

实测（A800，`_find_sscd_weights()` 返回 `None`）：

```
SSCD 探测路径:
  False  checkpoints/sscd_disc_mixup.torchscript.pt
  False  ~/.cache/torch/hub/checkpoints/sscd_disc_mixup.torchscript.pt
  选中 -> None                              ← 降级 resnet18
但:
  True   .cache_weights/sscd_disc_mixup.torchscript.pt   ← 95MB 躺在这
```

**`.cache_weights/` 不在任何探测路径里**。所以 SSCD 虽然下载了、`docs/预训练权重打包清单.md` 里也列了，**运行时从未被加载过**——去重一直跑的是 resnet18 降级后端（阈值 0.995）。

**修法**：交付打包时把 `.cache_weights/sscd_disc_mixup.torchscript.pt` **复制到 `checkpoints/`**（或 torch hub 缓存目录）。只放在 `.cache_weights/` 等于没打包。

**连带**：`QA_VP.md §1.7` 的「降级路径即生产路径」写着"判定以 `docs/预训练权重打包清单.md` + `.cache_weights/` 实际内容为准"——**这个判定依据本身是错的**，`.cache_weights/` 是下载缓存、不是运行时探测位置，照它判会得出"SSCD 可用"的错误结论。该条需修正为"以代码里的 `_SSCD_WEIGHT_CANDIDATES` / `_CATNET_WEIGHT_CANDIDATES` 实际探测路径为准"。

### ② 当前真实生产配置（与文档描述的"SOTA 组合"不同）

| 能力 | 文档/清单给人的印象 | **实际生效的** |
|:---|:---|:---|
| 去重 | SSCD（512维 GeM，抗裁切/水印） | **resnet18**（ImageNet pooled，阈值调严至 0.995） |
| 篡改 | CAT-Net v2 深度 HRNet | **dct-bag**（纯 NumPy 块伪影栅格） |
| 概率校准 | 温度缩放 | **无**（T=1.0，输出饱和） |

`docs/技术报告_初赛.md` 的表述是诚实的（明写"可插拔降级"、"dHash + ResNet 余弦"），此处仅提醒**不要在别处宣称 SSCD/CatNet 已生效**。

### ③ `EXPECTED_CKPT_SHA256 = None`（完整性校验未启用）

`src/gatekeeper/authenticity.py` 的 checkpoint SHA256 校验目前是开发态（`None` 跳过）。该校验是配套 `weights_only=False`（ckpt 含 numpy 标准化统计）防 pickle 任意代码执行的。

**建议**：交付封印前设为实际哈希。注意这是**双刃**——设了之后任何重训都必须同步更新该常量，否则硬报错。故应与 `seal_container.py` 一起放在**交付最后一步**（同 `memory/seal-container-timing.md` 的时机原则）。
