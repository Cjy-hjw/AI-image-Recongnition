## 一定要附上的我方上下文(grounding,防泛泛而谈)

### 任务与评分口径(官方已确证)
- 赛道七:甲状腺超声,静态 2D(.dcm)+动态 3D 帧序列(.nii.gz,750帧上限,我们抽样32帧)
- 总分 = Sclin = 目标三(60%:分割Dice/检测AP/良恶性AUC-PR/TI-RADS加权Kappa)
  + 目标四(40%:ETE加权Kappa/位置加权宏平均AUC/T临床显著性AUC)
- 🔴 **检测 AP 的口径是 mask IoU 匹配**(静态2D IoU/动态标注帧均值,匈牙利一对一
  IoU≥0.5),**不是边界框检测**——锚框检测器(YOLO系/detectron2)与该口径不匹配
- 四头(位置/ETE/临床T/TI-RADS)仅对匹配成功的主病灶评分;分割 mask 是全链闸门
- 置信度违规(NaN/越界)=静默垫底非崩溃

### 当前架构(实测 61.89/100)
- 双 backbone:ConvNeXt-Nano(分割)+ EfficientNet-B2(分类,cls_backbone)+ 
  TaskAlignmentAdaptor;总 24M 参数;输入 512×512(可上 640,显存 32G 余量 23G)
- 四头消费 stage4 特征+soft_mask+CBM概念+尺度标量(见总纲 §5)
- 训练:冷启(ImageNet起点)→A/B/C 调度(LLRD解冻),24 epoch/~38分钟
- 🔴 r6 实验定案:**跨域混训底座 warm-start 对分类有害**(TN3K 底座特征被 LLRD
  高 lr 打散 24ep 不恢复,冷启 2ep 即 0.87)——"换底座"不等于免费午餐
- 当前瓶颈(诊断未回,初步判断):检测 AP 3.05(输出端 conf 语义缺陷是嫌疑之一)、
  Dice 8.62(小结节/分辨率);分类四项正常(mal 16.25/tirads 8.16/loc 9.36/T 9.26)

## 要 DR 回答的问题(按优先级)

1. **医学域预训练 backbone 替换**(RadImageNet超声子集/rad-dino/RadNet):与
   ConvNeXt-Nano/EfficientNet-B2 同量级替换的实测先例?超声小数据集(~5.4k 样本)
   上"ImageNet 冷启 vs 医学域冷启"的差异文献?注意要区分"域内但跨任务底座"
   (r6 已证伪)与"纯预训练权重冷启"(未验证)。
2. **视频/时序 backbone**(InternVideo/VideoMAE/Video-Swin):对"每例仅 3-5 帧
   有效标注的稀疏动态序列"是否有适配先例?推理成本(单例 9-25s 预算)可接受吗?
3. **混合架构猜想**:分割用 SAM2/MedSAM 的 prompt 范式做"自动 prompt 生成 +
   mask 输出"在医学小数据上的迁移先例?(我们无交互环节,需自动 prompt)
4. **检测 AP 口径适配**:在"mask IoU 匹配评分"下,检测置信度的最优构造方式
   (实例内概率均值/peak/top-k/独立检测分支打分头)有无文献支撑?
5. **不建议的方向自查**:我们判断 YOLO系/CT 3D 全家/胸片 CLIP 系/mm 框架系
   不对症——有无我们漏判的?特别检查 OpenUS(超声基础模型)是否有可迁的
   甲状腺/结节分割预训练权重。
