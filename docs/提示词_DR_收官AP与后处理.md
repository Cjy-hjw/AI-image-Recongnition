## 提示词正文(以下整段投喂)

你是医学影像检测/分割评测与推理后处理方向的资深研究员。请针对下面这个**已冻结模型权重、只剩推理侧可改**的真实竞赛工程,做一次深度文献调研并给出**可执行的 post-hoc 手段清单(按预期收益×工程风险排序)**。

### 一、任务与评分口径(硬事实,不要臆测)

甲状腺超声多任务诊断,容器化常驻 HTTP 推理服务,离线(**禁联网**)、**最终仅提交一次**、整批推理 **8h 硬时限**(当前实测约 3h)、RTX 5090 32G + 16 vCPU、单帧推理分辨率 512²。

总分 = Sclin = 目标三(60%) + 目标四(40%),当前线上第 8 次跑分 **68.80/100**。分项得分与得分率:

| 目标 | 子项 | 指标 | 当前得分 | 得分率 |
|---|---|---|---|---|
| 三(60) | 良恶性 | AUC-PR | 16.22 | ~90%(到顶) |
| 三 | TI-RADS | 加权 Kappa | 8.32 | — |
| 三 | 结节分割 | **单个结节平均 Dice** | **8.72** | **58%(洼地)** |
| 三 | 结节检测 | **检测 AP** | **9.33** | **63%(洼地)** |
| 四(40) | ETE | 加权 Kappa | 7.52 | — |
| 四 | 病灶位置(7类) | 加权宏平均 AUC | 9.36 | — |
| 四 | T 临床显著性 | AUC | 9.15 | — |

关键评测规则(官方原文级事实):

1. **匹配规则**:静态 = 2D mask IoU;动态 = 各标注帧帧级 IoU 的**算术平均**,且**某标注帧上模型无预测(切片全 0)则该帧 IoU 记 0**、**不设单帧 IoU 下限**。均用**匈牙利算法一对一**匹配,**IoU ≥ 0.5 判匹配成功**。
2. **分类/分级类指标只在"匹配成功的主病灶"上计算**;主病灶漏检则在 AP 与 Dice 上受双重惩罚,分类项直接不计入。
3. **置信度失效判罚**:`Detection.confidence` / `Malignancy.confidence` / `T_conf` 必须 ∈ [0,1];缺失 / NaN / Inf / 类型错 → 评估脚本按 0 处理,该样本在所有排序类指标(AP、AUC-PR、AUC)中**排到最后**。
4. **动态数据必须输出全帧 3D NIfTI**(z 轴切片数与帧顺序必须与原视频严格一致,否则该病例所有指标不予计分);无结节帧填 0 合法。
5. 官方 AP 实现族未公布。DR-1 的后验推断:手写 step-wise 60% / VOC 插值 30% / COCO 101 点 8% / sklearn 阶梯 2%。

### 二、当前推理后处理管线(改动点都在这里)

- 模型输出**单通道整图软 mask**(sigmoid),无实例分割头。
- 二值化:静态阈值 0.35 / 动态阈值 0.50(两条独立路径)。
- 实例化:在**原图尺寸**上做连通域分析(静态 2D 8-邻域;动态 3D 26-邻域 + 时间维闭运算缝 1 帧缺口)。
- 过滤:最小面积占比 `min_area_ratio = 1e-4`(相对整图);实例数上限 `max_nodules = 20`,超出按**面积降序**截断。
- 检测置信度聚合:静态 = **实例内体素软概率算术均值**;动态 = **实例出现帧的逐帧概率均值**。
- 无 NMS(连通域天然不重叠)、无置信度校准、无跨帧 tracking/ReID(动态实例关联完全依赖 3D 连通域 + 1 帧闭运算)。
- 分类四头输出对**同一病例的所有实例填同一份值**(官方允许,评测自动按匹配结果筛选)。

### 三、已判死的实验(**严禁在建议里重提,提了即无效**)

全部有跑分或云端扫参数字背书:

- 训练侧 0 胜 6 负:混训底座重训 / 新表重训 ×2 / 640 分辨率(全指标输且触淘汰线)/ seg-only Boundary+Lovász 微调(dice +1.07pt 但未过 0.72 门)。**模型权重与架构已冻结,本 DR 的一切建议不得涉及训练、微调、蒸馏、重标定需要梯度的模块、换骨干。**
- 换骨干已被独立 DR 否决 5 个候选(OpenUS / rad-dino / RadImageNet / VideoMAE / SAM2-MedSAM),否决理由与时间无关(机理失配 / 专有 CUDA 算子装不进离线容器 / 显存与时限爆表 / 动态图仅 3-5 帧标注)。云端公共模型池已扫,无超声域新增。
- **TTA 判死**:静态 hflip 只平均分割概率,线上 -0.94(Dice +0.12 但 **AP -0.68**),机制 = TTA 平均压缩了 `Detection.confidence` 的分布、损伤排序指标。**任何 TTA / 多尺度 / 模型集成一律排除**(且只有一份可用权重)。
- **mask 连通域清理 + 填孔**判死:离线全量对拍静态匹配率 -0.27pt、AP -0.35pt,动态逐位不动。
- **放开 max_nodules 20→30** 判死:云端扫参释放 165 个新实例,**TP / 匹配率 / Dice / AP 逐位不动**(释放的全是 conf 排在所有已检出 TP 之后的尾部 FP)。
- 静态阈值 0.35 线上零收益;min_area_ratio 三档扫参逐位相同;动态阈值五档单调,0.50 已最优。
- 唯一正收益 = 分类项**期望取整**(Kappa 类),+0.50,已吃完。推理端零训练红利已吃尽。

### 四、DR-1 已证结论(直接采信,**不要重复论证**)

- 全 AP 实现族对"追加 FP"**单调不降**(有严密证明),**安全充分条件 = 新增 FP 的置信度严格低于全部已检出 TP**。
- 高分碎片插队对手写 step-wise AP 造成**双曲衰减**;算例:3 个高均值碎片插到第 15 位之前,N_GT≈100 时 AP 跌约 -1.45%;8-10 个可跌 -5%~-10%。
- **置信度聚合的尺度偏差**已被点明:体素均值让"小而尖锐的碎片"系统性反超"大而边界模糊的真结节";取 max 更糟。
- DR-1 提出但**尚未执行**的两条对策:① 面积幂律衰减重标定 `s' = s·min(1,(Area/Area_thr)^α)`;② 双轨制分段释放(高置信小病灶通道 + 长尾托底通道强制压到 [0.001,0.05])。

### 五、唯一尚未挖尽的结构性信号(请重点围绕它展开)

**动态视频池的时间维碎裂**:动态池 48 例中 **24 例(50%)的预测实例数顶到 max_nodules=20 上限**,n_pred 在 10-19 区间密集;而静态池 993 例 max n_pred = 7,**饱和率 0%**。结合"官方动态匹配 = 各标注帧 IoU 的算术平均、漏帧记 0"这一规则,主会话的假设是:**同一物理结节在时间维被 3D 连通域切成多个片段实例,导致 (a) 每个片段只覆盖标注帧的一部分 → 平均 IoU 被漏帧的 0 拖到 0.5 以下 → 匹配失败;(b) 实例数虚高挤占 20 名额并在全局排序里制造大量 FP。**请验证/证伪这个机理,并给出后处理层的正解。

交叉表另有:主病灶 4.3% 真漏检 / 89.5% 干净;次病灶 miss 17.1%。

### 六、要你回答的问题(逐条作答,不要合并)

**A. 动态/多实例时间维聚合**
1. 医学影像视频/3D 序列检测里,把逐帧或逐切片的分割响应聚合成"一个病灶实例"的通行做法有哪些?(3D 连通域 / tracking-by-detection / 匈牙利跨帧关联 / 轨迹级 NMS / 时序形态学闭运算 / 基于质心距离与 IoU 的贪婪链接)各自在**标注极稀疏(每个视频仅 3-5 帧有 GT)**场景下的适用性与失败模式?
2. 当评测规则是"帧级 IoU 算术平均、无预测帧记 0"时,**把断裂片段合并成一个长实例**与**保留片段**,在数学上分别怎样影响平均 IoU?合并的收益边界条件是什么(缺口帧数占标注帧比例的阈值)?是否存在"合并反而稀释 IoU"的反例(如两个真的相邻不同结节被粘连)?
3. 时间维闭运算的 gap 参数(当前缝 1 帧)在文献里的通行取值与敏感性证据?有没有"按实例面积/运动速度自适应 gap"的先例?
4. 若不做合并,而是**把同一轨迹的多个片段的 mask 在 z 轴并集后作为单个提交实例**,是否等价?风险在哪?

**B. 置信度重标定与排序指标**
5. post-hoc 置信度校准(Platt / isotonic / temperature / beta calibration)对 **AP、AUC-PR、step-wise AP** 这类**纯排序指标**的影响:哪些校准是**严格单调变换**(因而对排序指标恒等、零收益)、哪些**不是**(因而可能真实改变 AP)?请给出明确的数学判据与文献出处。这直接决定我们要不要花时间做校准。
6. 在"同一份 score 同时被用于排序(AP)与被用作分类置信度"的场景里,**分池校准(per-subgroup calibration,如静态池/动态池、大面积/小面积分桶)**为什么可能改变全局排序进而改变 AP?有没有医学检测里用分组重标定提升 FROC/AP 的实证?
7. 面积幂律衰减 `s·min(1,(Area/Area_thr)^α)`:文献里有没有先例(size-aware confidence re-weighting / lesion-size-conditioned scoring)?α 与 Area_thr 的选取方法论?在 GT 中**真小结节占比不低**时,这种压制会不会把真阳性也压到尾部造成 AP 净亏?给出判断该风险的可观测统计量。
8. **双轨制**(把长尾候选的置信度强制映射到 [0.001,0.05] 底部安全垫)在 step-wise AP / VOC 插值 / COCO 101 点 / sklearn 阶梯四族下的**逐族行为推演**:是否真的四族全安全?特别是 sklearn 阶梯族(含 (0,1) 补齐点)是否会因尾部大量低分样本被稀释?

**C. 分割 Dice 侧的 post-hoc 手段**
9. 在权重冻结、只能改二值化与形态学的前提下,提升**单个结节平均 Dice**(注意:是逐结节平均,不是全图 Dice)的通行 post-hoc 手段有哪些?请覆盖:全局阈值 vs **自适应/逐实例阈值**(如 Otsu on ROI、按实例软概率分布的百分位阈值)、概率图的 CRF / 测地线 / 水平集细化、边界带重标定、size-conditioned 阈值(小病灶用更低阈值)。逐条给出医学影像文献先例与典型增益量级。
10. "逐结节平均 Dice"这一口径本身的优化倾向:它对**小结节**的权重与全图 Dice 有何差异?是否存在"牺牲大结节边界、优先保小结节不漏"的最优策略?给出数学论证。
11. 阈值与 AP 的耦合:降低二值化阈值会同时改变实例数、实例面积、体素均值置信度。请给出**同时优化 Dice 与 AP 的参数搜索应该怎么设计**(联合网格 / 帕累托前沿 / 以匹配率为中间量的分解),以及避免"val 上赚线上不赚"的方法论(我们已实测过一次:静态阈值 0.35 在 val 三项不劣、线上零收益)。

**D. 实例筛选与匹配博弈**
12. 匈牙利**一对一**匹配 + IoU≥0.5 的规则下,"同一 GT 附近提交多个重叠/相邻候选"必然产生 FP。是否存在已知的**提交策略最优化**结论(如每个疑似区域只提交一个、或提交"并集 mask"而非"最佳片段")?文献或竞赛经验里的通行做法?
13. 次病灶 miss 17.1%、主病灶 miss 4.3% 的结构下,**追召回**的边际收益/风险如何估算(注意分类项只看主病灶,故次病灶只影响 AP 与 Dice)?
14. 有没有"**弃权**"策略的理论依据:即对极低把握的实例干脆不提交,在 AP 下是否可能净赚?(DR-1 已证追加尾部 FP 单调不降,那么反过来删除尾部 FP 是否零影响?若零影响,删除的唯一价值是什么?)

### 七、交付要求

对**每一条建议手段**,必须给出以下 7 项(缺项视为未完成):

1. **手段名 + 一句话机理**

3. **预期收益量级的估计方法**:不要拍脑袋给数字,要给出"用我们手上哪些统计量、按什么公式推算上界/下界"
4. **下行风险与触发条件**:最坏会亏多少、在哪一族 AP 实现下最危险
5. **工程复杂度**:改动面(仅后处理参数 / 需新增算法模块 / 需额外依赖包——注意**离线容器禁联网,新增第三方依赖需提前装入镜像,scipy/opencv/numpy/nibabel 已有**)

7. **离线验证实验设计**:见下条
