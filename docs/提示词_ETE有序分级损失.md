## 1. 任务定义（甲状腺超声 · 甲状腺外侵犯 ETE 分级）

预测单个结节的「甲状腺外侵犯」程度，**4 个有序类别**：

| 官方编码 | 语义 | 样本数【实测】 | 占比 |
|---|---|---|---|
| 1 | 无侵犯 | 3906 | 92.02% |
| 2 | 包膜侵犯 | 267 | 6.29% |
| 3 | 软组织侵犯 | 67 | 1.58% |
| 4 | 血管侵犯 | **5** | **0.118%** |

合计 4245（= 官方 xlsx 中 ETE 列的**非空行数**，全表口径，含主病灶与次病灶）。
代码内用 0-based：`ete_idx = 官方编码 − 1`。

**这是有序的**：侵犯程度 4 > 3 > 2 > 1，
把「血管侵犯」误判成「无侵犯」比误判成「软组织侵犯」在临床上严重得多。

**该子任务的分值**：属于「目标四」（占总分 40%）下的三个子项之一。
⚠️ **官方未公布目标四内部如何拆分**，若按等分则约 13%，**这是【推断】不是官方口径**。

## 2. 🔴 评测指标（官方原文，本次调研的核心约束）

官方《初赛评审规则简要说明》原文：

> 「甲状腺外侵犯（ETE）：**侵犯分级加权Kappa**，仅匹配成功且为**恶性**的主病灶」

我方实现（`src/training/metrics_official.py`）：

```python
def _ete_weighted_kappa(rows):
    sel = [r for r in rows
           if r["is_main"] == 1 and r["valid_extrathy_ext"] == 1 and r["gt_malignancy"] == 1]
    if len(sel) < 2:
        return None
    y_true = [r["gt_extrathy_ext"] for r in sel]
    y_pred = [int(np.argmax(r["ete_probs"])) for r in sel]   # 注意:argmax,吃硬预测
    k = cohen_kappa_score(y_true, y_pred, labels=list(range(4)), weights="quadratic")
    return None if np.isnan(k) else float(k)
```

**关于指标的三点，请在回答中明确处理**：

1. **官方只说「加权 Kappa」，全文 8 处均未指明 linear 还是 quadratic**【实测：已逐处核对官方原文】。
   我方取 quadratic 并标注为假设。→ 请说明你的方案在两种口径下是否都成立；若不成立，哪种更该赌。
2. **Kappa 吃的是硬预测（argmax），不是概率**。"概率排序对但 argmax 错"拿不到分
   —— 与 AUC 类指标的优化方向**根本不同**。
3. **评测只在「恶性主病灶」子集上算**，见 §5 的 Q3。

def log_class_prior(class_counts, device=None, dtype=torch.float32):

### 3.3 模型侧：ETE 头的输入

`ExtensionHead` 有三路输入：
1. **global**：EfficientNet-B2 全局池化特征
2. **local**：分割 mask 导出的「包膜-结节交界带」加权特征（膨胀−腐蚀取 4px 边缘带）
3. **margin**：CBM「边缘」概念的 softmax（detach）

另输出一个标量 `band_ratio`（交界带面积占比）也进 MLP。输出 `[B,4]` 原始 logits。

### 3.4 🔴🔴 上一轮的关键实验条件：第 2、3 路输入中的 local 通路是**常量零**

**这是本次调研最重要的背景，请务必纳入考虑。**

上一轮 35 epoch 训练中，分割主干被调度**全程冻结**（设计如此，非 bug），导致：
- `val_dice` 从 ep1 到 ep35 恒为 **0.0007**【实测】
- 分割输出概率 `pred_prob` 全域 **0.4425 ~ 0.4463**【实测】—— 是一张**处处几乎相同**的图

而交界带是靠**膨胀减腐蚀**得到的。在一张处处相同的图上，膨胀和腐蚀结果一样，相减恒为 0。
我方实测复现【实测，用真实的 `boundary_band_from_mask` 跑】：

| 输入 mask | 交界带 sum | band_ratio |
|---|---|---|
| 上一轮真实值（处处 0.445） | **0.0000** | **0.000000** |
| 精确全零 | 0.0000 | 0.000000 |
| 正常有结节的 mask | 8022.0 | 0.979 |

→ **上一轮 ETE 头的 local 通路输出恒为全零向量、band_ratio 恒为 0**。
它实际只看到了 global + margin 两路。

🔴 **这意味着两件事**：
1. 上一轮 kappa≈0/转负，**可能不止是损失配置的问题** —— 头在一半输入是常量的情况下，
   本来就学不到什么。
2. **下一轮分割改为全程自训**（调度已改，本地验证通过），local 通路会**首次拿到真实特征**。
   即「损失配置」和「输入特征质量」这两个变量**会同时改变**。

**请在你的方案中明确表态**：
- 你的建议对「输入从常量 0 变成有信息量」这个同时发生的条件变化是否稳健？
- 是否应该**先只改分割**（让 ETE 在真实输入下用现有损失重跑一轮），
  再根据结果决定损失怎么改？还是两者必须一起改？
- 如果建议一起改，怎么区分改善来自哪一个？

## 4. 🔴 实测失败证据（35 epoch 官方真实数据）

**配置**：`ete_focal_gamma=2.0`、`ete_cb_beta=0.99`（权重比 20.4:1）、`la_tau=0`。

| 现象 | 实测值 |
|---|---|
| `loss_ete_ce`（纯 CE） | 0.192 ~ 0.616 |
| `loss_ete_focal`（实际回传的） | 0.0015 ~ 0.0838 |
| → 逐 step 压制比 | **7.3× ~ 129.6×，均值 ~39×** |
| `ete_kappa` ep1-25 | **恒 0.0**（= 常数预测，全判「1 无侵犯」） |
| `ete_kappa` ep26-33 | **转负：-0.054 ~ -0.0039**（8 个 epoch 全负） |

**对照组（同一次训练的其它三个头，证明训练管道本身没问题）**【全部实测，取真实峰值】：

| 头 | 指标 | epoch 1 | 峰值 |
|---|---|---|---|
| 良恶性 | AUC-PR | 0.501 | **0.888 @ep15**（反推值，见下注） |
| TI-RADS（5 类有序，加权 Kappa） | kappa | 0.126 | **0.705 @ep24** |
| 位置（7 类） | 加权宏平均 AUC | 0.569 | **0.740 @ep16** |
| 临床 T（2 类） | AUC | 0.621 | **0.728 @ep28** |
| **ETE（4 类有序，加权 Kappa）** | **kappa** | **0.0** | **0.0 → 负** |

> 注：`mal_auc_pr` 上一轮没有直接打印，0.888 是用 `composite×5 − 其余四项` 反推的【推断】。
> 其余四项均为日志直读【实测】。

### 🔴 TI-RADS 对照：成立，但**只在有限区间内成立**

TI-RADS 同为**有序多类 + 加权 Kappa**，用的是**纯 masked CE**
（无 focal、无 CB 加权；配置里有个二阶有序项 `tirads_ordinal_weight` 但**默认 0、未启用**），
实测 kappa **0.126 → 0.705**。

**但两者的不平衡程度差约 50 倍**【实测】：

| | 类分布 | 最小类占比 | 最大/最小比 |
|---|---|---|---|
| TI-RADS | 312 / 728 / 922 / 1696 / 1540 | **6.00%** | 5.4× |
| ETE | 3906 / 267 / 67 / 5 | **0.118%** | 781× |

→ 这个对照只能说明「**CE 在最小类 ≥6% 的温和不平衡下够用**」，
**不能**直接推广到 0.12% 的 ETE。请给出在 0.1% 量级下 CE / CB / focal 的组合判断。

> 另一条线索：项目已为 TI-RADS 实现了二阶有序正则项（`tirads_ordinal_weight`，默认关闭），
> 但**没有为 ETE 写**。若你认为有序正则是正解，请说明它在 0.12% 极端不平衡下是否还成立。

**我方对「kappa 转负」的解读**（请验证或推翻）：
加权 Kappa 按距离惩罚，转负意味着预测的错误**比常数基线在距离上更远**，
即模型开始**系统性过度预测稀有类**，与 20.4:1 类权重叠加 focal 的双重放大方向一致。

**已做的止血处理（本轮，未经验证）**：`focal_gamma` 2.0→0.0、`cb_beta` 0.99→0.9。
这只是降压，**没有正面回答「加权 Kappa 下该用什么损失」**。

### Q1（核心）在加权 Kappa 作为评测指标时，4 类极度不平衡有序标签该用什么损失？

| 候选 | 关注点 |

| （a）普通加权 CE（当前止血方案） | 最简单；但把 4 类当无序处理，不利用有序结构 |
