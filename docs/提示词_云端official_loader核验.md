# 给云端 agent 的核验任务（精炼口述版，2026-08-12 更新）

> 直接在官方数据 `/2026aicompetition` 里只读核验，**不改任何数据、不导出影像**。
> 产出报告要**原始数字**不要结论，每条给数值和抽样示例。
> 不会的列名/字段自己用 pandas 读 xlsx 找，代码在云里写。

```
在 /2026aicompetition 里只读核验，不改数据，报告要原始数字不要结论：

1. nvidia-smi：GPU 型号、显存 total。
2. 标注 xlsx：打印所有 sheet 名和列名；找到 ROI级别 sheet。
3. 以下几列各做 value_counts 全打（原始字符串别归并）：
   良恶性、位置(lesion_loc)、甲状腺外侵犯(extrathy_ext)、RoiName、SliceIndex。
4. 良恶性里表示"无"的单元格原样贴出来（看是否含"阴"字）。
5. 位置/侵犯列是否有数字+中文混写、越界值、没见过的写法。
6. 目录结构：一级/二级目录各多少；dcm(静) 和 nii.gz(动) 各多少。
7. 抽 5 个病例：图像与 mask 尺寸是否一致、mask 是否只有 0/1。
8. 逐行统计各临床列有值/空(缺失)的比例。
9. 抽 3 个动态病例：mask 非零帧号从 0 还是 1 开始。

报告每条给原始数字和示例，别只给结论。
```

**核验报告回来后**：本地按报告修 loader → 重新打包上传 → 云端 `--smoke` 冒烟 → 按实测显存定 batch → 正式训练。**本文件在核验完成并落盘报告后删除。**
