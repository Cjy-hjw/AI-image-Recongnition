# 云端核实任务:病理金标准列与良恶性列是否矛盾

> 背景:`docs/8.1赛事公开资料/数据探查证据链.md` 10 轮已查清 `病理结果-组织学`(patho_histology)与
> `ROI良恶性` 各自的 value_counts(第2/11轮),也查清了`主病灶标记`=`RoiName=="M"`(第1轮)、
> `lesion_loc`/`extrathy_ext`/`clin_t_stage` 真实列名 100% 命中(第13轮)——**这些都不用再问**。
> 唯一没人查过的是:文档把 `病理结果-组织学` 标注为"金标准",如果它和 `ROI良恶性` 在部分样本上
> 不一致,现在训练恶性任务用的 `ROI良恶性` 就可能不是最优真值源。只要这一件事的原始交叉表。

请在能访问真实官方 xlsx(`甲状腺_标注结果_训练集_(1) - 新.xlsx`,`header=1`)的云端环境跑:

```python
import pandas as pd

df = pd.read_excel("<真实xlsx路径>", header=1, dtype=str)

col_malig = next(c for c in df.columns if "良恶性" in str(c))
col_patho = next(c for c in df.columns if "病理" in str(c) and "组织学" in str(c))
col_roi = "RoiName"

print("良恶性列名:", col_malig)
print("病理列名:", col_patho)
print()

# 只看主病灶(RoiName=='M'),这是官方评分实际用到的子集
df_main = df[df[col_roi] == "M"]

print("=== 全表交叉表:病理结果-组织学 vs ROI良恶性 ===")
print(pd.crosstab(df[col_patho].fillna("NaN"), df[col_malig].fillna("NaN")))
print()
print("=== 仅主病灶(M行)交叉表 ===")
print(pd.crosstab(df_main[col_patho].fillna("NaN"), df_main[col_malig].fillna("NaN")))
print()

# 两列都非空、都非"无"类值时,是否出现方向相反的判断
# (例如病理=良性肿瘤 但 良恶性=恶;或病理=恶性肿瘤 但 良恶性=良)
both_valid = df_main[df_main[col_patho].notna() & df_main[col_malig].notna()]
mismatch = both_valid[
    ((both_valid[col_patho].str.contains("恶性肿瘤", na=False)) & (both_valid[col_malig] == "良")) |
    ((both_valid[col_patho].str.contains("良性肿瘤", na=False)) & (both_valid[col_malig] == "恶"))
]
print("两列均非空、方向相反的行数:", len(mismatch))
if len(mismatch) > 0:
    print(mismatch[[col_patho, col_malig]].head(20))
```
