- **侵犯头②**:**保 4 类(血管仅 5 例,⚠️ 论证前提已过时——原写"AUC 下不可并类",评审规则确认 ETE 实际指标是加权Kappa非AUC,并类是否仍不可行需重新评估,用户 2026-08-12 核实中,见 `docs/待官方答复清单.md` Q1)**;CB-Focal + Logit Adjustment;ROI-Mask 交界带(5px,实测带宽 = kernel−1)局部特征 × CBM"边缘"Margin logits 旁路;目标 0.75-0.80(设计预期,未实证)。

### 5.1 实现进度(2026-08-12 阶段 2.3 完成:**位置头 + 侵犯头 + 临床T 头全部实现,三头齐备**)

**已就绪的 4 个接入接口**(阶段 2.0,`MultiTaskThyroidModel.forward` 的 outputs 键,详见 `src/models/heads/__init__.py`):

| 接口 | outputs 键 | 形状 | 梯度 |
|---|---|---|---|
| Stage-4 空间特征图 | `stage4_spatial` | **[B,352,16,16]**(512² 输入实测) | **有**(位置头/侵犯头回流 cls_backbone 是设计意图) |

- ⚠️ **`soft_mask` 有两份**:`forward` 内送 `prior_extractor` 的那份**有意不 detach**(物理先验通路,见 `stages.py`);outputs 里的 `soft_mask_detached` 是另发副本。改任一处前先分清。
- **尺度标量语义**是**归一化等效直径** `sqrt(面积占比)` 而非体积:T 分期临床判据是最大径;面积^1.5 会把典型结节压到 1e-3 量级致输入塌陷。实现在 `src/models/mask_features.py`(阶段 2.2 的交界带提取也落此文件)。

### 5.2 阶段 2.1 位置头(2026-08-12 完成)

`src/models/heads/location.py` + `src/models/losses/components/location.py`。
CoordConv + Stage-4 空间特征 → 侧别3/纵向3 双分支 → 合成 7 类。

- **和为 1 是数学恒等式**:`ΣP = P(左)·1 + P(右)·1 + P(峡) = 1`,不靠再归一化。
- 🔴 **类别常量已下沉到 `src/models/label_schema.py`**(原在 `src/inference/prediction_json.py`)。原因:`.importlinter` 契约2 规定 **`src.models` 是最底层、不得依赖 `src.inference`**,而位置头必须按同一份顺序构造标签 —— 常量留在 inference 会让 CI 的 import-linter job 直接红(实测 BROKEN,已修复为 4 kept/0 broken)。`prediction_json` 改为 re-export,对外 import 路径不变。**改类别定义请改 `label_schema.py`**。
- **四个坑(都是"错了不崩、只静默学错"那类)**:
  1. **峡部没有纵向属性**,level 分支须用 `build_level_validity` 屏蔽;且峡部的 level 标签是 `-1`,直接喂 `cross_entropy` 报越界 → clamp+屏蔽**两道保险缺一不可**。
  2. **水平翻转必须用 `flip_location_index` 联动翻标签**,漏了会让位置头学到反的左右,而 loss 照常下降。
  3. 🔴 **CoordConv 必须先过非线性再池化**。卷积是线性的,`GAP(conv([x,c])) = GAP(conv_x(x)) + GAP(conv_c(c))`,第二项是常数偏置、第一项平移不变 → **裸 CoordConv+GAP 对左右图案逐位相等**,坐标通道形同虚设。已用三段反证锁在测试里(普通卷积不可分 → 裸 CoordConv 仍不可分 → 加 ReLU 才可分)。
  4. **标签越界正负不对称**:`idx=7` 会 IndexError,而 `idx=-1` 走 python 负索引静默取到末元素(恰是峡部)再被吞成"无监督"。已加显式下界断言。
- **未接生产路径**:`v21_output` 的 `location_probs` 仍是占位(均匀分布),接线在阶段 2.5。

### 5.3 阶段 2.2 侵犯头 ETE(2026-08-12 完成)

`src/models/heads/extension.py` + `src/models/losses/components/extension.py` +
`src/models/mask_features.py::boundary_band_from_mask`。
交界带(膨胀−腐蚀)加权池化 Stage-4 局部特征 + `band_ratio` + CBM `margin` 旁路 → 4 类。

- **保 4 类不并类**:血管仅 5 例(0.12%)。⚠️ **论证前提已过时**:原写"若官方指标是 Macro-AUC,并类会让该类 AUC 无从计算"——评审规则(2026-08-12)确认 ETE 实际评审指标是**侵犯分级加权Kappa**,非 AUC/Macro-AUC。并类在 Kappa 口径下是否仍不可行需重新推导,用户核实中,**此决策待重新评估,暂不改代码**(见 §1 与 `docs/待官方答复清单.md` Q1)。
- 🔴 **CB 的 β 不能抄论文 0.9999**。实跑权重比(血管:无):β=0.9→2.4:1 / **0.99→20.4:1(默认)** /
  0.999→196.4:1 / **0.9999→646.9:1**。n=5 时 0.9999 退化为近似逆频率加权 = 让 5 张图吃掉整个损失。
- 🔴 **Logit Adjustment 是 `logits + τ·log π`(加)**,符号反了会放大不平衡且**损失照常下降**
  (实跑反号时 loss 仍 2.90→0.19)。已用收敛方向实验锁死(纯 CE gap≈3.0 / LA≈0 / 反号≈5.9)。
  推理侧**不得再调一次**。CB 与 LA 同开会过校正,故 `la_tau` 默认 0(超参在 `configs` 的 `train.ete_*`)。
- **`focal_gamma` 只接受 0 或 ≥1**:γ∈(0,1) 在 `p_t=1.0` 处梯度 NaN 而 loss 看不出异常
  (实跑 γ=0.5 → loss=0.0/grad=nan);`p_t==1.0` 在 fp32 下真的可达(logit gap≥50)。
- **带宽 = kernel_size − 1**(实测 k=3→2px / k=5→4px / k=7→6px)。架构方案所称「5px 交界带」
  对应 **k=5(实测 4px)**,照字面把核设成 6 是错的。
- **CBM `margin` 必须 detach**:ETE 与「边缘」概念高度相关,但不能让 ETE 梯度重塑该概念
  ——CBM 报告是交付的可解释性模块,概念漂移即报告失去可信度。`stage4_spatial` 则**不 detach**
  (回流 `cls_backbone` 是设计意图)。
- **未接生产路径**:`v21_output` 的 `ete_code` 仍是占位(恒 1),接线在阶段 2.5(backlog #116b)。

### 5.5 阶段 2.3 临床 T 头(2026-08-12 完成)

`src/models/heads/clinical_t.py` + `src/models/losses/components/clinical_t.py` +
`tests/test_clinical_t_head.py`(27 项,全绿)。
GAP 全局特征 + 结节尺度 `[s, log s]` 双通道 + ETE 概率(detach + softmax)→ 轻量 MLP → 2 类。

- **GAP 直接复用 `cls_pool` 输出,不需要模型额外暴露 pooled 键**:`cls_pool` 就是 `AdaptiveAvgPool2d(1)`,
  与 `stage4_spatial` GAP 后**逐位相同**(实测最大差 0.0)。
- 🔴 **别把侵犯头的 `cb_beta=0.99` 抄过来**:CB 的 `1−β^n` 在千级计数上已饱和,
  `class_balanced_weights([2410,1831], 0.99)` 权重比恒为 **1.0000** —— 配了等于没配,**不报错不告警**。
  β=0.999→1.0838 / β=0.9999→1.2800,仍不及逆频率 **1.3162**。CB 是给长尾的(ETE 血管 n=5 处 β=0.99 才给出 20.4:1)。
  要加权用 `inverse_frequency_weights`。
- 🔴 **`label_smoothing` 默认 0**:LS 把 `P(T=1)` 上界**精确钳死在 `1−ls/2`**(实测 ls=0.05→0.9750、ls=0.1→0.9500),
  而官方 `T_ClinSig.T_conf` 读的正是这个数 —— 开 LS = 系统性压缩交付置信度,是拿概率校准换分类精度。
- 🔴 **`T_conf` = P(T=1)**,不是"对所报 T 值的置信度"(二者在 T=0 时给出 0.1 vs 0.9,完全不同)。
  官方样例 `{"T":1,"T_conf":0.92}` 单看无法区分;取前者的依据是**与交付层既有口径自洽** ——
  `prediction_json.build_nodule_entry` 里 `Malignancy.predicted = bool(confidence >= threshold)`,
  即 confidence 是"恶性概率"而非"预测可信度",同一 schema 里两个置信度字段没有理由用相反语义。
  ⚠️ 仍属**官方未明确项**,应列入待问组委会清单;若官方澄清为后者,改动点只有 `ClinicalTOutputs.t_conf` 一行 + 交付侧读取处。
- **头内禁用 `BatchNorm1d`**:实测 train 模式 batch=1 直接 `ValueError: Expected more than 1 value per channel`,
  而训练末批可能只剩 1 样本。侵犯头能用 `BatchNorm2d` 是因为它作用在 16×16 空间上、batch=1 仍有 256 个元素可统计;
  GAP 之后只剩 [B,C] 没有这个余量。需要归一化改用 `LayerNorm`。
- **ETE 输入 detach + softmax**:detach 是因为 ETE 是官方**独立计分**维度,
  让 T 的梯度反灌会把 ETE 表征拽偏(换 T 涨一点、丢 ETE 的分,净亏);
  转 softmax 的理由**不是**"随机初始化下 logits 很大"——那是错的,Gate2 实测真模型 5 seed 下
  `|ete_logits|max` 只有 **0.12~0.27**。真实理由两条:① **平移不变性**(`logits` 与 `logits+c` 是同一分布,
  raw logits 会让 T 头对这个无意义自由度敏感;softmax 消掉它且**信息无损**);② **量级随训练无上界增长**
  (交叉熵持续推大 logit gap,而 scale∈[0,1]、全局特征经 ReLU 是 O(1),让无界量与有界量共享 MLP 首层
  等于把量级平衡交给运气)。
  ⚠️ 该条曾以"±15.6"为据写进本文与 `训练架构方案.md`,**那个数是主会话用 `randn*6` 造的合成 logits,
  不是头的真实输出** —— Gate2 lane3 实测推翻。教训同 §8「实测数字不得凭印象写」。
  三头统一原则:**下游头消费上游头的输出一律 detach**。
- **尺度标量带 log 通道**:T 分期判据(T1≤2cm/T2 2-4cm/T3>4cm)关心直径的**倍数**关系,
  log 尺度才等距 —— 实测三对 2 倍关系(0.01→0.02 / 0.1→0.2 / 0.4→0.8)线性差相差 40 倍、log 差恒为 0.6931。
  ⚠️ **诚实标定**:去掉 log 通道后头**照样分得开** 0.001 和 0.01(Linear 能放大 0.009 的差,变异实验实证)——
  log 解决的不是"能否表示"而是**分辨率是否均匀**,对应测试因此只能是白盒的,黑盒行为判据在这里零区分力。
- **`log` 前 `clamp(min=1e-4)`**:空 mask(阴性病例)时 s 恰为 0,`log 0 = -inf` 会毒化整个 MLP。
  1e-4 对应面积占比 1e-8(512² 图上不足 0.03 像素),不会截断任何有效样本。
- **配置**:`configs/thyroid_config.yaml` 新增 `train.clin_t_class_counts: [2410,1831]` /
  `clin_t_use_class_weights: false` / `clin_t_label_smoothing: 0.0`。
- **未接生产路径**:`v21_output` 的 `t_clin_sig` 仍是占位,接线在阶段 2.5(backlog #116b)。

### 5.6 阶段 2.4 训练循环接线(2026-08-12 完成)——三头接线 + 损失编排 + 官方指标 + train/validate step

**数据侧**(`official_loader.py`):labels 新增 `is_main`(主病灶标志,供三头只训主病灶/指标按官方口径筛)+ `lesion_id`(病灶级聚合键);`OfficialThyroidDataset` 新增 `hflip_prob`/`seed`——hflip **与位置标签联动翻转**(`flip_location_index`,调用形态 `int(flip_location_index(torch.tensor(loc)))`),**val 恒无 hflip**。

3. **`heads/tirads.py`(新)**:`TiradsHead` 消费 CBM 五概念 logits(`logits_comp`[B,4]/`logits_echo`[B,4]/`logits_shape`[B,2]/`logits_margin`[B,4]/`logits_foci`[B,4],实读 `cbm_head.py:132-136` 切片核实拼接确为 18 维,非笼统"五概念"),**全部 `.detach()`** 后与 stage4_spatial GAP 池化结果 concat 过 MLP → 5 类 softmax。🔴 **不新造几何特征**(原 plan 曾设想加 `nodule_aspect_ratio_from_mask` 二阶矩纵横比,审查阶段自行推翻——ACR 的 taller-than-wide 已由 `logits_shape`[B,2] 承载,二阶矩是冗余的第二路 shape 信号,且 `clamp(min=1e-4)` 是从 `clinical_t.py` 面积占比场景照搬,量纲对"纵横比"不成立,用现成概念更省更对)。
4. **`losses/components/tirads.py`(新)**:`compute_tirads_loss` = masked 加权 CE(照 `compute_clinical_t_loss` 的 `(loss*v).sum()/(v.sum()+eps)` 范式)+ 可选二次有序项 `L_ord=((Σ_k p_k·k)−y)²`(对齐官方"加权 quadratic Kappa"语义,预测分布跑到真值远端 loss 更大)。**默认 `ordinal_weight=0` 关闭**(rules.md §5「先证后改」,没有真实数据无法调参)。类权重 re-export 复用 `clinical_t.inverse_frequency_weights`,不重抄。
   🔴 **2026-08-13 Gate2 审查后修正**:有序项此前无条件计算(权重=0 时仍走 softmax+期望值建图,只是乘 0 不影响 total),Lane3(简化/效率角度)实测该分支在关闭态仍产生约 0.45ms/forward 的建图开销,已改为 `if ordinal_weight > 0.0:` 门控,权重=0 时直接 `torch.zeros((), device=..., dtype=...)`,不建图。改动后重跑 `test_tirads_head.py` 15/15 + Gate1 + 全量 pytest 无回归。
