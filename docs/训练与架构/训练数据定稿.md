## 1. 已证实事实（可直接写进代码）✅

### 1.1 训练数据目录结构

```
/2026aicompetition/datasets/training/annotation/
  {一级目录}/                        ← 32 位 hex；是 PatientId 还是 StudyUid 待定(见 §4)
    {SeriesUid}/                     ← 1.2.826.0.1.3680043.8.498.xxxxx
      {原始影像}                     ← 静态图=.dcm(DICOM)  /  动态图=.nii.gz(NIfTI)
      M_1_mask.nii.gz               ← 主病灶 mask
      病灶1_1_mask.nii.gz           ← 次病灶 mask（多结节才有）
```
一个 series = 1 原图 + N 个 mask。datasets 下另有 `evaluation_first/second/finals`、`verification` 子集。

### 1.8 mask 格式 ✅

- 静态：**3D 单帧**（nifti shape 如 1456×819×1，前两维 = (W,H) 即 (Columns,Rows)；🔴 2026-09-01 第 5 次跑分实测破案：官方 GT 静态 mask 带 Z=1 单帧维，此前写纯 2D 被官方 shape 校验整批判零，修复 commit 559b306）；动态：3D（如 1024×768×344）。
- 像素值 `0/1` 二值（1=结节、0=背景）。
- **动态 mask 的 z 维 = 视频总帧数**，但仅 3–5 帧非零标注、其余全 0 —— 与规范"输出完整序列、只评标注帧"一致。**我方 `nifti_io.scatter_frames_to_full_length` 输出口径正确，此前担心的"0分风险"不成立。**
- ✅ **2026-08-13 第12轮全量复核（500 个目录/537 个 mask 文件）确认命名格式**：主病灶 `M_{编号}_mask.nii.gz`（`M_1_mask.nii.gz` 448个/83.4%、`M_2_mask.nii.gz` 15个/2.8%、`M_3_mask.nii.gz` 1个/0.2%）；次病灶 `病灶{序号}_{编号}_mask.nii.gz`（如 `病灶1_1_mask.nii.gz`）。**与既有假设（本文 §1.1/§1.4/§1.11 及 `official_loader.py` 的 mask glob 逻辑）完全吻合，明确排除 `M_mask.nii.gz`(无编号) 与 `M_1-mask.nii.gz`(横杠分隔) 两种此前存疑的变体，无需改代码**。

## 2. 三个新维度的训练要点

### 2.1 临床显著性 T —— ❌ 规则法作废，必须训练

规则 **"恶性 且（直径>1cm 或 ETE≥2）→ T有"** 实测吻合率仅 **68.2%、漏报率 85.6%**：T有病例里 85% 无 ETE 侵犯。

**驱动因素**（E5 交叉分析）：**N 分期(淋巴结)是强驱动**——T无里 N有仅 0.3%（"N有 ⇒ 几乎必 T有"），但反向不成立（T有里仍 981 例 N无）。恶性且T有的 1485 例中约半数靠 N 分期、半数靠体积等。
→ **T = 体积 + N分期 + 其他 的综合，单规则不可行，须作独立分类维度训练。**

⚠️ **隐患**：N 分期取决于颈部淋巴结转移，而输入是甲状腺结节超声图，**淋巴结常不在画面内** → T 维度可能有**影像学理论上限**，训练前需评估可学习性。

### 2.2 masked loss 判据 = 「临床列是否为空」，不是「是否 M 行」✅

非 M 行（次病灶）也有约 13% 带临床标注（病理/ETE/位置/T 各 ~227 行）。
→ 训练时**逐行检查该临床列是否为空**：有值就回传、空就 skip；`清晰帧` 行只有坐标、仅参与检测任务。**不能简单只训 M 行、也不能全训。**

✅ **2026-08-12 全量实测精确化（原始回报已并入 `数据探查证据链.md` 第11轮）**：M 行（4877）临床列缺失率——良恶性 **1.9%**（93 行）、癌存在/病理/ETE/位置/T/N/M 各 **~17.1-17.8%**（~830-870 行）、TI-RADS 总分类独立缺 2.8%。非 M 行（3042）缺失率 **83-100%**（主要是坐标标注，即"约 13% 带标注"的精确口径 = 每列 ~227 行有值）。
