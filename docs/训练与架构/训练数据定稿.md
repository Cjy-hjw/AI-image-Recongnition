## 1. 已证实事实（可直接写进代码）✅

### 1.1 训练数据目录结构

```
/2026aicompetition/datasets/training/annotation/
  {一级目录}/                        ← 32 位 hex；是 PatientId 还是 StudyUid 待定(见 §4)
    {SeriesUid}/                     ← 1.2.826.0.1.3680043.8.498.xxxxx
```

一个 series = 1 原图 + N 个 mask。datasets 下另有 `evaluation_first/second/finals`、`verification` 子集。

### 1.11 数据 ↔ 标签对齐机制 ✅（回答7+8，训练管道核心）

**一个 PatientId 可对应多个检查目录**（32% 患者 1:2~3），故**不能只用 PatientId** 关联静态标注。

- **静态图 `.dcm`**：目录 `{PatientId}/{SeriesInstanceUID}/{SOPUID}.dcm`。
  ROI 行的 **`Col15`(SeriesUid) = DICOM SeriesInstanceUID = 子目录名**（100% 验证）。
  → 用 Col15 定位子目录。（注：DICOM StudyInstanceUID = PatientId；Col15 ≠ StudyUid。）
- **动态图 `.nii.gz`**：目录 `{PatientId}/{PatientId}/{PatientId}.nii.gz`，无 DICOM 头。
  ROI 行的 Col15 是悬空 UID（前缀 `...2.1143` 而非静态的 `...8.498`），**不匹配磁盘名**
  → **用 PatientId 直连**（⚠️ 成立前提：一患者仅一动态序列，见 §4.2 待确认①②）。
- **ROI 行 ↔ mask 文件**：同子目录内靠 **RoiName**（M→`M_1_mask.nii.gz`，病灶N→`病灶N_N_mask.nii.gz`）。
- **无标注图要跳过**：部分检查目录在 ROI 表无对应行（检查级别 1 行、磁盘多目录）。
- 三 sheet（检查/序列/ROI 级别）Col1 均为 PatientId；ROI 级别 Col15 才是序列级区分键。

## 2. 三个新维度的训练要点

### 2.1 临床显著性 T —— ❌ 规则法作废，必须训练

规则 **"恶性 且（直径>1cm 或 ETE≥2）→ T有"** 实测吻合率仅 **68.2%、漏报率 85.6%**：T有病例里 85% 无 ETE 侵犯。

**驱动因素**（E5 交叉分析）：**N 分期(淋巴结)是强驱动**——T无里 N有仅 0.3%（"N有 ⇒ 几乎必 T有"），但反向不成立（T有里仍 981 例 N无）。恶性且T有的 1485 例中约半数靠 N 分期、半数靠体积等。
→ **T = 体积 + N分期 + 其他 的综合，单规则不可行，须作独立分类维度训练。**

⚠️ **隐患**：N 分期取决于颈部淋巴结转移，而输入是甲状腺结节超声图，**淋巴结常不在画面内** → T 维度可能有**影像学理论上限**，训练前需评估可学习性。

### 2.2 masked loss 判据 = 「临床列是否为空」，不是「是否 M 行」✅

非 M 行（次病灶）也有约 13% 带临床标注（病理/ETE/位置/T 各 ~227 行）。
→ 训练时**逐行检查该临床列是否为空**：有值就回传、空就 skip；`清晰帧` 行只有坐标、仅参与检测任务。**不能简单只训 M 行、也不能全训。**

### 2.3 动态图标注

动图与静态图**同表**（sheet `ROI级别`），关键帧用 RoiName `清晰帧1/2/3` + `开始`/`结束` 标识，均为点标注（pointAnnotate），只有坐标无临床信息。

### 2.4 类别不平衡（训练必须处理）

血管 ETE 仅 5 例、交界性病理 7 例、峡部 86 例。参 `docs/提示词_新增三维度调研.md` §5（Focal/class-balanced/阈值移动/masked loss）。

## 3. 评分框架（🔴 2026-08-12 已被官方《初赛评审规则简要说明》取代，本节保留仅存档，现状以 §4.1 与总纲 §1 为准）

- 赛道七 **总分 = Sclin**（⚠️ 评审规则原文是"总分 = Sclin"，Sclin∈[0,1]，不含"×100"；总纲 §1 已按百分制口径重写，此处"×100"是旧表述，字面与官方不符但语义等价，保留存档不改）。
- 匹配：**静态2D掩膜IoU + 动态各标注帧帧级IoU算术平均，匈牙利算法一对一最优匹配，IoU≥0.5判定成功**（评审规则已给出精确阈值，此处旧表述缺阈值）。
- TI-RADS 分类指标 = **加权 Kappa**（不变，评审规则确认一致）。
- 🔴 **"ETE/位置/T 仅考核恶性结节"——已被评审规则推翻，本条是错误信息**：评审规则明确**位置指标"仅匹配成功的主病灶"，不限恶性**；只有 ETE 与 T 才是"仅匹配成功**且为恶性**的主病灶"。即：良性主病灶的**位置**标签仍参与位置指标计算，只有 ETE/T 才对良性结节填保守占位不计分。详见总纲 §1「甲状腺外侵犯(ETE)的判定新增一条硬约束」。
- 主病灶：多病灶取"最具临床意义者"，次要/良性不参与分期（此条对 ETE/T 仍成立，对位置不成立，见上条）。
- 分割需覆盖 **<10mm 微小结节**；所有分类/分级/分型**必须输出概率分布否则计 0 分**（已落地，但 TI-RADS/ETE 的概率字段仍是未决矛盾，见 `docs/待官方答复清单.md` Q4）。
- 可解释性：结构化标签初赛计分；热力图/掩码决赛必选；自然语言报告可选。
