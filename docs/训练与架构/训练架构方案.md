## 1. 总原则：三个头都训，不走常数兜底

常数/纯规则兜底在 AUC 塌到 **0.5**、加权 Kappa=**0**（观察一致=期望一致）；
训练头在 AUC/Kappa 上均有确定性优势。故三维度**全部训练专用头**，但都是**轻量融合头**，
不新建大子网络。

| 维度 | 训练路线 | 预期 AUC | 精力 |
|:--|:--|:--|:--|
| **位置 lesion_loc** | 解剖因子分解（见 §2） | **0.85+** | ① 40% |
| **侵犯 extrathy_ext** | 保4类 + CB-Focal + Logit Adjustment + CBM边缘复用 | 0.75–0.80 | ② 40% |
| **临床T clin_t_stage** | 轻量融合头（结节尺度标量+全局特征+ETE logits） | 0.72（有影像学上限） | ③ 20% |

> **实现状态（2026-08-12）**：三头均已实现（位置 §2 / 侵犯 §3 / 临床T §4），逐头 `verify_model.py` + Gate2 通过，详见 `docs/项目现状总纲.md` §5。实现与本文下述方案的具体差异见 §4 补注。

## 2. 位置头：解剖因子分解（优先级第一）

7 类联合分类里峡部仅占 1.8%，稀释严重。拆成两个子头相乘：

- **侧别头**：3 类（左 / 右 / 峡部）
- **纵向头**：3 类（上 / 中 / 下）

概率合成：
```
P(Location=7 峡部)      = P(Side=峡部)
P(Location=k), k∈1..6   = P(Side=左/右) × P(Level=上/中/下)
```
峡部由侧别头直接定、屏蔽纵向头的非法组合（杜绝"峡部上极"越界）。
收益：峡部在侧别3分类中占比升到 ~1.8%，F1 提升 12–15%。
数据增强：**水平翻转须同步翻转左右侧别标签**。

特征：共享 EfficientNet-B2 Stage-4 全局特征（保留气管声影/肌层等解剖参照）+ CoordConv 坐标网格。

## 3. 侵犯头：保 4 类 + 稀有类保护 + CBM 复用

- **粒度**：保留 4 类（血管仅 5 例）。⚠️ **论证前提已过时**：原写"在 AUC 评测下不能并类"，评审规则确认 ETE 实际评审指标是**侵犯分级加权Kappa**，非 AUC——并类在 Kappa 口径下的代价需重新推导（Kappa 度量分类一致性，AUC 度量排序能力，二者对"合并稀有类"的敏感性不同）。用户 2026-08-12 核实中，**暂不改代码**，见 `docs/待官方答复清单.md` Q1。
- **稀有类保护**：CB-Focal Loss + Logit Adjustment 保护血管类梯度。
- **特征（ROI-Mask Guided）**：取 ConvNeXt-Nano Decoder 的结节 Mask 概率图，膨胀-腐蚀出
  「包膜-结节交界带」（边缘 5px），与 EfficientNet-B2 局部特征逐通道相乘，高亮侵犯区。
  > **实现口径补注（2026-08-12 阶段 2.2 落地）**：实现取 `kernel_size=5` → **实测带宽 4px**（带宽 = `kernel−1`，k=3→2px / k=5→4px / k=7→6px）。照字面把核设成 6 是错的（会得 5px 但对不齐「膨胀−腐蚀」的偶数核语义）。
- **CBM 复用**：现有 CBM「边缘 Margin」概念与包膜侵犯生理重叠，直接把 Margin logits 旁路接入：
  ```
  h_ETE = Concat(f_backbone_global, f_ROI_boundary, Softmax(z_CBM_Margin))
  ```
  提供临床先验 + 增强可解释性，无需为 ETE 另建 CBM。

## 4. 临床 T 头：轻量融合（优先级最低）

淋巴结(N分期)不在甲状腺结节视野内 → 影像学上限 ~0.72 AUC。不值得重投。
做法：拼接 EfficientNet-B2 全局 Pooling 特征 + 结节等效体积标量 + 侵犯头 ETE logits，
接一个轻量 MLP。二分类、阳性率 35.7% 相对均衡，训练难度低。

> **实现补注（2026-08-12 阶段 2.3 落地，`src/models/heads/clinical_t.py`）**：
> 本文方案写「ConvNeXt 体积标量」，实现改用 `nodule_scale_from_mask` 的**归一化等效直径** `sqrt(面积占比)`
> （理由：T 分期判据是最大径，线性尺度直接对应；面积^1.5 会把典型结节压到 1e-3 量级致输入塌陷），
> 且额外带 **log 通道** `[s, log s]`（T 分期关心直径**倍数**关系，log 尺度才等距）。
> 本文方案写「ETE logits」，实现接收 logits 但**内部转 softmax**。理由**不是**「随机初始化下 logits 很大」
> ——那是错的，Gate2 实测真模型 5 seed 下 `|ete_logits|max` 只有 **0.12~0.27**。真实理由两条：
> ① **平移不变性**（`logits` 与 `logits+c` 是同一分布，raw logits 会让 T 头对这个无意义自由度敏感，
> 而 softmax 消掉它、信息无损）；② **量级随训练无上界增长**（交叉熵持续推大 logit gap，
> 而 scale∈[0,1]、全局特征经 ReLU 是 O(1)，让无界量与有界量共享 MLP 首层等于把量级平衡交给运气）。
> ETE 输入须 **detach**（ETE 是官方独立计分维度，不让 T 梯度反灌拽偏 ETE 表征）。
> 头内禁用 `BatchNorm1d`（GAP 后只剩 [B,C]，batch=1 无统计余量会崩；归一化改用 `LayerNorm`）。
> 各硬约束（CB β 饱和 / label_smoothing 钳置信度 / T_conf 语义 / log clamp）详见 `docs/训练与架构/三头实现记录.md` §5.5。

## 5. 关键依赖：评测指标决定稀有类策略

🔴 **官方评审规则已确认 ETE 的真实指标是"侵犯分级加权Kappa"，位置是"位置分类加权宏平均AUC"——均非本表原设想的"Macro-AUC"**（Macro-AUC 从未被官方使用，纯粹是我方推测，见总纲 §1 与 `docs/待官方答复清单.md` Q1）。下表按指标类型列出的两条策略路径本身仍有效，**只是 ETE 应对号到"加权Kappa"行**，此前"侵犯头保4类因为Macro-AUC下并类算不出"这条论证需要重新走"加权Kappa"这条路径推导，用户核实中，暂不改代码。

| 官方指标 | 血管/交界稀有类策略 | 是否为 ETE 实际适用指标 |
|:--|:--|:--|
| **Macro-AUC**（我方此前推测，官方未使用） | **必须保留细类**（合并则该类 AUC 无法计算=0分）+ Logit Adjustment | ❌ 非 ETE 实际指标 |
| **加权 Kappa**（🔴 ETE 官方实际指标） | 若允许合并→合并收敛离散误差；若强制细类→加 **Ordinal Distance Loss**（CE + 类间距离方差惩罚） | ✅ ETE 实际适用此行 |

→ **组委会「各维度用什么指标」已由评审规则确认**（ETE=加权Kappa、位置=加权宏平均AUC，见 §5 顶部与总纲 §1），不再是待确认前提；仅并类决策本身用户核实中。

## 6. 多任务不降级：分阶段 LLRD（不是全参联合、不是纯冻结）

🔴 **2026-08-16 订正:本节前提已失效,分割不再冻结。** 下文「保证**已有**分割 DICE 不退化」中的「已有」指 `best_model_mixtrain_xl_e40.pth`(TN3K 97.71%)。该权重现已**三路不可达**(A800 拒连 / 云端产物按赛规不能导出 / 仓库 `checkpoints/` 被 gitignore 且为空),「已有分割」这个前提整体消失。冻结分割于是从「保护资产」变成「锁死唯一得分闸门」——实测 35 epoch 下 `val_dice` 恒 0.0007、`pred_mask` 恒全零 → 官方 IoU≥0.5 匹配零命中 → 五项分类/分期零样本 → Sclin≈0(见 `docs/项目现状总纲.md` §6③,附官方原文行号)。
**现行调度已改为分割 A/B/C 全程可训**(解码器 `head_lr` / ImageNet 主干 `head_lr×0.1`)。本节以下内容作为**原始设计蓝图存档**保留,理解 A/B/C 由来时可读,但**不要据此认为分割应当冻结**。

保证已有分割 DICE / 良恶性 AUC-PR（⚠️ 评审规则确认是 AUC-PR，非 AUC） / TI-RADS Kappa 不退化：

| 方案 | 旧任务退化 | 新任务收敛 | 32G 适用 |
|:--|:--|:--|:--|
| 全参端到端联合 | 高（扭曲已优化空间） | 快 | 易 OOM/梯度冲突 |
| 纯冻结主干只训头 | 零 | 慢 | 极省显存 |
| **分阶段 + LLRD** ✅ | **极低(<0.5%)** | **最优** | **最佳** |
| 梯度手术 PCGrad/FAMO | 无 | 较慢 | 开销 +30% |

**采用分阶段 + LLRD**：解冻时主干高层学习率设为新头的 1/10 ~ 1/100，护住旧任务隐空间。

分阶段配方（详见架构报告"阶段0–3"）：
- **阶段0**：数据准备、masked loss（按临床列是否为空跳过，非按是否M行）。
- **阶段1（Ep1–10）**：冻结双主干，只温升训练 3 个新头。
- **阶段2（Ep11–30）**：LLRD 解冻 Top-2 层联合微调。
- **阶段3（Ep31–35）**：概率校准（温度缩放）+ 决策阈值移动。
