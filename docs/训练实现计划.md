- **1.2 图↔mask↔标签对齐**：静态 `{pid}/{Col15}/*.dcm`+RoiName→mask；

- **1.3 标签构造**（M3）：lesion_loc / extrathy_ext **`import` prediction_json 的权威常量**；
  masked loss 判据 = 该临床列**是否为空**（空 skip、有值回传；非 M 行 13% 也标、按 RoiName 命中自己 mask；清晰帧行仅坐标不入三头）。
- **1.4 动态样本构造细化**（sonnet S3）：344 帧仅 3-5 非零 → 定义每样本抽帧策略、

  （该 tensor 形状在阶段2 verify_model 与 2.1 的 7 维校验一并写死断言，勿执行期现算）。

## 阶段 2 · 本地：三头实现（逐头 verify_model + Gate2）

按 `训练架构方案.md`，优先级 位置 > 侵犯 > 临床T。**本地写代码，逐头独立 `verify_model.py` + Gate2**。

- **2.1 位置头**：侧别3×纵向3 合成 `P(k∈1..6)=P(Side)×P(Level)`、`P(7)=P(Side=峡)`；
  共享 Stage-4 + CoordConv；水平翻转同步翻左右标签；**7 维分布和=1 且顺序映 `LOCATION_LABELS`**，
  复用 `normalize_location_probs` 校验（写进 verify_model 断言，sonnet 遗漏2）。
- **2.2 侵犯头**：保 4 类；ConvNeXt mask 概率图膨胀-腐蚀出交界带(5px)×局部特征 + CBM Margin 旁路；
  损失 `@待指标`：AUC→CB-Focal+Logit Adjustment；Kappa→可并类 / Ordinal Loss。
- **2.3 临床T 头**：全局 Pooling + 体积标量 + ETE logits → 轻量 MLP；二分类。
- **2.4 三头概率导出契约**（sonnet 遗漏3，官方硬约束否则计 0 分）：`decode_predictions` 扩展
  `LocationProbs[7]`(和=1)、ETE 4 类概率、T 二类置信度，走 `*_prob` 契约。
- **2.5 build_model 集成三头 key**（sonnet S2）：`build_model` 是 `strict=False` 但
  **missing/unexpected 非空即 raise** → 新增三头 key 须在 build_model 侧成型，
  区分「backbone-only 权重」与「含三头完整 checkpoint」，否则热启动必崩。
- **Gate2**：三头触及损失数学/梯度路由 → 逐头派 reviewer 子 agent，**禁 haiku**。

## 阶段 4 · 云端：官方数据训练

- 分阶段：A(Ep1-10 冻主干温升新头) → B(Ep11-30 LLRD 解冻 Top-2，主干 lr=新头 1/10~1/100)
  → C(Ep31-35 温度缩放校准 + 阈值移动)。
- **旧任务退化复测**（sonnet S5）：阶段C 后按 patient 分组 holdout 复测分割/良恶性/TI-RADS，
  验证 <0.5% 退化承诺。
- 类别不平衡：血管5/交界7/峡部86 → CB-Focal + class-balanced sampling。
- **32G 显存具体复核**（sonnet S8）：三头分支 + 动态全帧 batch → 落到具体 batch/分辨率/AMP，
  按平台 32G 上界（非 A800 80G）复核。早停：Ep3 后指标随机则中止。
