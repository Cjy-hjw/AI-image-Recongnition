# **五大核心评审目标与属性分类**

**PRELIMINARY EVALUATION**

大赛将五项评审目标划分为医保安全属性与临床诊断属性两大类别。医保安全设置晋级门槛；临床诊断决定模型能力得分，两者共同构成初赛的完整评估体系。

### **医保安全属性 (GATE)**

1. AI区分真人体、假人体、非人体影像，防范虚假影像骗保风险
2. AI识别重复影像与拼接影像，杜绝同一检查多次报销的欺诈行为

### **临床诊断属性 (SCORE)**

1. 识别肿瘤占位与非肿瘤占位，考核病灶检测的定位精度
2. 完成肿瘤分期、分级、病理分型等临床诊断，评估诊断深度
3. 自动标注病灶关键点位并输出可解释性诊断依据

> ⚠️ 未达医保安全门槛指标不参与总分排名且无晋级决赛资格

# **初赛门槛规则与赛道七豁免机制**

**RULES & EXEMPTION**

初赛设置医保安全门槛，未达标模型不参与排名且无晋级资格。赛道七（甲状腺超声）因任务特殊性豁免全部医保安全考核，总分直接由临床诊断得分构成，体现了赛制对不同临床场景差异性的尊重。

1. 赛道一至六、八的全部队伍必须完成医保安全属性考核，门槛指标推理测试前48小时公示
   - 前48小时公示
2. 未达标模型不参与初赛总分排名、无晋级决赛资格，但各项得分仍计算供团队参考
   - 无晋级资格
3. 赛道七豁免目标一二全部考核，无医保安全得分Sins，总分直接采用临床诊断得分
   - 赛道七全面豁免
4. 门槛指标类型包括Top-K、Recall@10%FPR、Precision@15%Recall
   - Top-K · Recall · Precision

# **核心变量定义与动态权重设计**

**SCORING VARIABLES**

计分体系采用动态权重机制：医保安全得分Sins越高，其权重Wins越小、临床诊断权重Wclin越大。这一设计引导模型在保障影像真伪识别基础能力的前提下，将优化重心逐步转向临床诊断精度。

### **初赛计分核心变量定义**

表格

| 变量      | 名称             | 取值区间   | 计算公式 / 说明                                              |
| :-------- | :--------------- | :--------- | :----------------------------------------------------------- |
| **Sins**  | 医保安全属性得分 | [0, 1]     | 3/(1/S非人体+1/S重复+1/S拼接)3/(1/*S*非人体+1/*S*重复+1/*S*拼接) ，任意一项为0则Sins=0 |
| **Sclin** | 临床诊断属性得分 | [0, 1]     | 赛道专属病灶检测、分类、分期、可解释性等综合计算             |
| **Wins**  | 医保安全动态权重 | [0.2, 0.4] | Wins=0.2+0.2×(1−Sins)Wins=0.2+0.2×(1−Sins)                   |
| **Wclin** | 临床诊断动态权重 | [0.6, 0.8] | Wclin=1−WinsWclin=1−Wins                                     |

# **总分计算公式与计算示例**

**Scoring Formula**

总分由医保安全得分与临床诊断得分按动态权重加权求和，满分100分。赛道七豁免安全任务后总分直接等于临床诊断得分。第二轮推理测试另设鲁棒性与泛化能力评估，虽不计入初赛总分但影响决赛评审。

### **Section 01 总分公式与示例**

- **01 赛道1-6、8通用公式：**

总分=Sins×Wins×100+Sclin×Wclin×100总分=Sins×Wins×100+Sclin×Wclin×100

- **02 赛道七特殊公式：**

总分=Sclin×100总分=Sclin×100

(无医保安全得分参与)

- **03 示例：**
  Sins=0.8, Sclin=0.75 → Wins=0.24, Wclin=0.76 → **总分=74.22**

### **Section 02 综合能力评估 (不计入初赛总分)**

- **01 鲁棒性评估：** 测试集加入扰动样本，计算性能下降率，评估模型抗干扰能力
- **02 泛化能力评估：** 加入小众设备和基层医院影像，评估跨设备跨场景推理稳定性
- **03** 所有测试数据完整存档，作为决赛专家评审模型落地实用性的参考依据

# **推理结果提交要求与评分过滤原则**

**SCORING RULES**

模型须对所有影像输出全部五个目标的推理结果，但组委会依据金标准（而非模型预测）筛选真实病例计算临床诊断得分。误判真实为伪造仍参与计分，误判伪造为真实则不参与，确保评分客观公正。

### **全量输出 (目标 1-5)**

所有模型必须对测试集每一例影像输出目标一至五的全部推理结果（赛道七除外），不得遗漏任何目标维度。

### **金标准筛选 (独立过滤)**

组委会依据金标准标签筛选"真实病例"样本，不使用模型预测的真伪类别进行过滤，确保评估基准独立于模型输出。

### **误判计分规则 (目标 3-5)**

- **真实病例被误判为伪造：** 诊断结果仍参与目标三四五计分；
- **伪造病例被误判为真实：** 诊断结果不参与计分。

# **通用基础任务与全赛道统一约束**

**MEDICAL AI COMPETITION**

通用基础任务要求识别三类伪造影像并设置门槛考核。全赛道统一约束明确了主病灶判定标准、概率输出强制要求和可解释性分层规则，确保各赛道评审标准的一致性和公平性。

### **通用基础任务**

- **非人体影像识别：** 检测无人体解剖结构的虚假影像
- **拼接影像识别：** 检测跨患者、跨部位、跨序列的合成影像
- **重复影像识别：** 检测仅轻微亮度/缩放调整、无临床差异的复制影像

### **全赛道统一约束**

- **主病灶判定：** 单病灶取唯一，多病灶取最具临床意义者，次要/良性病灶不参与分期
- **强制输出功率：** 所有分类/分级/分型任务必须输出功率分布或置信度，否则计0分
- **可解释性分层：** 结构化标签初赛计分，热力图/掩码决赛必选，自然语言报告可选

# **赛道七·甲状腺癌 / 赛道八·胸部X光检测**

**TRACK 7 & 8**

赛道七豁免医保安全任务，聚焦甲状腺超声的结节分割与TI-RADS评估，静态和动态数据采用不同匹配策略；赛道八面对胸片17类征象的复杂检测任务，局灶征象采用面积自适应阈值、弥漫征象采用固定阈值，并考核分尺寸检测与量化评估能力。

### **赛道七：基于超声的甲状腺癌**

- 静态数据帧级IoU匹配 + 动态数据病灶级IoU匹配，匈牙利算法求解最优匹配
- 结节分割（含<10mm微小结节）、良恶性判断、ACR TI-RADS分类（加权Kappa）
- 恶性结节考核：甲状腺外侵犯4级分级、7类病灶位置、T临床显著性判断

### **赛道八：基于胸部X光的多疾病检测**

- 17类征象检测：10类局灶（面积自适应阈值）+ 7类弥漫（固定阈值0.25）
- 分尺寸检测能力考核：小病灶<30mm²、中病灶30-300mm²、大病灶≥300mm²
- 量化评估：肺肿块尺寸回归（Spearman相关系数）+ 胸腔积液严重程度分级
