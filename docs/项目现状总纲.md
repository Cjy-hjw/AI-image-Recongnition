## 4. 数据格式（已封板,docs/训练数据定稿.md 权威）

- **目录层级**:一级 = PatientId(32 位 hex);二级 = SeriesUid(静态)或 PatientId 同名嵌套(动态)。
- **静动判据**:`.dcm` = 静(~4680/5057)、`.nii.gz` = 动(~721/343),全量互斥、**0 混合**,推理也按扩展名分发。
- **mask**:`M_1_mask.nii.gz`(主,RoiName=M,4877 行)/`病灶N_N_mask.nii.gz`(次);静态 2D、动态 3D;像素 0/1。
- **标签解析**:`图像性质`列 1 静 2 动;静态靠 SeriesInstanceUID=子目录(100%),动态一患者一序列直连。**masked loss 判据 = 临床列是否为空**(非 M 行 13% 也标注)。
- **动态帧定位**:SliceIndex 列从 1 起(3~750),仅清晰帧/起止有;M 无帧号 → 主病灶用 **mask 非零帧**(仅 3-5 帧非零)。
- **防泄漏铁律**:`GroupKFold(groups = 一级目录名 = PatientId)`,禁随机 KFold/train_test_split。
- **⚠️ 禁硬编码列号**(各轮列号不一致),**必须按字段名解析**。
- **⚠️ 编码冲突(必须按定稿,勿照旧格式说明)**:
  - 位置 `lesion_loc`:格式说明列 **9 类**(顺序左上/左下/左中…),实测定稿 **7 类** = `1左上 2左中 3左下 4右上 5右中 6右下 7峡部`。**按定稿 7 类**,照旧顺序会全错。
  - 侵犯 `extrathy_ext`:格式说明列 6 类,实测 **4 类** = `1无 2包膜 3软组织 4血管`,阴性/NA/UNK 入码 1。

## 5. 三头架构方案（docs/训练架构方案.md,官方类别定义到齐后进 plan）

- **位置头①(最高优先)**:侧别 3 × 纵向 3 解剖因子分解,P(7)=峡部由侧别直接定,P(1..6)=Side×Level;**水平翻转须翻左右标签**;共享 EfficientNet Stage-4 + CoordConv;目标 AUC 0.85+。
- **侵犯头②**:**保 4 类(血管仅 5 例,AUC 下不可并类)**;CB-Focal + Logit Adjustment;ROI-Mask 交界带(5px)局部特征 × CBM"边缘"Margin logits 旁路;目标 0.75-0.80。
- **临床 T 头③**:全局 Pooling + ConvNeXt 体积标量 + ETE logits → 轻量 MLP;二分类阳性率 35.7%;影像学上限 ~0.72(淋巴结不在视野)。
- **训练**:分阶段 LLRD(阶段1 冻主干温升新头 → 阶段2 解冻 Top-2 层,主干 lr = 新头 1/10~1/100 → 阶段3 概率校准),保旧任务退化 <0.5%。三维度都训不走常数兜底(常数 AUC=0.5/Kappa=0)。**训练侧构造标签必须 import `prediction_json` 的 `LOCATION_LABELS`/`_ETE_LABEL_TO_CODE`**,禁自定义映射。
