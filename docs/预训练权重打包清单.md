## ⚠️ 交付容器另需的自训权重（非本清单的"预训练下载"范畴，但漏带同样致命）

本清单只覆盖**外部下载的预训练权重**。交付离线容器时，以下**自训产物**必须一并打包，漏任一项都会让对应链路整体失效：

| 文件 | 产出脚本 | 漏带后果 |
|:---|:---|:---|
| `checkpoints/thyroidxl_merged_v2.pth` | `train_thyroidxl.py` → `merge_lora_checkpoint.py` | `build_model` 降级随机初始化（仅 `[WARNING]`，**不报错**）→ 输出看似正常但全是垃圾预测，比崩溃更隐蔽 |
| `checkpoints/authenticity_model.pth` | `scripts/retrain_authenticity.py` | R3(2026-08-10)后**降级 skipped、不再零诊断**（`build_auth_module` 返回 None + `auth_skipped=True`）；但仍建议打包以保证该项审计有效（见下方说明） |
| `checkpoints/sscd_disc_mixup.torchscript.pt` | 外部下载（见 §3），**必须复制到 `checkpoints/`** | ⚠️ **放在 `.cache_weights/` 等于没打包**——`_SSCD_WEIGHT_CANDIDATES` 只探测 `checkpoints/` 与 `~/.cache/torch/hub/checkpoints/`，不查 `.cache_weights/`。2026-07-29 审计发现 SSCD 下载了却从未被加载（去重一直跑 resnet18 降级后端）。**✅ 已于 2026-07-30 复制生效** |
| `checkpoints/calibration.json`（可选） | 温度校准拟合 | 缺失则全 T=1.0 降级，概率不校准但不影响可用性 |

**`authenticity_model.pth` 为何曾硬失败、R3(2026-08-10)后改为降级**：`predict.py` 无条件调 `run_gatekeeper_audit` → `build_auth_module` → `AuthenticityModule.load_weights`；**R3 前**权重缺失时该函数硬 `raise RuntimeError`（2026-07-10 Gate2 修复，此前静默退化为随机初始化分类、闸门形同虚设），被入口 `except Exception` 兜成 `status="ERROR"` 的 `result.json`——不裸崩溃，但**该样本零诊断字段**。且 `predict.py` 与 `video_predict.py` 不对称：后者有 `--skip_gatekeeper` 可绕过，前者没有。**R3 起**改为：`build_auth_module` 对该权重缺失/加载崩溃**不再 raise，返回 None + `auth_skipped=True` 降级**——`run_gatekeeper_audit` 标 `auth_skipped=True`、`is_phantom=0`、`auth_probs=None`，诊断照常产出。这是**显式跳过的诚实记录**（WARNING + `auth_skipped` 字段），非伪装 pass；依据：authenticity 赛道七零计分，一个不计分组件的权重故障绝不能让唯一得分项（临床诊断）清零。`load_weights` 内部仍可 raise（`QA_VP.md` §1.7：静默随机推理比报错危险），降级发生在调用方 catch 层。

> 该硬报错**曾不应删除**（`QA_VP.md` §1.7 权重红线：静默随机推理比报错危险）。但在赛道七已豁免医保安全考核、gatekeeper 零计分的前提下，这条红线的收益归零、代价却是满分丢失——**2026-07-29 Gate2 审查**据此列为独立跟踪项（P1-2），处置方案（补 `predict.py --skip_gatekeeper` 对称入口 / CI 校验权重存在性）一度待定。**该待定方案已由 R3(2026-08-10) 落地**——比 `--skip_gatekeeper` 更优：不用手动跳过，`build_auth_module` 自动降级返回 None + `auth_skipped=True`，且是显式跳过的诚实记录（非伪装 pass）。**本节存在目的变为**：交付前尽量打包该权重以保证真实性审计有效（降级后该项审计为空，虽不影响得分但损失一项可解释性维度）——作为交付前必核项保留。

```python
import timm
import torch

# 方法1: timm自动加载（需联网或缓存）
model = timm.create_model('convnext_nano.in12k_ft_in1k', pretrained=True)

model = timm.create_model('convnext_nano', pretrained=False)
state_dict = torch.load('.cache_weights/convnext_nano.in12k_ft_in1k.pth')
model.load_state_dict(state_dict)
```

## 完整性校验

使用manifest验证下载完整性：
```python
import json
import hashlib
from pathlib import Path

manifest = json.load(open('.cache_weights/weights_manifest.json'))

for name, info in manifest.items():
    filepath = Path('.cache_weights') / info['path']
    actual_md5 = hashlib.md5(filepath.read_bytes()).hexdigest()
    
    if actual_md5 == info['md5']:
        print(f"✓ {name}: MD5校验通过")
    else:
        print(f"✗ {name}: MD5不匹配")
```
