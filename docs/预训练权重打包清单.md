## 加载示例

### ConvNeXt/EfficientNet (timm)
```python
import timm
import torch

# 方法1: timm自动加载（需联网或缓存）
model = timm.create_model('convnext_nano.in12k_ft_in1k', pretrained=True)

# 方法2: 从本地权重加载
model = timm.create_model('convnext_nano', pretrained=False)
state_dict = torch.load('.cache_weights/convnext_nano.in12k_ft_in1k.pth')
model.load_state_dict(state_dict)
```

### 打包方式1: 直接上传权重文件夹
```bash
# 将整个.cache_weights/文件夹上传到容器
# 总大小: 546.60 MB
tar -czf pretrain_weights.tar.gz .cache_weights/
```

### 打包方式2: 集成到Docker镜像
```dockerfile
# Dockerfile
COPY .cache_weights /workspace/pretrain_weights

```

### 打包方式3: 合并到checkpoints/
```bash

cp .cache_weights/* checkpoints/pretrain/
```

## 完整性校验

使用manifest验证下载完整性：
```python
import json
import hashlib
from pathlib import Path

manifest = json.load(open('.cache_weights/weights_manifest.json'))

for name, info in manifest.items():
    filepath = Path('.cache_weights') / info['path']
    actual_md5 = hashlib.md5(filepath.read_bytes()).hexdigest()
    
    if actual_md5 == info['md5']:
        print(f"✓ {name}: MD5校验通过")
    else:
        print(f"✗ {name}: MD5不匹配")
```
