# 2026全国医保影像AI识图大赛赛道七：官方数据形态逆向推断与多任务预演数据集选型研究报告

## 任务A：国家医保影像赛事与数据规范逆向分析

### 医保基金监管视角下的特定违规场景与政策背景

首届“2026全国医保影像AI识图大赛”由国家医疗保障局与广西壮族自治区人民政府共同主办，国家医疗保障局大数据中心等单位承办。这一高规格主办背景决定了赛事的底层逻辑不仅是临床诊断，更是医保基金的安全监管。近年来，全国各地查处的虚假住院和虚构检查案例表明，医学影像检查已成为骗取医保基金的重点监控区域。例如，江苏无锡虹桥医院案中，不法分子通过直接复制、截取图像报告库中其他患者的彩超、CT或核磁共振图像，手动修改报告数值来虚构诊疗服务；四川达州渠县万寿镇卫生院则将26张彩超图片重复使用达608次，导致大量患者的彩超报告图像完全一致；更有部分医院采取拍“空片”的形式，影像中仅有放射床或头枕而并无人体。  

在这种背景下，“影像上云”和AI辅助质控成为国家医保局实现主动监管、智能筛查的关键技术路径。前置机端图像质控规范中明确鼓励引入人工智能技术辅助开展检查图像的质量控制。因此，大赛将“① 真实性识别”与“② 规范性审核”设定为一票否决的基础考核项。只有能够精准识别“非真人体”、“假人体（体模）”以及“复制、篡改、拼接”图像的AI算法，才具备进入临床辅助诊断与效率评估等后续竞技环节的资格。  

### 真实性识别基础项的数据形态与物理特征推断

真实性识别的核心任务是区分真人体、假人体（体模）和非人体影像。  

医学超声体模（如聚乙烯醇PVA、琼脂等高分子材料制成的商用甲状腺体模）主要用于设备校准和穿刺培训。虽然其专利材料在手感和基本声学阻抗上高度逼真，但在动态超声下，体模影像与真人组织有显著的物理边界。真人体存在不可避免的生理运动，如颈动脉搏动、吞咽动作引起的肌肉纤维滑行、以及伴随呼吸的胸锁乳突肌形变，而体模影像是完全静态或仅有规则外力形变的。此外，真实人体的皮下脂肪、腺体、血管与气管呈现极其复杂的解剖分层与声学衰减伪影，而合成体模基质分布高度均匀，缺乏精细的解剖纹理。最关键的是，体模内部不具备彩色多普勒血流显像中的动态红蓝微流体信号，亦无多普勒频谱的脉冲波特征。  

针对AI合成或深度伪造（Deepfake）影像，近年来学术界提出了MedForge、MedForensics以及BTD等医学深伪检测数据集。这些数据集表明，基于生成对抗网络（GAN）或扩散模型（Diffusion Models）篡改的图像（例如人工注入或擦除肿瘤病灶）虽然在宏观视觉上能够欺骗人类专家，但在频域和高频噪声分布上会遗留非自然的周期性伪影或边界过渡区域不连续性。非人体影像在真实医保场景中，主要指因系统录入错误、接口异常或故意欺诈而混入的设备噪声蓝屏、无信号雪花图、工作站系统截图、扫描纸质单据、甚至是完全不包含解剖结构的床位或枕头“空片”。  

### 规范性审核基础项的数据形态与标注口径推断

规范性审核主要识别重复影像和拼接篡改影像等异常情形。  

在医保欺诈中，“重复影像”通常表现为同一张超声截屏或同一段动态剪辑被频繁绑定在不同患者、不同就诊时间戳的结算单中。这种重复包含完全一致的像素级复制，也包含经过重采样（下采样降低分辨率）、局部裁剪变形、叠加字符水印或调整亮度对比度后的“近重复（Near-Duplicate）”影像。因此，官方数据形态在评估重复影像时，大概率会采用图像对（Pair）或图像组（Group）的关联关系作为标注口径，考核模型在跨案例数据库中检索、匹配并识别出相同图像源的能力。  

“拼接篡改”则是局部区域的篡改检测（Image Forgery/Splicing Detection）。常见的手段是采用复制-移动（Copy-Move）算法将其他恶性结节区域缝合到无结节超声图中。学术界针对该任务的标注口径通常分为图像级分类（篡改对立于真实）和像素级分割（生成二值化掩膜以标示篡改区域边界）。  

参考LuNoTim-CT数据集（针对肺结节Copy-Move和修复篡改的基准集） 与通用图像篡改检测集（如CASIA、DEFACTO）的标注机制，医保规范性审核对于拼接影像的标注大概率提供像素级Mask，用以支持细粒度的局部篡改定位，或者至少提供紧密边界框（BBox），以精准评估AI模型对篡改交界处声学边缘失真、增益断层等微弱物理线索的捕获精度。  

### 甲状腺癌赛道核心标签与临床金标准推断

在甲状腺癌智能检测领域，判断结节良恶性及进行疾病诊断必须依赖可靠的参考标准。

临床和医保场景下，确证甲状腺癌的金标准始终是细针穿刺细胞学活检（FNA）或手术切除后的组织病理学诊断，而并非仅凭放射科医生的肉眼超声判读。因此，官方数据集的“良恶性”和“肿瘤分期”标签必定以此类客观病理结果作为最终标注。  

为了实现“关键点自动标注和诊断结论可解释”，官方大概率会引入标准化的ACR TI-RADS（美国放射学会甲状腺影像报告和数据系统）分级和临床词典概念标签，包括成分、回声、形状、边缘以及钙化灶。  

鉴于赛道七的官方描述明确提出“要求AI能够从视频中识别并判断病变”，官方提供的数据格式最可能并非静态2D图片，而是**动态超声视频剪辑（Cine-clip）**。这代表AI需要在时间序列和空间维度上同时进行信息检索与推理。  

赛道名称定为“基于超声的甲状腺癌智能**检测**”，且涉及“关键点自动标注”，意味着数据不仅在视频/图像级别标记有“良性/恶性/占位类型”，在空间位置上也将提供结节的紧密定位框（BBox）和病灶尺寸测量的多点坐标信息。

### 算法架构多任务适配与API接口预留设计

为了应对官方数据可能存在的模态差异，确保模型在专属云平台训练和推理时具有高度的自适应性，双主干模型必须在输入端和输出端设计解耦的适配层与可切换的接口。

```
                                  [ 输入数据流 (静态图像 / 动态视频) ]
                                                   │
                                                   ▼
                                       ┌───────────────────────┐
                                       │ 1. 前置质控筛查网络    │ (拦截假人体/非人体)
                                       └───────────┬───────────┘
                                                   │ (通过)
                                                   ▼
                                       ┌───────────────────────┐
                                       │ 2. 视频多帧特征提取器  │ (时空主干: SAM 2 / ConvNeXt-3D)
                                       └───────────┬───────────┘
                                                   ├──────────────────────────────────────┐
                                                   ▼                                      ▼
                                       ┌───────────────────────┐              ┌───────────────────────┐
                                       │ 3A. 目标检测与分割头   │              │ 3B. 孪生对齐检索分支   │
                                       │ (Det-Head & Seg-Head) │              │ (Siamese Embedder)    │
                                       └───────────┬───────────┘              └───────────┬───────────┘
                                                   │ (病灶定位/掩膜)                       │ (重复检测)
                                                   ▼                                      ▼
                                       ┌───────────────────────┐              ┌───────────────────────┐
                                       │ 4. 可解释概念瓶颈层   │              │ 5. 双流取证定位头     │
                                       │ (CBM Bottleneck Layer)│              │ (Forensic Heatmap)    │
                                       └───────────┬───────────┘              └───────────────────────┘
                                                   │ (TI-RADS概念嵌入) [cite: 23]
                                                   ▼
                                       ┌───────────────────────┐
                                       │ 6. 最终分类决策头      │ (良恶性/肿瘤分期)
                                       └───────────────────────┘
```

第一，前置拦截过滤器（Veto-Head）。模型必须设计一个轻量化的二分类/多分类分支，接收单帧图像，快速输出其属于真人体、假人体或非人体的概率。若输出概率指示非人体或体模，则直接跳过后续复杂的检测与分割计算，输出安全预警码。

第二，时空连续性提取器（Spatio-Temporal Backbone Adapter）。鉴于官方数据为超声视频（Cine-clip），1D/2D的ConvNeXt-Nano分割支路必须能够无缝切换至支持时序关联的3D-CNN或配备显存注意力机制的MedSAM-2模型，以对相邻帧进行融合特征处理。  

第三，双向检测与分割对齐头（Dual Det-Seg Outputs）。在病灶识别层，需同时接入目标检测头（如YOLO风格的BBox输出）和像素级分割头（U-Net/Mask-RCNN风格的掩膜输出）。若官方测试集仅评估BBox，则分割网络作为辅助表征增强分支，采用多任务联合损失约束，但在推理阶段将Seg-Head关闭以保证判读效率。  

第四，基于多任务哈希的近重复检测头（Duplicate Detection Head）。针对规范性审核，模型需预留一个并行分支，用于计算超声帧的紧凑特征描述子（Feature Embedding），并通过孪生网络（Siamese Network）和局部敏感哈希（LSH）快速检索是否存在跨患者或跨时间的像素级高重合度图。  

第五，双流取证热图（Forensic Heatmap Output）。针对拼接篡改任务，模型输出端除了图像级二分类（是否篡改），还需预留一个能够生成噪声不一致性特征的热力图定位接口，输出拼接边缘的概率分布，以契合官方潜在的像素级Mask验证要求。

### 核心推荐：Stanford AIMI Thyroid 与 Thyro-LMD 双模演练

为了在算法上线前解决多任务空跑和伪标签问题，本研究强烈推荐采用 **Stanford AIMI Thyroid Cine-clip** 与 **Thyro-LMD** 作为核心演练数据集。  

这两者之所以是最优的组合，是因为它们在物理形态和标签维度上分别与本赛道形成了完美契合：

首先，在动态时间序列的处理上，Stanford AIMI Thyroid提供了多达17,412帧完整的超声时序视频，彻底打破了TN3K静态单帧局限。利用这批数据，可以有效激活和演练双主干模型在时序关键帧检索、病灶动态连续追踪以及3D空间分割上的表现，这正是官方明确提及的“视频中判断病变”的核心竞技点。它所附带的活检病理良恶性分类标签以及真实的TI-RADS描述符，能够直接用于激活EfficientNet-B2分类头的反向传播。  

其次，在可解释性的概念瓶颈层（CBM）预演上，最新发布的Thyro-LMD不仅具有确证的术后病理金标准，更重要的是它首次提供了完全对齐ACR TI-RADS临床标准词典的细粒度多标签标注（成分、回声、形状、边缘、钙化灶）。这些描述符真实反映了由于临床流行病学规律导致的极度不平衡、长尾多标签分布（例如，恶性代表性的微钙化和直立形状在真实世界中比例偏低）。引入Thyro-LMD，能强迫可解释CBM头在一个极具挑战性的真实长尾多标签场景中跑通训练，其学术与竞赛价值远超仅依靠人工形态学硬推的伪标签。  

### 多数据集异构融合与混合训练数据配比建议

为了在多任务（分割、二分类、5大概念分类）中发挥各开源数据集的规模优势，本报告设计了一个三阶段混合训练及数据配比方案：

#### 第一阶段：空间定位与时序分割预训练（TN3K：60%，Stanford AIMI：40%）

- **训练逻辑**：由于TN3K（3493张图）包含高质量的静态结节Mask，而Stanford AIMI（17,412帧）包含时序Mask，将它们混合，主要用于初始化ConvNeXt-Nano分割主干，同时训练时序显存注意力层，使主干网络在2D和3D空间中均具备极佳的边缘与位置感知能力。  

#### 第二阶段：良恶性与CBM概念多任务联合训练（TN5000：50%，Thyro-LMD：30%，Stanford AIMI：20%）

- **训练逻辑**：大规模图像分类由TN5000（5000张病理确诊图）提供强有力的正负样本表征支撑，利用Thyro-LMD（ACR临床词典） 和Stanford AIMI（视频级描述符） 作为概念联合标签。通过多损失函数动态调节，重点演练多任务适配器在多维度标签共存条件下的梯度均衡表现。  

#### 第三阶段：真实性与规范性前置质控预演（模拟合成：100%）

- **训练逻辑**：因为开源界并无专门的“医保骗保假人体与拼接超声”数据集，团队必须在DataLoader端配置在线数据合成引擎：将10%的干净样本随机利用Copy-Move算法在结节边界制造剪切痕迹并标注像素级Mask；引入10%的公开体模噪声图像作为负样本；构建10%的近重复成对超声帧，以此联合训练Veto-Head和Forensic-Head，走通完整的医保智能检测合规漏斗。  

### 领域偏移与跨中心数据异质性缓解对策

由于公开的数据集来自不同国家（美国、中国、哥伦比亚等）、不同医疗中心以及完全不同的超声扫查仪，模型在混合训练和跨库测试中必然会遭遇严重的领域偏移（Domain Shift）。  

常见的偏移类型包括：协变量偏移（如由于不同品牌设备的探头频率不一致导致图像斑点噪声、强反射增益分布不均）以及先验/标签偏移（不同数据集的恶性病灶发生率不一致，如TN5000中恶性样本占绝大多数）。  

为了使模型在部署到专属云环境中面临未知的官方异构数据时依然稳健，本报告提出以下针对性的特征空间对齐机制：

首先，特征级MixStyle特征规范化（Feature-level Style Diversification）。在ConvNeXt与EfficientNet主干网络的前几个浅层特征图提取中，插入MixStyle归一化层。该层不改变图像的解剖结构语义（结节尺寸、形状、边界），但通过对小批量（mini-batch）内不同设备的特征图均值和标准差进行插值融合，主动混淆设备的成像风格和强反射增益，迫使深层特征对齐器只关注结节的真实病理学演变特征。  

其次，基于教师-学生模型的多中心交叉蒸馏（Cross-Domain Knowledge Distillation）。基于多个独立源域训练（例如分别在Stanford AIMI、Thyro-LMD、DDTI上训练独立的专家网络），然后通过对抗性对齐将这些多源专家网络的中间层丰富特征，融合蒸馏到一个统一的学生网络中。这能够极大增强主干网络对未知中心、未知设备的零样本泛化能力（Out-of-Distribution Generalization）。  

### 半监督与部分标签缺失场景下的架构优化机制

在混合数据集演练中，最棘手的问题在于“部分标签缺失”：例如在第二阶段，TN5000仅有检测框和分类标签，没有5大TI-RADS概念；而DDTI虽然有概念描述但样本规模偏小。如果使用传统的联合训练，缺失标签的损失流将导致回传梯度严重退化。  

针对这一问题，本研究设计了以下两点架构优化机制：

#### 多任务掩膜损失（Masked Task-Specific Loss）

为每个任务设计一个二值化的标签有效性控制掩膜向量 *M**t*,*i*∈{0,1}，标志第 *i* 个样本是否含有任务 *t* 的真实标注。在总体反向传播中，仅对存在真实标注的支路计算任务损失：

Lhybrid=*t*∈{*se**g*,*c**l**s*,*co**n**ce**pt*}∑*λ**t*(*i*=1∑*B**M**t*,*i*⋅L*t*(*Y**t*,*i*,*Y*^*t*,*i*))

其中 *λ**t* 为采用FAMO多任务调度算法动态计算的动态任务权重。此机制保证了TN3K的多任务数据加载时，分类与概念头的权重梯度会被精准遮罩，不会引起参数污染。

#### 半监督概念瓶颈对齐（SSCBM）

对于占绝大多数、不带真实ACR概念标签的样本（如TN5000和TN3K），模型在特征空间中采用半监督概念瓶颈模型（SSCBM）的优化逻辑。  

其基本机理如下：利用含有真实TI-RADS概念（Thyro-LMD和Stanford）的少量高质量子集作为锚定点（Anchors）；使用主干提取的视觉描述符与预训练CLIP文本编码器转换的临床语义特征进行余弦相似度度量，产生一个软伪概念标签（Soft Pseudo Concept Label）；再通过一个 *K*-最近邻（*K*-NN）特征网络传播将这些伪标签硬化。  

更进一步，引入空间一致性对齐损失（Alignment Loss），计算CBM预测分支各通道激活图与检测框/Mask空间分布的重叠度，限制概念响应只在结节所在的物理区域激活，从而防止概念解释出现无意义的语义幻觉。在僅有10%标注样本的情况下，该算法能将任务分类和概念预测精度拉回至全监督基线3%以内的极佳水平。  

### 下一步可执行验证方案

为了让研发团队高效地开始预演，本报告规划了明确的前置执行步骤：

第一步，通过斯坦福大学AIMI研究中心的数据门户，申请并完成研究使用协议的点击签署，拉取HDF5格式的 `dataset.hdf5` 及其元数据文件 `metadata.csv`（大小约为36.42 GB），部署至团队的Linux RTX服务器中。
