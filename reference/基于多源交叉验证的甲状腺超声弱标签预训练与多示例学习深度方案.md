# 基于多源交叉验证的甲状腺超声弱标签预训练与多示例学习深度方案

## 患者级弱标签的临床机理与单帧评估的物理瓶颈

在甲状腺超声影像的计算机辅助诊断中，将患者层面的病理学金标准直接广播至该患者的所有二维超声切面，构成了典型的弱监督学习瓶颈。临床超声扫查是一个连续且高度动态的交互过程，医生移动探头会产生包含数十张切面的影像序列。在这些庞杂的帧序列中，仅有极少数切面能够精准拦截到具有恶性病理诊断特征的病灶靶区，例如边界不规则、微钙化引起的点状强回声以及纵横比大于一等核心恶性声学表征。大量其余切面往往仅包含正常的甲状腺腺体实质、无病理特异性的实性回声区、或者由于声束物理局限性导致的各种非诊断性物理伪影。  

如果在此类弱标签分布下采用常规的强监督单帧图像分类方法，强制骨干网络将所有无诊断性特征的背景帧或良性切面拟合为恶性标签，优化器的梯度方向会被海量的噪声切面严重污染。骨干网络在这种训练模式下无法收敛至有效的诊断特征上，而是倾向于走捷径。在图像级随机划分的非严格交叉验证中，由于同一患者的多张超声帧被随机分流至训练集与验证集，模型会轻易捕捉到特定设备的探头参数、机器特有的斑点噪声模式、患者独特的皮下脂肪层厚度以及非诊断性背景纹理。这种基于物理和解剖背景的过拟合可以在验证集上刷出虚高的评价指标，例如将无泄漏状态下本应为极低的特征表现伪装成较高的幻觉指标。然而，一旦在临床部署或严格按患者物理隔离的验证机制下，这种患者特异性的背景关联瞬间瓦解，骨干网络暴露出其未掌握任何泛化判别力的本质，导致受试者工作特征曲线曲线下面积退化至接近随机猜测的物理极限。  

根据多中心及前沿文献的严格测评，在完全切断患者间交叉泄漏的前提下，直接在广播式弱标签上硬训单帧二维超声骨干网络的分类表现极其有限，其真实性能通常在极低区间内震荡。这意味着单帧图像在缺少病灶局部精确区域标注（如边界框或像素级掩码）且采用全局弱标签训练时，其可泛化的分类能力微乎其微。这是由于梯度更新的期望方向在有噪标签干扰下被完全中和。因此，通过多示例学习架构将一个患者的所有超声切面视为一个“包”，把无法推导的帧级预测权重的拟合过程转交给无监督或弱监督的包级特征聚合，不仅在算法逻辑上是成立的，而且在超声临床诊断的物理机理上也是必须跨越的门槛。  

## 适配弱标签超声的主干网络预训练与渐进式微调方案

由于本任务的数据规模相对较小，仅包含八百余例患者，若直接在带有严重标注噪声的广播弱标签下全量微调 ImageNet 初始化的骨干网络，会瞬间破坏浅层已经建立的具有强泛化能力的通用低级视觉特征，从而引发灾难性遗忘与表征坍塌。为此，本方案设计了分阶段渐进式优化通路，先进行线性探测以对齐分类边界，再实施精细化的分层学习率微调。  

### 双阶段训练机制与数值级超参数配置

在第一阶段，骨干网络完全冻结，锁死所有卷积和池化层，仅释放多示例学习特征聚合模块与末端全连接分类头进行训练。此阶段的目的是让新增的、随机初始化的聚合网络与分类头在超声图像的尺度分布上实现初步对齐。在第二阶段，全量释放 EfficientNet-B2 的参数，但必须实施分层学习率衰减策略，使得深层语义层与分类头采用相对较高的学习率进行局部自适应调整，而越往浅层视觉特征层学习率呈指数级衰减，以此保护底层的基本边缘与纹理提取器。  

针对配置了单张 A800 显卡、三十二吉字节显存、AdamW 优化器以及混合精度的工程环境，以下给出各训练阶段在数值级别上的精细配置指南：

### 针对超声影像特性的数据增强策略

超声成像在物理上存在极强的特殊性，例如斑点噪声（由于相干波干涉引起的乘性噪声）、声影（由于钙化或骨质导致声波无法穿透产生的下方暗区）以及操作压迫形变。数据增强的设计必须紧密贴合这些物理机理。  

本方案推荐采用的增强流水线包含：水平翻转，由于甲状腺叶的解剖结构和结节在横截面上具有镜像对称性，该操作能安全扩增样本且不破坏其临床诊断价值；轻度仿射变换，设定旋转角限制在正负十五度以内，缩放范围控制在九成至一点一倍，模拟扫查时探头的微小切面倾斜与解剖深度调节；弹性变形与网格畸变，设弹性系数 *α*=1、方差 *σ*=50、概率 *p*=0.2，可高度逼近医生手工施加探头压力时人体软组织的真实弹性力学形变；斑点噪声注入，引入均值为零、方差在万分之一至千分之五之间的乘性高斯噪声，以对齐不同超声设备在数字前端重建过程中的信号涨落差异。  

相对应地，本方案严厉禁止采用以下增强操作：垂直翻转，超声图像在垂直方向（深度轴）有着极为严格的物理和临床意义，最上方代表皮肤浅层，往下方深度递增代表气管、深部肌群与骨骼，垂直翻转会彻底颠覆结节向周边深层浸润的解剖学位置特征，并破坏纵横比诊断指标；大范围随机裁剪，由于部分原始切面中的结节占比极小，过于宽松的随机裁剪常导致裁剪框内仅包含背景软组织而丢失整个结节，从而将完全空扫的图像送入 MIL 中进行训练，造成严重的梯度偏离；剧烈的色彩扭曲与多通道强色差抖动，超声切面实质上为单通道灰度信号，非多普勒彩色血流混叠部分（占比极低）不需要彩色特征，盲目篡改伪彩色或三通道独立色差会大幅引入高频域噪点，削弱骨干网络对灰度对比度这一临床回声指标的分辨灵敏度。  

### 自监督预训练在小规模超声场景下的可行性与路线论证

针对当前八百余例患者的较小规模数据，直接从零开始利用自监督算法在无标签超声图像上重头训练主干网络，通常难以达到预期。像掩码自编码器这类生成式自监督算法，需要骨干网络重建被高度掩码丢弃的超声切面，其高度依赖极大规模和多维度的图像集才能学到可泛化的解剖边界，否则浅层重建层极易在小样本的高频超声斑点噪声上过拟合。  

因此，更为高效且具有工程可行性的方案是“两阶段域适应自监督预训练”。在这种策略下，首先继承在大规模通用数据集上经过充分预训练的视觉权重，接着使用本方案现存的八千五百张超声图像，在不接入良恶性标签的情况下，利用基于对比学习的无监督算法（如 SimCLR 或 MoCo-v2）对主干网络进行短暂的无监督对比学习预训练。这一过渡性预训练阶段能够有效促使模型摒弃对 ImageNet 中光学彩色纹理的偏置，并使其卷积层对超声特有的斑点结构、声阻抗界面边界建立自适应反应，随后再进行有监督的多示例学习微调，从而极大提升迁移效率。

## 门控双注意力多示例学习（MIL）聚合架构与工程实现

鉴于目前只能获取患者级的金标准标签，利用多示例学习框架将同一患者的多张超声图聚合成一个具有物理意义的特征向量，是实现端到端梯度的唯一可行通路。  

### 聚合算法架构选型论证：ABMIL vs TransMIL

在多示例特征聚合网络的设计中，注意力的建模精度直接决定了去噪的效果。  

- **注意力多示例学习 (ABMIL)**：利用两层前馈神经网络，通过门控注意力机制学习每个超声切面对最终病理决策的贡献权重，并输出注意力权重。它假设包中的各个实例在给定包特征的条件下条件独立，专注于抑制无关背景帧，对于甲状腺超声这种包长度较短（通常一个患者仅有 4∼15 张切片）的情形，其计算结构异常稳定且不易过拟合。  
- **Transformer 多示例学习 (TransMIL)**：通过引入自注意力机制对示例之间的空间和解剖关联进行显式建模。虽然 TransMIL 在处理病理整片扫描（WSI）这种包含数万个 Patch 的超大包上展现出强大的长程关联能力，但在甲状腺超声诊断中，图像包具有极短、离散的特点。在此场景下，过于复杂的自注意力层极易将斑点噪声和机器假象误判为切片间的主动关联，造成二阶特征空间的扭曲和严重过拟合。因此，本方案选择基于门控注意力池化（Gated Attention Pooling）的弱监督机制作为核心聚合算子。  

### 门控双注意力多示例学习数学解析

定义第 *i* 位患者（即一个包 *H**i*）包含 *n**i* 张超声切面图像：  

*H**i*={*h**i*,1,*h**i*,2,…,*h**i*,*n**i*}

首先，通过 EfficientNet-B2 骨干网络，将每张单通道超声图像特征映射为一个 *C* 维的实例特征向量（分类池化特征维度 *C*=352） [cite: user]：

**x***i*,*j*=EfficientNet-B2(*h**i*,*j*)∈R*C*

为了实现精准的特征聚合，门控注意力聚合层对每个提取出的实例特征向量进行空间非线性转换与门控交互。单个超声示例 *h**i*,*j* 的最终归一化注意力得分 *a**i*,*j* 算子定义如下：  

*a**i*,*j*=∑*k*=1*n**i*exp{**w***T*(tanh(**V****x***i*,*k**T*)⊙sigm(**U****x***i*,*k**T*))}exp{**w***T*(tanh(**V****x***i*,*j**T*)⊙sigm(**U****x***i*,*j**T*))}

其中，**V**∈R*L*×*C* 与 **U**∈R*L*×*C* 分别为平行的两路全连接映射权重，用于捕获实例特征的非线性关联并充当乘性控制门，超声特征投影维度设定为 *L*=128。**w**∈R*L*×1 为最终的线性投票权重向量，而 ⊙ 代表逐元素乘法，该算子相比单一的正切激活函数具有更强的梯度稳定性，能够自适应地对特征进行强力激活或深层抑制。  

通过对所有超声切面进行加权池化，生成该患者唯一的全局解剖表征向量 **z***i*∈R*C*：  

**z***i*=*j*=1∑*n**i**a**i*,*j***x***i*,*j*

这一聚合后的包特征特征向量将被最终输送给全连接分类头，由交叉熵损失函数引导端到端的梯度反向传播。  

### 工业级端到端 PyTorch 代码实现

Python

```
import torch
import torch.nn as nn
import torch.nn.functional as F
import timm

class GatedAttentionPooling(nn.Module):
    def __init__(self, feature_dim=352, attn_dim=128):
        """
        门控注意力多示例聚合层 (ABMIL)
        针对 EfficientNet-B2 的 352 维全局池化特征进行优化
        """
        super(GatedAttentionPooling, self).__init__()
        self.feature_dim = feature_dim
        self.attn_dim = attn_dim
        
        # Tanh 非线性通道分支
        self.attention_V = nn.Sequential(
            nn.Linear(self.feature_dim, self.attn_dim),
            nn.Tanh()
        )
        
        # Sigmoid 门控通道分支
        self.attention_U = nn.Sequential(
            nn.Linear(self.feature_dim, self.attn_dim),
            nn.Sigmoid()
        )
        
        # 注意力得分标量映射层
        self.attention_w = nn.Linear(self.attn_dim, 1)

    def forward(self, x):
        """
        Args:
            x (Tensor): [N, C], N 代表当前患者超声切片数, C=352
        Returns:
            bag_repr (Tensor): [1, C], 患者聚合后的全局向量
            weights (Tensor): [N, 1], 每张切片分得的归一化注意力值
        """
        # 1. 提取双通道特征并进行元素级融合实现门控控制
        v_out = self.attention_V(x)  # [N, L]
        u_out = self.attention_U(x)  # [N, L]
        gated_attn = v_out * u_out    # [N, L]
        
        # 2. 映射为原始标量得分并通过 Softmax 在切片维度归一化
        attn_scores = self.attention_w(gated_attn)  # [N, 1]
        weights = F.softmax(attn_scores, dim=0)    # [N, 1]
        
        # 3. 对包内所有示例进行加权求和，得到包层级特征
        bag_repr = torch.sum(weights * x, dim=0, keepdim=True)  # [1, C]
        return bag_repr, weights

class ThyroidUS2PathMILNet(nn.Module):
    def __init__(self, model_name='efficientnet_b2', pretrained=True, feature_dim=352, num_classes=2):
        """
        适配 512x512 单通道超声输入的高效多示例学习网络模型
        """
        super(ThyroidUS2PathMILNet, self).__init__()
        
        # 1. 实例化单通道主干网络, 确保 in_chans=1 接收单通道超声灰度图
        self.backbone = timm.create_model(
            model_name,
            pretrained=pretrained,
            in_chans=1,
            num_classes=0  # 去除骨干自带的 ImageNet 分类头
        )
        self.feature_dim = feature_dim
        
        # 2. 装配门控注意力多示例聚合层
        self.mil_pooling = GatedAttentionPooling(feature_dim=self.feature_dim, attn_dim=128)
        
        # 3. 最终患者级分类器
        self.classifier = nn.Sequential(
            nn.Dropout(p=0.3),
            nn.Linear(self.feature_dim, num_classes)
        )

    def forward(self, bag_tensor):
        """
        Args:
            bag_tensor (Tensor): 形状为 [N, 1, 512, 512] 的四维张量，
                                 代表单个患者的 N 张单通道 512x512 灰度超声图
        Returns:
            logits (Tensor): [1, num_classes]，包级良恶性诊断对数概率
            weights (Tensor): [N, 1]，各切面重要度权重，便于临床黑盒可视化解释
        """
        assert len(bag_tensor.shape) == 4, "输入必须是 shape 为 [N, 1, H, W] 的一个 Patient 包张量"
        
        # 1. 在骨干上逐帧映射，产生示例高维度特征
        # 由于 batch_size = N (通常 4 ~ 15), 满足 32G GPU 显存限制
        frame_features = self.backbone(bag_tensor)  # [N, C]
        
        # 2. 多示例门控加权聚合
        bag_feature, weights = self.mil_pooling(frame_features)  # [1, C], [N, 1]
        
        # 3. 分类诊断
        logits = self.classifier(bag_feature)  # [1, num_classes]
        return logits, weights
```

## 务实工程判断与演进式落地路线图

面对当前的零泛化困境以及即将于 2026 年底发布的官方数据，本方案不建议陷入无休止地对单帧强监督网络进行微调的泥潭中。必须迅速调整架构，并遵循高性价比的迭代路线。

### 第一阶段：多示例学习基准线搭建与数据划分锁死（1 至 2 周）

首要任务是彻底重构数据读取与划分流水线。废除随机 KFold 交叉验证，改为以 Patient 标识作为物理硬断点的严格五折交叉验证（Patient-split 5-Fold Cross Validation），确保任意患者的全部超声帧绝不发生跨折交叉泄漏。接着部署上述门控注意力多示例学习（Gated Attention MIL）聚合层，骨干保持 ImageNet 初始状态完全冻结，仅训练分类头。  

若第一阶段部署成功，模型在无泄漏划分下的患者级 AUC 指标必须突破当前的 **0.50** 死亡基准，达到 **0.65 ∼ 0.70** 的稳健区间。这一进展将验证实例聚合层已经成功识别出具有恶性判别力的单帧，并过滤掉了空扫背景帧。如果在第一阶段无论如何调优，患者级 AUC 依然被卡死在 0.60 以下，则说明当前超声灰度底图存在灾难性的物理损伤（例如：图像下采样至 512×512 的过程中，由于插值算法不当，直接抹平了极微小的微钙化高频强回声亮点）。此时应立刻暂停算法设计，重返最上游的数据源，重新审视并重新导出高清晰度的超声切片。

### 第二阶段：双阶段 LLRD 微调与超声特异性几何形变融入（3 至 4 周）

在第一阶段跨越 0.65 的基准阈值后，全面开启 LP → FT 双阶段微调机制。解冻 EfficientNet-B2 的卷积权重，按照本方案给出的分层衰减系数 *η*=0.75 配置 LLRD，以保护主干网络的底层卷积层。同步引入 Albumentations 的仿射、弹性形变、网格畸变以及斑点噪声注入增强流，以增强骨干在面对不同成像机型时的鲁棒性。  

在第二阶段微调结束后，模型在严格无泄漏评估下的患者级平均 AUC 预期将稳步推升至 **0.73 ∼ 0.76** 的前沿区间。

### 第三阶段：多源病理公开数据集联合灌注（5 至 6 周）

为了在官方比赛数据发布前构建具有强抗过拟合能力的超声骨干，必须通过数据灌注来突破单中心数据的规模局限。下载并整合 `ThyroidXL`（万张级别、四千例患者） 与 `TN5000` 数据集，将它们的数据特征空间通过统一的分辨率对齐和归一化，灌入已构建的 MIL 端到端训练网络中进行多中心联合弱监督预训练。  

经过第三阶段的大规模域特征联合预训练后，该骨干网络（去掉 MIL 分类头之后的高级特征提取层）对甲状腺结节各维度的超声表征（如回声级别、钙化形态、边界侵袭性）已建立起极具临床泛化力的表征敏锐度。此时，无泄漏患者级 AUC 的理论预测值将能够稳定站在 **0.78 ∼ 0.82** 的行业顶级高位区，从而为后期官方多任务学习系统的顺利收敛奠定最为厚实的 Backbone 迁移起点。

### 退出与终止判定阀值

在执行此落地路线时，如果在第三阶段联合训练结束后，主干网络在无泄漏评估下的最优 AUC 依然处于低于 **0.62** 的偏低状态，说明该 8500 张公开数据集本身的扫查质量与未来 2026 年发布的高规格官方比赛数据可能存在严重的源域分布断层（例如：该 figshare 27021604 数据集中包含了大量质量极差的 RTE 弹性图且多普勒叠加混叠比例严重污染了骨干认知）。一旦触发此性能卡点，则不应再浪费时间于该批公开数据的预训练上，应当果断将 Backbone 封存至基础 ImageNet 水平，并保留本方案已跑通的 MIL 聚合代码，将全部精力转向多任务（分割与概念识别）联合框架的纯架构设计上，静待高品质官方大数据的正式发布。
