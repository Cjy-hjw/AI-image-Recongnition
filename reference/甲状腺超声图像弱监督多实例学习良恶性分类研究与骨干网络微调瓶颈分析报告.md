# 甲状腺超声图像弱监督多实例学习良恶性分类研究与骨干网络微调瓶颈分析报告

## 弱监督多实例学习的 Fine-tuning 上界与基准分析

在利用 ImageNet 预训练骨干网络（Backbone）配合患者级弱标签（非帧级精确标注）进行多实例学习（Multiple Instance Learning, MIL）的场景下，解冻骨干网络进行端到端微调（Fine-tuning）并不总是能取得优于冻结骨干网络的表现。在计算病理或放射超声等大图像域、高比例无关背景噪声的弱监督任务中，直接端到端微调极易导致模型过拟合于噪声实例，进而引发严重的泛化退化与表征漂移。  

为了定量评估这一任务的性能空间，本研究梳理了医学图像及弱监督多实例学习领域的典型基准表现。在病理全切片图像（WSI）及超声多帧图像分类任务中，冻结特征提取器并使用对比自监督学习（Contrastive SSL）或领域自监督学习获得的特征，其分类器 AUC 往往能达到 0.80−0.95 的高水平。然而，在完全没有细粒度空间标注且仅依赖患者级弱标签的条件下，如果直接对 ImageNet 预训练骨干网络进行端到端解冻微调，由于领域差距（Domain Gap）与弱监督梯度稀疏性，其 AUC 的典型范围通常会受限于 0.65−0.78 之间。表1汇总了典型弱监督医学图像分类任务中不同微调策略与池化机制的基准表现对比：

由表1可知，针对 figshare 27021604 这一甲状腺超声数据集，官方基准模型 ThyUS2Path（基于五折交叉验证）给出的最高性能上界为内部测试集 AUROC=0.754±0.035，外部独立验证集（Batch 2）AUROC=0.735±0.029。  

相比之下，目前实验中 Phase 1（冻结 EfficientNet-B2，仅训练分类头与 Gated-ABMIL）获得的 best_patient_val_auc=0.5653 与官方公开的基准性能存在显著差距 [cite: Background, 65, 115]。这表明当前的网络架构、空间特征过滤或数据输入流程中存在严重的特征损耗，未能充分释放骨干网络的判别潜力。  

## 骨干网络解冻失效与表征漂移机制

层级学习率衰减（Layer-wise Learning Rate Decay, LLRD）策略在 Phase 2 的解冻微调中失效，且表现出验证集 AUC 在 0.46 - 0.56 之间剧烈震荡的现象，其本质是由多实例学习中固有的选择性漂移（Selection Drift）与灾难性遗忘（Catastrophic Forgetting）机制导致的。  

### 弱监督 MIL 中 LP-FT 策略的表征崩溃原理

传统的 LP-FT（Linear Probing then Fine-Tuning）策略通过先训练线性分类头（LP）建立稳定的分类边界，再以极低的学习率解冻骨干网络（FT），从而在减少特征畸变（Feature Distortion）的同时实现领域对齐。然而，在医学弱监督多实例学习任务中，这一机制经常面临失效。其核心原因在于**监督梯度的不确定性反馈**：  

在多实例学习中，一个患者包 **X***i*={**x***i*,1,**x***i*,2,…,**x***i*,*N*} 仅关联一个包级标签 *Y**i*∈{0,1}。在注意力多实例学习（ABMIL）框架中，包级的类别预测概率 *Y*^*i* 是由各实例（超声帧）特征 **h***i*,*j*=*f**θ*(**x***i*,*j*) 经过注意力权重 *a**i*,*j* 加权融合后得到的：  

**z***i*=*j*=1∑*N**a**i*,*j***h***i*,*j*,*Y*^*i*=*g*(**z***i*)

其中注意力权重由门控机制（Gated Attention）动态计算 [cite: Background, 143]：

*a**i*,*j*=∑*k*=1*N*exp(**w**⊤(tanh(**V****h***i*,*k*⊤)⊙*σ*(**U****h***i*,*k*⊤)))exp(**w**⊤(tanh(**V****h***i*,*j*⊤)⊙*σ*(**U****h***i*,*j*⊤)))

当骨干网络参数 *θ* 被解冻时，损失函数 L 对 *θ* 的梯度回传会受到注意力权重的直接调制：  

∂*θ*∂L=*j*=1∑*N*(∂**h***i*,*j*∂L+∂*a**i*,*j*∂L∂**h***i*,*j*∂*a**i*,*j*)∂*θ*∂**h***i*,*j*

在微调初期，由于骨干网络基于 ImageNet 预训练，无法精准识别超声结节等特定领域的病理表征，导致分配给各个实例的注意力权重 *a**i*,*j* 极不准确，通常会将高权重赋予图像中的机器标注字符、黑边、测量卡尺（Crosshair Markers）或耦合剂反光等无判别意义的强对比度伪影（即 Simplicity Bias 易用性偏置）。  

一旦骨干网络被解冻，这些错误的注意力权重会将强烈的噪声监督信号强制反向传播至骨干网络的深层卷积层。模型为了迅速最小化包级损失，会扭曲骨干网络中原有的通用几何与纹理特征提取能力，使其特征空间发生畸变（Feature Distortion），导致验证集表现剧烈震荡并迅速崩溃，发生典型的“选择性漂移”与灾难性遗忘。  

### 替代方案的有效性分析

针对这一瓶颈，近年来学界主要采用参数高效微调（PEFT）策略和渐进式解冻架构来稳定表征空间：  

1. **LoRA 与 OWLoRA (正交加权低秩自适应)：** LoRA 通过在骨干网络的注意力层或投影层旁路引入低秩矩阵乘积 Δ**W**=*r**α***BA**（其中 **B**∈R*d*×*r*,**A**∈R*r*×*k*,*r*≪*d*）来限制梯度更新的空间。在 2025 年提出的 CoMEL 框架中，研究者利用正交加权低秩自适应（OWLoRA）限制新增参数的更新方向与历史任务或预训练通识特征正交，在病理 WSI 分类和定位任务中有效抑制了弱监督导致的表征漂移，包级准确率提升了高达 11%。  
2. **LP-FT-LoRA 三阶段微调框架：** 针对 Bangali NLP 与医疗垂直域的迁移不稳定性，研究者提出了 LP-FT-LoRA 三阶段微调协议：  
   - *第一阶段：* 完全冻结骨干，仅训练分类头与注意力池化层（LP），建立基准包级对齐。  
   - *第二阶段：* 冻结分类头，激活 LoRA 旁路，引导骨干提取器向目标超声纹理进行低维自适应对齐。  
   - *第三阶段：* 使用极低的学习率（例如 1×10−5）对分类头与 LoRA 旁路进行短暂的联合微调（Joint Refinement），从而彻底隔绝了对基础特征空间的畸变污染。  

## 图像分辨率与特征损耗的临床病理学关联

甲状腺乳头状癌（PTC）在超声声像图上的判别特征非常细微，临床实践中常依赖边缘毛刺（Irregular Margins）、极低回声（Profound Hypoechogenicity）、纵横比大于 1（Aspect Ratio ≥1）以及微钙化（Microcalcifications，声像图上表现为点状强回声，通常直径小于 1 mm）等声学表征来做出恶性诊断。  

### 512x512 分辨率与微钙化特征损耗

将超声帧图像分辨率下采样到 512×512 本身，并不会彻底抹去全部的微钙化点（对于 10 MHz 探头提取的原始图像，微钙化在 512×512 分辨率下通常仍能占据 2×2 至 4×4 像素的斑点空间）。**真正导致微钙化等关键判别特征丢失的，是当前代码架构中的“特征预池化（Pre-pooling）”操作** [cite: Background, 142]。  

根据 Grounding 代码上下文分析，当前的分类架构如下 [cite: Background]：

Python

```
# timm efficientnet_b2, in_chans=1, num_classes=0 -> 1408-dim
# feature_dim=1408 (EfficientNet-B2 pooled)
```

当 `timm.create_model` 中的 `num_classes=0` 时，模型在输出前会对最末端的卷积特征图进行全局平均池化（Global Average Pooling, GAP） [cite: Background]。对于输入的 512×512 Grayscale 图像，EfficientNet-B2 的末端特征图（Feature Map）尺寸通常为 16×16×1408 [cite: Background]。

这意味着，图像级的高频空间激活值（例如代表微钙化点、边缘侵犯毛刺等高频声学界面反射的极高回声极值点，在特征图上可能仅表现为 1×1 或 2×2 的高亮特征响应）会在进入多实例注意力层（`GatedAttentionPooling`）之前，**先在帧内经历一次全图均值化抹平** [cite: Background, 142]。

由于全局平均池化将 16×16=256 个空间位置的信息强制取了平均值，这些细微但致命的恶性病理反射特征就会被稀释 256 倍，进而完全淹没在周围腺体、肌肉等正常回声的背景噪声中。最终，多实例分类器接收到的只是被均值化后的实例特征向量，这也是单帧 CE 预训练 AUC 卡死在 0.50（即随机猜测天花板）的根本症结所在 [cite: Background]。

## 骨干网络自监督预热与领域适应策略

在等待官方强监督标注数据发布前，针对超声特定域开展自监督预训练（Self-Supervised Learning, SSL），是解决 ImageNet 初始权重与超声图像成像机制（斑点噪声、伪影阻抗、灰度单通道）严重失配的关键策略。  

### 适用于甲状腺超声领域的自监督表征算法

由于缺乏图像级定位标注，当前阶段可以引入以下三种在无标签超声/医学影像任务中被实证高效的无监督预学习方案：  

1. **多视角对比自监督学习 (Multi-View Contrastive SSL):** 在超声临床采图中，医生通常会针对同一个甲状腺结节从横切面（Transverse View）和纵切面（Longitudinal View）进行多角度扫查。利用 2024 年提出的多视角自监督对齐机制，可以将同一病灶不同扫描切面的图像对定义为正样本对（Positive Pairs），将不同患者或不同结节的切面图像定义为负样本对（Negative Pairs）。通过引入 InfoNCE 损失进行跨视角对比学习，迫使模型对视角的空间旋转表现出不变性，从而学到真正与病理结节拓扑结构相关的深层声学表征。在多中心甲状腺公开集上的实验表明，经过此类跨视角对齐预热后，下游分类微调的收敛速度和 AUC 显著超越了单纯的 ImageNet 预训练。  
2. **掩码自编码器重建预学习 (Masked Autoencoder, MAE):** 基于 Vision Transformer（ViT）或层次化 CNN 架构，可引入 MAE 重建机制进行像素级自监督训练。将无标签的超声图像块进行高达 75% 比例的空间掩码遮蔽，强制解码器（Decoder）重建受损的斑点纹理与连续的结节边界。在 AIMI 和 TN3K 数据集上的预训练实证表明，尽管由于无标签数据的异质性，MAE 重建所带来的直接分类 AUC 提升可能较为平缓，但其为模型提供了极佳的空间纹理感知能力，能使下游分割与分类联合训练时的收敛过程显著加速。  
3. **基于 DICOM 元数据的弱监督领域迁移 (Weakly-supervised Metadata Learning):** 超声设备输出的原始 DICOM 图像中通常富含大量的物理元数据（如声波阻抗频率、扫查深度、时间序列、增益参数等）。Hu 等人在弱监督自监督研究中指出，可以将这些易于批量获取的物理属性定义为连续或离散的“伪弱标签”，引导骨干网络预测扫查深度或频率分类。这种物理约束预训练能引导特征提取器建立对真实声学衰减、声影和后方回声增强等超声物理效应的底层敏感性，极大地改善了跨医院、跨设备（如 GE、Hitachi、Aloka 等不同扫描仪）多中心数据的特征鲁棒性。  

## 结论与具体的工程微调策略方案

### 明确回答与战略建议

**在当前的实验条件下（842名患者，512x512 Grayscale 图像输入，以及目前无空间注意力的 Gated-ABMIL 架构下），对 Phase 2 阶段进行全参数解冻或简单的 LLRD 骨干网络微调绝对不值得继续投入算力优化。**

在当前的架构设计中，骨干网络末端存在的全局平均池化（GAP）预降维操作已经从物理上抹除了微钙化及边缘浸润等至关重要的空间微观纹理 [cite: Background, 142]。此外，多实例学习包级损失的梯度稀疏性导致的选择性漂移，在端到端训练时极易污染骨干网络的预训练权重。继续优化目前的 Phase 2 会导致分类器反复在灾难性遗忘与噪声过拟合之间震荡。  

然而，这并不意味着应该放弃等待官方数据，而是应该立即对模型架构实施**无监督/弱监督空间对齐重构**，并切换至参数高效微调（PEFT）路线。  

### 如果建议继续：当前数据集的重构与具体微调策略

为了在无精确标注的当前数据集上突破 0.5653 的 AUC 瓶颈并逼近 ThyUS2Path 官方的 0.735−0.754 基准 [cite: Background, 65, 115]，必须立即执行以下重构方案：

#### 1. 架构改造：规避特征预池化，引入空间自注意力图

必须移除 `timm` 输出时的 `num_classes=0` (GAP) 机制 [cite: Background]。骨干网络应直接输出三维的卷积特征图（对于 EfficientNet-B2，尺寸为 *H*×*W*×*C*=16×16×1408） [cite: Background]。设计一个轻量级的空间注意力（Spatial Attention）子模块，显式计算帧内各个空间坐标的注意力图，以此保持局部高频钙化灶特征不被均值化抹除：  

**M**spatial=*σ*(**W**2⋅ReLU(**W**1⋅**F**backbone))

将特征图在空间上进行加权合并，生成未退化的 1408 维特征向量，再将其送入 `ThyroidMILNet` 的实例级池化层 [cite: Background, 2, 47]。

#### 2. 微调机制：实施三阶段 LP-FT-LoRA 策略

为了彻底解决梯度不一致导致的特征畸变，应转为三阶段参数高效微调协议：  

- **LoRA 注入配置：** 在 EfficientNet-B2 骨干网络的深度投影层与 Conv 算子旁路注入 LoRA 层，配置秩 *r*=8，缩放系数 *α*=16，LoRA 丢弃率设置为 0.1。  
- **优化器与基本设置：** 采用 AdamW 优化器，一阶、二阶动量系数 *β*1=0.9,*β*2=0.95，基础权重衰减权重设置为 0.05。

### 如果建议放弃：官方标注数据发布后的最优微调策略

当 2026-08-01 官方发布包含精准图像级结节边界框（Bounding Box）或结节轮廓分割标注的强监督数据集后，多实例学习弱标签范式应迅速升级为两阶段强监督目标检测辅助分类范式：  

#### 1. 强监督结节感兴趣区域（ROI）提取网络训练

- **模型选型：** 采用 YOLOv11-OBB（旋转边界框检测器）或两阶段 Faster R-CNN。  
- **输入与标注：** 利用像素级标注或边界框作为强监督目标，训练模型精准过滤超声图像中的文字、黑边、气管伪影等无关背景噪声，实现精准的结节 ROI 定位与剪裁。  
- **预处理优化：** 所有的多帧超声输入在进入分类网络前，一律被裁剪为包含病灶结节本身以及向外拓宽 10% 的外周浸润上下文区域（Context Edge），并统一缩放至标准的 256×256 分辨率。  

#### 2. ROI 节点与多局部上下文图神经网络分类框架（ROI + Context GNN）

放弃无空间位置感知的传统多实例学习（MIL）特征池化机制，采用近年来在甲状腺超声诊断中表现极其稳定的非局部图关系神经网络：  

- **特征提取器：** 采用在超声自监督数据上预热过的 ResNet-50 骨干网络，对结节 ROI 裁剪图和外周关键区域进行特征提取。  
- **建图机制：** 将每个患者的超声检查定义为一个小型的异构图 G=(V,E)，其中“结节主 ROI 图像块”作为核心主节点，“外周边沿浸润局部图像块”作为上下文节点（Context Nodes）。  
- **关系传递与融合：** 使用图神经网络层（如 GraphSAGE，参数聚合选用双向注意力机制）显式融合结节的内部纹理特征（微钙化、内部回声）与边缘关联特征（声影、晕征、包膜浸润）：  

**h***i*(*l*+1)=Aggregation(**h***i*(*l*),{**h***j*(*l*),∀*j*∈N(*i*)})

- **分类机制：** 在图的全局读出层（Readout）使用带有温度标定的多层感知机（MLP Classifier with Temperature Scaling）输出最终的良恶性病理确诊概率，以保证模型预测概率的临床置信度。  

这一强监督与空间关系网络相结合的范式，可以彻底避开弱监督 MIL 带来的梯度混淆，是使模型分类 AUC 跨越 **0.90** 门槛并达到临床实际可用标准的黄金路线。
