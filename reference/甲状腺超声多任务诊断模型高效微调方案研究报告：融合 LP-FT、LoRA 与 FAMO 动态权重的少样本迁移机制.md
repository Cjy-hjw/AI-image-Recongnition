# 甲状腺超声多任务诊断模型高效微调方案研究报告：融合 LP-FT、LoRA 与 FAMO 动态权重的少样本迁移机制

> **📌 报告元信息（后续 agent 必读）**
> - **入库日期**：2026-07-09
> - **适用场景**：LoRA 微调支线（`scripts/train_thyroidxl.py` 的 LP-FT-LoRA 训练配方）；其 LLRD 数值（η_cls≈0.82 / η_seg≈0.85）对后续三头训练仍具参考价值。
> - **结论现状**：**有效** —— LP-FT/LoRA/LLRD 方案经 v2 合并权重验收（CPU/GPU 一致性 + LoRA-vs-合并一致性 + 真实 predict.py 链路 AUC=0.8514）验证可信。

在临床超声影像诊断中，甲状腺结节的识别与病理性质评估面临着极高的技术挑战。超声图像特有的低对比度、严重的声学斑点噪声（Speckle Noise）以及病灶边缘模糊，使得依靠深度学习进行精确的结节分割与良恶性鉴别极其困难。在多任务竞赛场景下，官方提供的数据集规模通常十分有限（预计在 500 至 2000 例之间），且受限于合规性要求，数据无法本地保留。此外，由于超声检查的动态性，数据集通常由 JPG 静态图与 MP4 动态视频流混合组成，且存在大量的标注缺失。为了在如此苛刻的少样本约束下实现多任务模型的高效微调，并保护 ImageNet 预训练的泛化先验不被破坏，本报告针对双主干解耦架构，构建了一套将线性探测后微调（Linear Probing then Fine-Tuning, LP-FT）、低秩自适应（Low-Rank Adaptation, LoRA）、快速自适应多任务优化（Fast Adaptive Multitask Optimization, FAMO） 以及正则化丢弃（Regularized Dropout, R-Drop） 深度融合的级联微调技术方案。

## 线性探测与全面微调策略的理论演进

传统的微调范式通常直接对预训练模型进行全量更新，然而在下游任务数据集规模较小且分布差异较大时，这种方法往往导致模型性能不佳。学术界的研究表明，直接进行全量微调在目标域内（In-Distribution, ID）表现尚可，但在域外（Out-of-Distribution, OOD）数据上的表现通常显著差于简单的线性探测（Linear Probing, LP）。

其理论根源在于“特征畸变效应”（Feature Distortion Effect）：在微调初期，由于分类或分割头部参数是随机初始化的，其产生的随机梯度会以极大的幅度回流至特征提取器（Backbone）中。为了拟合目标域的训练集损失，骨干网络原有的、具备强泛化能力的预训练表征会被严重破坏，迫使其特征流向特定目标域的局部流形靠拢。这在仅有数百例的甲状腺超声场景下，会导致模型过度拟合特定探头型号、扫描切面和声学伪影，在验证集和盲测集中表现出灾难性的性能崩溃。

为了从根本上消除特征畸变，Kumar 等人提出了线性探测后微调（LP-FT）的两阶段策略。该方法首先保持骨干网络冻结，仅训练线性头部使其对齐目标域的流形空间；在头部获得良好初始化后，再解冻骨干网络进行全量微调。本方案针对 PyTorch 甲状腺多任务解耦模型，对 LP-FT 进行了定制化演进。

### 第一阶段（Linear Probing）训练范围与决策机制

在第一阶段（LP），必须完全冻结分类骨干 `cls_backbone`（EfficientNet-B2）和分割骨干 `seg_backbone`（ConvNeXt-Nano）的所有参数。这一阶段的关键在于明确哪些新设的参数层需要参与训练：

- **概念瓶颈层与良恶性头（ConceptEmbeddingCBMHead）**：概念瓶颈模型（CBM）的机制是将高维特征首先投影到 13 类临床 TI-RADS 概念属性空间（如微钙化、边缘不规则、极低回声等），再通过一个线性映射得到恶性概率。在 LP 阶段，**必须将 CBM 概念嵌入层与最终的恶性决策头作为一个整体进行联合训练**。若只训练最后一层分类头，由于底层的概念投影矩阵未经过初始化对齐，高维超声特征将无法映射到具有解剖学意义的 TI-RADS 概念流形上。
- **多分类序数头（Ordinal Heads）**：成分、回声、形态、边缘等 4 个序数分类头属于新增的任务特定层，必须在第一阶段参与训练，使其梯度在局部达到亚稳态。
- **分割解码器（Segmentation Head）与任务对齐适配器（TaskAlignmentAdaptor）**：上采样 decoder、1x1 投影卷积层以及用于实现分割特征向分类分支注入的单向适配模块。由于 `TaskAlignmentAdaptor` 执行了 `detach()` 操作，分割分支在第一阶段的单独训练将为分类分支提供高质量的、不受分类梯度污染的空间特征指导。

### LP 阶段切换阈值与早停判据设计

在 500 至 2000 例样本的数据尺度下，若 LP 阶段Epoch数过少，头部参数将无法逼近局部最优解，导致第二阶段全量微调开始时特征畸变依然发生；若 Epoch 数过多，由于新加的头部参数容量较小，会在目标域上快速发生局部过拟合。

本方案设计了一套双轨早停判据系统。第一阶段的目标是使验证集上的多任务综合效能指标达到饱和。定义验证集综合效能指数 $I_{val}$：

$$I_{val} = 0.6 \cdot \text{AUC}_{patient} + 0.4 \cdot \text{Dice}_{image}$$

训练过程中同时监控 $I_{val}$ 与总验证损失 $\mathcal{L}_{val}$。第一阶段的训练 Epoch 上限设为 12。触发向第二阶段（FT）切换的条件为：

1. **性能饱和触发**：验证集综合指数 $I_{val}$ 连续 2 个 Epoch 的绝对提升量低于 $1 \times 10^{-3}$；
2. **损失回弹触发**：验证集总损失 $\mathcal{L}_{val}$ 连续 2 个 Epoch 停止下降并表现出上升趋势（回弹幅度 $>1.5\%$）。

一旦满足上述任一条件，即刻终止第一阶段，将此时的任务头与适配器参数保存作为 Stage 2 优化的起始权重。

## 双骨干网络架构分层学习率衰减（LLRD）对齐方案

在第二阶段（FT）解冻骨干网络时，不能采用单一的全局学习率。由于卷积神经网络在不同深度上捕获的视觉特征具有高度分化的层次性：浅层网络提取的是通用的边缘、纹理、色调等低级特征，这些特征极具普适性，应当被最大程度地保留；深层网络则负责组合提取高级的语义表征，这部分表征具有强烈的域特异性，必须根据目标域进行大幅度调整。

分层学习率衰减（Layer-wise Learning Rate Decay, LLRD）通过为不同深度的层级分配呈几何级数递减的学习率，自深至浅锁住预训练先验，在少样本超声微调中能够发挥极其关键的正则化作用。根据经典实践，第 $l$ 层的实际学习率表示为：

$$lr_l = lr_{base} \cdot \eta^{(L_{max} - l)}$$

其中 $\eta \in (0, 1)$ 为衰减因子， $L_{max}$ 为网络最大深度索引，$l$ 为当前层的深度索引。针对本模型的两个完全解耦的主干网络，本方案设计了差异化的 LLRD 拓扑结构：

### 1. 分类主干 EfficientNet-B2 的 LLRD 参数设置

EfficientNet-B2 核心由 7 个 MBConv 模块阶段（Blocks 0-6）组成，加上输入 Stem 和输出 Conv/BN，整体拓扑按深度从深到浅划分为 9 个逻辑层级。考虑到 EfficientNet 包含较多的深度可分离卷积，其通道扩展层对特征抖动极为敏感，衰减因子设计为较为保守的 $\eta_{cls} = 0.82$。推荐分类基础学习率 $lr_{base\_cls} = 5 \times 10^{-4}$。

## LoRA 适配器注入与多任务参数拓扑设计

低秩自适应（LoRA）通过在冻结的线性权重或卷积层旁引入并行的可训练低秩分支，极大地减少了微调阶段的可训练参数量。在计算资源受限、超声图像域转移显著的竞赛环境中，LoRA 的引入能显著稳定多任务联合更新的轨迹。

### 1. 骨干网络的 LoRA 注入模块选择

为了使参数调优最为高效，LoRA 的适配器模块必须精准定位在两套主干网络中特征交换最稠密、语义承载度最高的网络瓶颈处：

- **EfficientNet-B2**：MBConv 模块由 $1 \times 1$ 通道扩展卷积（`conv_pw`）、深度可分离卷积（`conv_dw`）和 $1 \times 1$ 通道收缩投影卷积（`conv_pwl`）级联而成。本方案**推荐将 LoRA 适配器（PEFT 库支持的 `Conv2d` LoRA 算子）插在每个 MBConv 块的 Pointwise 卷积 `conv_pw` 和 `conv_pwl` 上**。深度可分离卷积 `conv_dw` 只负责捕获局部空间关联且参数量极小，不适合进行低秩分解；而 $1 \times 1$ 的 pointwise 卷积承载了通道之间 90% 以上的非线性映射和特征融合，在此处注入 LoRA 能够以最低的开销调整多任务高维特征的解耦方向。
- **ConvNeXt-Nano**：ConvNeXt 的 Stage 内部主要由一个深度卷积和紧随其后的 MLP 模块（包含两个线性层 `mlp.fc1` 和 `mlp.fc2`）组成。本方案**推荐将 LoRA 适配器插入 MLP 模块的 `mlp.fc1` 和 `mlp.fc2` 线性投影层上**。这不仅避开了对稀疏的局部深度卷积的调整，还能直接在 ConvNeXt 的本征瓶颈空间中引入任务自适应偏置。

### 2. 针对少样本（500-2000 例）的 LoRA 超参数拓扑规律

在多任务多头部、样本量级极小的特定应用场景下，LoRA 的 Rank $r$ 与 Alpha $\alpha$ 会对模型的表征能力与泛化性能产生决定性的影响。

| **Rank (r) 参数配置** | **Alpha (α) 配置** | **可训练参数占比** | **针对甲状腺超声少样本的多任务经验规律**                     |
| --------------------- | ------------------ | ------------------ | ------------------------------------------------------------ |
| **$r=4$**             | $\alpha=8$         | $\approx 0.4\%$    | **欠拟合与任务负迁移发生**：特征空间的表征能力和秩容量严重不足，分类与分割分支不得不强行共享相同的浅层特征表征，直接导致分割 Dice 指标和分类 AUC 的双重退化。 |
| **$r=8$**             | $\alpha=16$        | $\approx 0.9\%$    | **多任务平衡黄金点**：在限制可训练参数规模以防止过拟合的同时，低秩空间恰好能容纳由超声图像中复杂的组织边界和高维病理属性引起的流形扰动，实现分类与分割特征的和谐解耦。 |
| **$r=16$**            | $\alpha=32$        | $\approx 1.8\%$    | **局部过拟合风险剧增**：模型开始在冻结的 ImageNet 表征之外挖掘并拟合超声图像特有的物理缺陷（如探头滑动产生伪影、图像边缘字符等），导致域外（OOD）测试指标剧烈下滑。 |



本方案推荐的黄金配置为：**Rank $r=8$，Alpha $\alpha=16$，LoRA 丢弃率设置为 $0.1$**。

### 3. LoRA 参数与 FAMO 动态权重的优化器兼容拓扑

FAMO（Fast Adaptive Multitask Optimization）在每一轮迭代中，通过对不同任务损失的历史动态进行对数改进率评估，来更新各个任务的实时权重。由于其具有极佳的 $O(1)$ 空间与时间效率，非常适合边缘算力环境。

在模型适配 LoRA 结构后，**LoRA 参数必须和主干中被解冻的底层权重共用同一个优化器，但被切分到不同的参数组（Parameter Groups）中**：

- **共用优化器的必然性**：FAMO 在计算任务权重的更新时，极度依赖整个网络梯度的全局投影和瞬时状态。若将 LoRA 独立至另一个优化器，会导致两套优化器的更新轨迹去耦，从而使 FAMO 在计算对数损失改进梯度时，无法捕获 LoRA 分支参数变化对骨干特征表示的瞬时纠偏效应，使动态加权机制退化为普通的标量缩放。
- **参数组划分的设计**：在 PyTorch 的 `Optimizer` 中，必须为每个解冻的主干 Stage 及其嵌入的 LoRA 权重、各任务头分别构建独立字典，从而使得 LLRD 机制可以顺利将不同的学习率缩放比例应用到各自对应的可训练参数层上。

## 多任务微调顺序与标签缺失治理

超声多任务竞赛数据往往存在双重缺陷：一是样本量有限；二是存在严重的多任务不完整标注现象（如部分样本仅有良恶性分类标签而缺乏手工分割 Mask，或反之）。如何设计多任务训练顺序以及如何合理处理这些缺失标签，是提升微调表现的关键。

### 1. 联合多任务微调（Joint MTL） vs. 级联微调

学术界在医学影像处理中常常倾向于“先训分割，后迁移分类”的级联方案。然而，针对本模型中特殊的 `TaskAlignmentAdaptor`（分割特征 `detach()` 后注入分类分支，避免分类梯度回流影响分割表征）设计，**本方案坚持从第一轮起就执行双任务完全联合微调（Joint MTL）**。

- **级联优化的弊端**：若在第一阶段仅训练分割分支，骨干网络会被强制收敛到纯粹关注结节几何物理边界的亚空间中。此时，虽然分割指标极佳，但是由于超声结节良恶性评估所依赖的微观语义表征（如点状钙化、纵横比、弹性系数等）在单纯的几何边缘检测中并无高额损失惩罚，这些细粒度分类特征在 backbone 中将被过早过滤。当第二阶段接入分类任务时，受限于已经被强化的几何特征空间，分类网络将难以拟合，面临严峻的多任务冲突。
- **联合微调的协同效应**：在 FAMO 的实时平衡协调下，网络能够自适应地探索两个任务特征空间的交叉流形，`detach()` 机制又完美隔绝了分类分支的嘈杂梯度流入分割主干，从而在不影响分割性能的前提下，为分类分支提供了稳定、高质量的空间上下文辅助。

### 2. 缺失标注治理：半监督伪掩膜（Pseudo-Mask）生成算法

虽然在缺失分割标签的样本上可以利用 Masked 多任务损失将分割部分的梯度设为零，但这忽略了这部分图像中同样蕴含的几何边界信息。由于超声数据包含 MP4 动态视频流，可引入基于 Medical SAM 2 (MedSAM-2) 或经典 MedSAM 的主动伪掩膜生成算法，对无分割标签的样本进行数据增强。

#### 伪标注构建机制

```
[步骤 1: 关键帧定位] ──► 选择 dynamic cine 视频流中含有专家手工标注的极少数关键帧。
                             │
                             ▼
[步骤 2: 时序双向传播] ──► 使用 SAM2 的 Memory Attention Module 沿着时间轴
                           向前、向后进行双向传播，对其余无标签视频帧自动生成掩膜。
                             │
                             ▼
[步骤 3: 边界框弱监督] ──► 针对只有良恶性分类、完全缺失分割的静态 JPG 图像：
                           1. 提取分类分支 ConceptEmbeddingCBMHead 在特定超声属性上的高响应特征图。
                           2. 利用检测器或阈值法生成一个包含结节的最小外接 bounding box。
                           3. 将其作为 Box Prompt 输入 MedSAM 自动推断结节边界。
                             │
                             ▼
[步骤 4: 概率置信度过滤] ─► 仅保留预测概率大于 0.85 的像素点作为伪标签 (Label = 1)；
                           保留低于 0.15 的像素点作为背景伪标签 (Label = 0)；
                           中间过渡灰度区域标记为 -100，完全不参与分割损失计算。
```

- **时序双向传播机制**：超声动态 cine 视频流中包含着丰富的帧间时序关联，各帧之间的组织几何形态高度连续。通过调用 `MedSAM-2` 的“One-prompt Video Propagation”模式，将同一视频中已知极少数关键帧的 Mask 作为 prompt 注入。利用其 Memory Attention Module 在时间步上建立长短期特征依赖，可以在无人工干预下获得整段视频所有帧的高精度伪 Mask。
- **边界框弱监督生成机制**：针对完全没有分割标注、只有良恶性病理结果的静态 JPG 图像，利用弱监督定位思想。首先提取分类骨干网络的高层特征图，通过 Grad-CAM 或直接利用 CBM 头中属性高频激活的特征层，生成粗糙的结节疑似区域 bounding box。接着，将该自动生成的弱监督框作为 Box Prompt 传给微调过的 `MedSAM` 模型，从而在图像上自动推断出高水平的结节边界作为伪分割 Mask。
- **可信度阈值过滤（Confidence Masking）**：为了杜绝半监督伪标签中引入的边缘噪声对 `seg_backbone` 的干扰，伪标注不直接作为硬标签。对 MedSAM2 输出的掩膜概率图 $P_{mask}(x, y)$ 进行动态切分：设定 $P_{mask} > 0.85$ 的区域为确定前景（Label=1）， $P_{mask} < 0.15$ 的区域为确定背景（Label=0），中间不确定的边缘模糊区域全部设为忽略目标（PyTorch Loss 中的 `ignore_index=-100`）。在反向传播中，这些区域的 Dice 与 BCE 损失被完全屏蔽，从而最大化保护模型的边界泛化能力。

## 极小样本场景过拟合防控与混合正则化矩阵

在双主干架构、上千万参数容量而样本量仅 500-2000 的典型深度过拟合高危场景下，传统的正则化手段需要经过精密筛选：

1. **常规 Dropout 策略的改进**：
   - 在双主干的浅层阶段全面禁用 Dropout，防止低阶视觉特征（边缘、方向、频率）产生过度的高频随机振荡；
   - 在 `cbm_head` 概念映射层与最终 ordinal classification heads 的密集全连接层之间，将 Dropout 率从原有的 $0.2$ 增加至 $0.4$，用以削减神经元之间的协同共适应度。
2. **Stochastic Depth（随机深度 / Drop Path）**：
   - 在 FT 阶段，对 ConvNeXt-Nano 骨干的 Residual Stages 级联应用随机深度丢弃（Drop Path），将 Drop Path 概率设定为 $0.2$。这能允许部分前向传播流直接绕过中间的 Conv 块，变相地缩减了多任务微调阶段的平均模型深度，能够极强地对抗局部特征过拟合。
3. **MixUp 的使用禁忌与流形混叠（Manifold MixUp）**：
   - **在图像级别完全禁用常规的 MixUp**：医学超声图像富含强烈的局部斑点噪声和解剖声学逻辑（例如后方回声衰减提示实性病变、边缘微钙化物理分布等）。若在输入端对图像像素级全局混合，不仅会导致结节形态产生非物理叠加，还会直接破坏分割边界的局部对比度，导致分割损失严重误导 Backbone 的特征收敛。
   - **采用流形混叠（Manifold MixUp）**：仅在分类分支的深度高维特征空间内（例如在 `cbm_head` 概念嵌入特征层），应用随机插值进行特征级别的混叠，从而在特征空间内平滑分类决策面。
4. **R-Drop（双向散度正则化）**：
   - R-Drop 是针对医学影像微调最强力、最无损的正则化方法之一。其机制是：将同一个 Batch 的图像输入模型两次，因为模型内部包含 Dropout 算子（在概念瓶颈层和分类头中），这两次前向传播将激活不同的子网络结构。R-Drop 强制这两次输出对于同一个输入样本产生一致的概率预测，通过最小化其双向 KL 散度，为模型决策提供了极佳的连续性约束。

### 引入 R-Drop 后的 FAMO 多任务联合损失函数设计

对于任意输入 Batch，经过两次独立的带有 Dropout 机制的前向传播，其预测输出对表示为：

$$\text{分类预测: } P^{(1)}(Y_{cls}|X), P^{(2)}(Y_{cls}|X)$$

$$\text{分割预测: } M^{(1)}(Y_{seg}|X), M^{(2)}(Y_{seg}|X)$$

FAMO 系统的 5 通道基本多任务监督损失由 $\mathcal{L}_{MT\_1}$ 和 $\mathcal{L}_{MT\_2}$ 分别计算，而 R-Drop 对分类任务和分割任务分别引入双向 KL 散度约束：

$$\mathcal{L}_{RD\_cls} = \frac{1}{2} \left[ \mathcal{D}_{KL}\left( P^{(1)} \parallel P^{(2)} \right) + \mathcal{D}_{KL}\left( P^{(2)} \parallel P^{(1)} \right) \right]$$

$$\mathcal{L}_{RD\_seg} = \frac{1}{2} \left[ \mathcal{D}_{KL}\left( M^{(1)} \parallel M^{(2)} \right) + \mathcal{D}_{KL}\left( M^{(2)} \parallel M^{(1)} \right) \right]$$

最终，结合了 R-Drop、半监督伪标签遮罩与 FAMO 5 通道动态权重的总微调损失函数 $\mathcal{L}_{Total}$ 建模为：

$$\mathcal{L}_{Total} = \sum_{c=1}^{5} w_c^{(t)} \left( \frac{\mathcal{L}_{c}^{(1)} + \mathcal{L}_{c}^{(2)}}{2} \right) + \alpha_{rd} \cdot \left( \mathcal{L}_{RD\_cls} + \beta \cdot \mathcal{L}_{RD\_seg} \right)$$

其中，$w_c^{(t)}$ 为第 $t$ 步时由 FAMO 计算得出的动态任务损失权重比例；$\mathcal{L}_{c}$ 为多任务损失（对于缺失标注的任务 $c$，其对应样本的损失在计算时被 mask 掉，不产生梯度）；$\alpha_{rd}$ 设定为 $0.5$（微调后期退火至 $0.2$）；$\beta$ 为分割散度惩罚，设定为 $0.15$。

## 无泄露分组交叉验证协议

竞赛的官方评估协议强制按患者进行分组（GroupKFold by patient_id），且该数据特性要求在一患者包含多个静态图像帧/视频帧时，病理结果（良恶性标签）将在患者级进行全局广播。在此约束下，**绝不能使用普通的随机交叉验证，必须严格遵循按患者 ID 物理分割的 GroupKFold 分组方案**。

- **防泄露核心原理**：若采用普通 KFold，同一患者在不同探头角度、不同扫查时间步下的高度同源超声图像会被同时分流到训练集与验证集。因为这些切片的解剖背景、组织反向散射特征、探头声斑完全一致，模型无需进行任何高层抽象，仅凭对底层噪声分布的“记忆”即可在验证集上取得完美的假象高分，但在测试集上将彻底暴露过拟合，性能崩塌。

### 评估指标的数学聚合

为了对模型进行完全没有泄露的、逼近真实临床表现的评估，需要对两个不同维度的核心指标进行严格约束：

| **指标维度**   | **评估对象**            | **计算与聚合机制**                                           | **核心公式**                                                 |
| -------------- | ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **良恶性分类** | 患者级（Patient-level） | 将一个患者 $P_j$ 的所有超声帧的帧级预测恶性概率 $p_{frame\_k}$ 进行患者级聚合。由于临床上只要在任一切面上捕获到明显的恶性特征即提示恶性风险，故**采用 Max 聚合法**作为患者最终得分，以此得分与病理金标准 $Y_{pat\_j}$ 计算总 ROC AUC。 | $P_{patient\_j} = \max_{k \in \mathcal{F}_j} \left( p_{frame\_k} \right)$ |
| **分割效能**   | 图像级（Image-level）   | 仅针对具有真实手工分割掩膜（或置信度极高的专家验证伪掩膜）的超声图像，在二维像素空间内计算预测掩膜 $\hat{Y}_{seg}$ 与真实掩膜 $Y_{seg}$ 的 Dice 相似系数。 | $\text{Dice} = \frac{2 \sum \left( \hat{Y}_{seg} \cdot Y_{seg} \right)}{\sum \hat{Y}_{seg} + \sum Y_{seg}}$ |

| **监控点与失败模式**                      | **早停/触发判据 (Trigger Indicator)**                        | **根本原因分析**                                             | **推荐的恢复干预行动 (Recovery Action)**                     |
| ----------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **CBM概念对齐失效** (Failure Mode 1)      | 在 LP 阶段前 3 个 Epoch 内，CBM 概念的预测交叉熵损失几乎维持水平直线，且验证集患者良恶性 AUC 徘徊在 $0.50$ 随机猜测水平。 | 线性头部学习率 $lr_{head\_base}$ 设定过小，无法打破随机初始化的对称性；或任务对齐模块中出现非预期 NaN。 | 立即异常早停。将首阶段学习率调大至 $2 \times 10^{-3}$，并排查 `TaskAlignmentAdaptor` 输出的张量中是否存在未处理的零分母异常。 |
| **主干预训练特征畸变** (Failure Mode 2)   | 从第一阶段 LP 刚切换至第二阶段 FT 的前 2 个 Epoch 内，验证集分割 Dice 出现断崖式下跌（骤降幅度 $>15\%$），分类 AUC 出现异常向下波动。 | Backbone 初始解冻微调的学习率设得过大，或者 LLRD 衰减比 $\eta$ 设得过大，导致高强度梯度瞬间灌入并破坏了浅层 ImageNet 先验。 | 触发紧急早停。回退至第一阶段 LP 结束时的权重，将 LLRD 衰减系数 $\eta$ 强制调低 $0.05$（例如 $\eta_{cls}$ 降至 $0.77$），同时将基础学习率减半重新启动 FT。 |
| **多任务梯度支配冲突** (Failure Mode 3)   | 在微调中后期，分割 Dice 稳步上升，但良恶性分类 AUC 连续 5 个 Epoch 恶化并彻底退化至 $0.51-0.53$（或者反之）。 | 两个独立解冻的骨干网络参数量差异较大，导致分割主干产生巨大梯度支配了共享的表征层，FAMO 的更新步长较大未能起到压制效应。 | 触发早停。保存当前最优分割权重后，在优化器中针对分类骨干的 LLRD 基础学习率实施小幅调优（如乘以 $1.2$），同时将 R-Drop 惩罚系数 $\alpha_{rd}$ 调高至 $0.45$ 强行保护分类表示。 |
| **小样本局部伪影过拟合** (Failure Mode 4) | 训练损失一路顺畅地下探，但验证集患者级良恶性 AUC 连续 5 个 Epoch 不再上升，且训练集与验证集 AUC 的差值超过 $0.20$。 | 500 例超声样本不足以约束解冻后的 LoRA 复合参数，网络开始对超声特有的边缘伪影、探头型号甚至噪点分布产生物理强记忆。 | 触发早停。保存折返点前 2 个 Epoch 的权重。调整下一轮的正则化配置：将 LoRA Dropout 提升至 $0.2$，将两骨干的 Drop Path 概率设定为 $0.3$，并在反向传播中增加高频噪声增强。 |
