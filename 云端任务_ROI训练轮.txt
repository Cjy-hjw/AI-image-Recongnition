## 2. 1ep 标定 λ_roi(先跑这个,不烧 20ep)

λ_roi 标定协议(DR 决策点 2,预注册):**η=0.15-0.25 目标占比**,
λ = η × L̄_seg / L̄_roi_raw(L̄ = 1ep 各自平均损失,从 JSONL/日志尾部取)。

```bash
mkdir -p /2026aicompetition/workspace/logs/roi_calib_backup
mv /2026aicompetition/workspace/logs/*.jsonl /2026aicompetition/workspace/logs/roi_calib_backup/ 2>/dev/null

cd /root/cloud_train_pkg
PYTHONPATH=/2026aicompetition/workspace/pylibs nohup python -u scripts/train_official.py \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --samples-pkl /root/cache_roi/samples.pkl \
    --resume-from checkpoints/official_heads_seg_best.pth \
    --roi-heads \
    --epochs 1 \
    --out checkpoints/roi_calib_1ep.pth \
    > /2026aicompetition/workspace/train_roi_calib.log 2>&1 &
tail -f /2026aicompetition/workspace/train_roi_calib.log
```

盯启动横幅(判据,全中才继续):
- `[ROI-heads 配方] roi_head_weight=... roi_size=224(训练;推理=512 已知域差异)`
- `[warm-start] ROI 头 46 键随机初始化(冷启动新头,预期行为)`
- `--> [ROI loader] train=... 条`(样本数 >5000;**0 条=旧 pkl,停**)
- ep1 结束打 `[ROI] ep1 loss=... roi_size=224`

**标定计算**(训完 1ep 后):
从日志/JSONL 取:整图 `loss`(或 seg 主项)均值 L̄_seg;`[ROI] ep1 loss=` 的
L̄_roi_raw。算 λ = 0.2 × L̄_seg / L̄_roi_raw(η 取 0.2 居中),回报三个数
(L̄_seg / L̄_roi_raw / 算出的 λ)等确认后进 20ep。

## 3. 20ep 正式训练(标定 λ 确认后)

```bash
# 改 config(只改这一行,λ 用标定值):
sed -i "s/roi_head_weight: 0.0/roi_head_weight: <标定λ>/" configs/thyroid_config.yaml
# grep 核对生效:
grep -n "roi_head_weight" configs/thyroid_config.yaml

cd /root/cloud_train_pkg
PYTHONPATH=/2026aicompetition/workspace/pylibs nohup python -u scripts/train_official.py \
    --data-root /2026aicompetition/datasets/training/annotation \
    --xlsx /2026aicompetition/datasets/training/annotation/甲状腺_标注结果_训练集.xlsx \
    --samples-pkl /root/cache_roi/samples.pkl \
    --resume-from checkpoints/official_heads_seg_best.pth \
    --roi-heads \
    --epochs 20 \
    --out checkpoints/roi_heads_ep20.pth \
    > /2026aicompetition/workspace/train_roi_20ep.log 2>&1 &
```

健康判据(每条不中=停机回报):
- ep1-3:loss 有限无 NaN;`[ROI] epN loss=` 在降或稳;
- ep1 后**无** `[FATAL] ROI 头梯度全零`(有=接线断,停);
- JSONL 逐 ep 有 `roi_branch` 行 + `roi_size=224` 键;
- ⚠️ 看到 `⚠️ roi_concept_weight=...>0` 警告 = config 被人改过,概念监督
  在官方数据上恒空(已知限制),**roi_concept_weight 保持 0** 别动。

快照在 ep4/8/12/16/20 自动落(--out 同名 _epN 后缀,seg_only 同款)。
